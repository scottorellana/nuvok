# 極寒と雪中の避難場所

深い氷点下では、**雪は敵ではなくなる：建設材料である**。雪洞は外が-30 °Cでも内部を約0 °Cに保つ。

## 重要手順

1. **問題が起きる前に避難する。** ホワイトアウトまたは-20 °Cでは、手が機能する有効時間は短い：限界ではなく、エネルギーと光が十分あるうちに避難場所を決める。
2. **雪の塹壕（最速）：** 自分の体 + 40 cmの溝、ブロック／スキー／枝 + 上に雪の屋根、低い入口をバックパックでふさぐ。作業30-60 min。
3. **固く締まった斜面の雪洞（最も暖かい）：** ドーム状の部屋へ向かって上がるトンネル；寝る台は入口より高くする（冷気は下へ外へ流れる）。壁は30+ cm。
4. **通気孔がなければ目覚めない。** 天井にこぶし大の穴を開け、棒を貫通させておき、その棒を時々動かして開いた状態を保つ。密閉された避難場所のCO₂は眠っている間に殺す。
5. **汗をかかずに作業する。** 汗をかいて建設する = 濡れた衣服 = 遅れて起こる低体温。作業時は層を脱ぎ、終わったら着る。入る前に衣服の雪をすべて払い落とす。
6. **地面から三倍断熱する：** 枝／バックパック／巻いたロープのマット — 体の下の氷は空気より多く熱を奪う。ブーツと手袋は濡れているなら絶対に着けたまま寝ない：胸元、衣服の中へ。
7. **凍傷（frostbite）：火ではなく体の熱。** 指／鼻／耳が白く硬い：自分または仲間の脇の下／鼠径部、こすらない（結晶が組織を切る）。行動中に再凍結する可能性があるなら絶対に解凍しない。

## してはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| 「寒いから」と避難場所を密閉する | 通気孔は常に開け、監視する |
| 上着を着たまま汗だくで建設する | 作業時は層を脱ぐ；終了時は乾いた状態にする |
| 凍った皮膚を雪でこする | 摩擦なしで、直接体温を使う |
| 濡れたブーツを履いたまま眠る | 胸元へ：自分の熱で少しずつ乾かす |
| 「快適にするため」大きな避難場所にする | 小さく低く：自分の熱で満たす必要がある |
| 方向を確認しようとホワイトアウトの中で避難場所を出る | 固定したガイドロープ、または中で待つ |

## ホワイトアウト（whiteout）

- 世界が消えたら：避難場所、または動かない。白い中を歩く = 円を描き、クレバスに入る。
- 外出には必ず避難場所に固定したロープ（5歩先のトイレでも迷う）。
- 避難場所を高く標識する（棒 + 布）：眠っている間に雪が入口を埋める。

## 実践例：極寒

**状況：** スノーモービルが-25 °Cで故障；風が強まり、集落は20 km先にある。

**実行：** 1. 今すぐ決定：吹雪の中を誰も20 km歩かない — 機械のそばに避難場所を作る（目に見える合図になる）。 2. 風下側に塹壕を作り、座席／シート + 雪で屋根を作る。 3. 掘っている間は層を脱ぐ；体を払い、入るときに乾いたものをすべて着る。 4. 棒で通気孔 + 下に三倍の断熱。 5. メッシュのSOSビーコンを出して待つ：捜索者は機械がある場所を探す。

**避ける：** 徒歩で「すぐ着く」と試みない、屋根を密閉しない、濡れた衣服で眠らない、機械を離れない（目に見える地点である）。

**エスカレーション：** 誰かが震えなくなる、ろれつが回らない、または屋外で「少し眠りたい」と言う場合：重度低体温 — 直ちに低体温ガイド、避難場所内で皮膚と皮膚の加温を行い、その人が意識を回復するまで本人の決定は一切有効ではない。
