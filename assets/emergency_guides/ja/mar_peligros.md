# 海と海岸の危険

海は無知を許さない：**離岸流はサメより多くの人を殺し**、潮は閉じ込め、踏むものが毒を持つことがある。

## 重要な手順

1. **入水する前に離岸流を読む。** 波のある区域の間にある不自然に穏やかな水路、濁った水／泡立った水が沖へ出ている場所：そこには入らない。捕まったら：浜と平行に進み、決して正面から逆らわない。
2. **潮汐を尊重する。** 崖の基部や潮だまりへ歩く前に、海藻／湿り気の線を見る（そこまで水位が上がる）。上げ潮 + 崖 = 致命的な罠：十分な時間の余裕を持って戻りを計算する。
3. **入水時は足を引きずる。** 砂に潜ったエイは、押しのける足ではなく、踏む足を刺す：「エイ歩き」で追い払う。
4. **知らないものに触らない。** クラゲ（打ち上げられ「死んで」いても刺す）、イモガイ、小さく鮮やかなタコ、ウニ：規則は単純 — 美しく動かないもの = おそらく有毒。
5. **出血しているなら、水から出る。** 出血する傷が少しでもあれば、出る：血は捕食者を呼び、海水は感染を起こす。真水で洗い、覆い、創傷ガイドへ。
6. **クラゲ刺傷：真水ではなく海水。** 海水ですすぐ（真水はより多くの毒を放出させる）、カードの縁／平らなナイフで触手を取り除き、多くの場合は局所加温（温水 20-45 min）；咬傷・刺傷ガイドへ。
7. **リーフや波のある岩場：決して海に背を向けない。** 「不意波」は毎年、岩場から人をさらう：近づく前に 10 分間、波のパターンを観察する。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 離岸流に正面から泳いで逆らう | 浜と平行に進み、斜めに戻る |
| 上げ潮のときに崖の基部を探索する | 潮位線を確認し、余裕を持って戻る |
| クラゲ刺傷に尿をかける | 海水 + 触手除去 + 加温 |
| リーフ／潮だまりを裸足で歩く | 常に履物を着用；砂地では足を引きずる |
| イモガイ／タコ／クラゲを「記念に」拾う | 知らない生物には、死んでいても触らない |
| 岩場で波に背を向ける | パターンを観察し、退避路を確保する |

## サメ（実際のリスクは最小）

- 夜明け／夕暮れ、出血している傷がある時、または跳ねる魚群の中で泳ぐのは避ける。
- 見かけたら：ゆっくり動き、垂直姿勢を保ち、水しぶきを立てず、視線を外さずに岸へ向かう。
- 接触があった場合に限り、吻／目／えらを打つ — ほとんどの場合、接触は起こらない。

## 実践例：海の危険

**状況：** 釣りをするために浜を歩いて岩の岬へ向かっている；崖下の通路は乾いており、午後が進んでいる。

**行うこと：** 1. 崖の海藻線を見る：通路がその下にあるなら、潮がそこを覆う。 2. 潮が上げているか下げているか確認する（岩を半時間観察する）。 3. 下げ潮の時だけ渡り、潮が変わる前に戻る。 4. 海に向かって釣りをし、決して背を向けない。 5. 履物は常に履いたままにする。

**避けること：** 上げ潮の時に「急いで」渡らない、見ずに潮だまりを踏まない、打ち上げられたクラゲに触らない、砕波帯の縁にとどまらない。

**エスカレーション：** 潮により崖際に閉じ込められたら：今すぐ到達可能な最も高い地点を探し、メッシュの SOS を起動する — 3 m 上がることで数時間を稼ぐ；波が岩に当たる中で泳ぎ出すのは最後の手段であり、浮力体がある場合に限る。
