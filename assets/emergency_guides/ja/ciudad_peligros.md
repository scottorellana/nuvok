# 崩壊した都市の危険

壊れた都市は静かに人を殺します：**しばらくすると臭いが分からなくなるガス、水たまりの中の電線、「奇跡的に」持ちこたえた壁** — そして人々のパニック。

## 重要な手順

1. **ガス：まず鼻、その後バルブ。** 腐った卵の臭い、またはシューという音 = 何も点けない（スイッチも不可：火花が出る）。開けて換気し、ガスの元栓を閉め、避難し、ドアを叩いて近所に知らせる — 呼び鈴は使わない。
2. **倒れた電線はすべて通電中**、電力会社が否定するまではそう扱う。バス一台分の距離（10 m）。水たまりでは水が到達範囲を広げる。電線が車の上に落ちたら：中にとどまり助けを待つ。
3. **損傷した構造物は余震ごとに再評価する。** 柱の X 字状のひび、傾いた床、もう閉まらないドア = 中で寝ない。スラブの下で素早く潰されるより、庭で不便に過ごすほうがよい。
4. **消防が来ない火災：勝つべきは出口であり、戦いではない。** 煙 = 四つんばい（呼吸できる空気は下にある）、手の甲で触れて熱いドア = 開けない、口に濡れ布。消すのはごみ箱程度の火だけ。それ以外は避難し、隔離する（出る時にドアを閉める）。
5. **日中に、集団で、目的地をもって移動する。** 崩壊後は通りが変わる：損傷した構造物の下、傾いた電柱、パニックの群衆を避ける。代替ルートを常に二つ。
6. **英雄行為なしの安全：** 目立たず、資源は見せずに保管し、簡単に扉を補強する（くさび、家具）、そして近隣ネットワークを最良の警報にする — 互いを知る地域は互いを守る（コミュニティ組織ガイド）。
7. **記録し、伝える：** 自宅の被害写真（後のため）と、経路／危険の状況を mesh で共有する — あなたの「橋が落ちた」という通知が、後から来る人を救う（戦術地図）。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 「ガス漏れを確認するために」電気を点ける | 電気は一切使わない：換気、元栓を閉める、外へ出る |
| 「切れている」倒れた電線をまたぐ | 10 m 離れる；確認されるまで通電中 |
| 「揺れに耐えたから」と屋内で寝る | X 字ひび、またはドアが引っかかる = 外へ |
| 火災中に熱いドアを開ける | まず手の甲；熱い = 別の出口 |
| 発電機／食料庫／武器を見せびらかす | 目立たず、近隣ネットワーク |
| 逆流してパニックの群衆を横切る | 群衆の端、中心に逆らわない |

## 都市の危険用救急キット

- ガスと水の元栓：家の全員が場所と閉め方を知っている。
- ABC 消火器、または台所に砂のバケツ。
- ベッドの横に閉じた靴（ガラス）+ 懐中電灯 + ホイッスル。
- 密封袋に入れた書類のコピー + アプリの ICE カード。

## 実践例：都市の危険

**状況：** 地震後、あなたの区画は停電した。隣家の前でガスの臭いがし、濡れた歩道の上に電線がある。

**行うこと：** 1. 電線の周囲に頭の中で 10 m の印を付け、遠くから大声で知らせる — 誰も水たまりを渡らない。 2. ガスのある家：ドアを叩き（呼び鈴は使わない）、スイッチに触れずに元栓を閉め、換気してもらう。 3. 念のため自宅のガスも止める。 4. 両方の危険を mesh の戦術地図に投稿する。 5. 今夜：中で寝る前にひびを確認する。

**避けること：** 「もっとよく見るために」ライターを点けない、「乾いた」棒で電線を動かさない、子どもを近くで歩き回らせない、ひびの入った家で寝ない。

**エスカレーション：** 爆発または明らかな火災：風上に向かって区画を避難、mesh の集合場所を有効化し、やけど／崩落ガイドが主導する；電撃の負傷者 = 反応がなければ CPR（電源から離れた後なら触れても安全）。
