# 極寒での水と食料

凍った水に囲まれていても脱水で死ぬことがある：**雪を食べると体の中核が冷える**うえ、乾いた寒気は汗をかいていなくても脱水を進める。そして寒さは二倍のカロリーを要求する。

## 重要な手順

1. **絶対に雪を直接食べてはいけない。** 体温で溶かすには、生き続けるための熱を消費し、エネルギーとして二倍の水を燃やすことになる。体が温かく、動いている場合に限り、ごく少量だけにする。
2. **なめずに、溶かす：** 鍋を使った火／ストーブ（鍋を焦がさないよう、底に少量の液体の水を入れて始める）、または日なたに置いた雪入りの黒い袋／衣服の層の間に入れたボトル（皮膚に直接当てない）。
3. **溶かすなら氷 ＞ 雪：** 氷は同じ体積で二倍の水を得られ、燃料は半分で済む。古い青みがかった淡水氷を使う；若い海氷は塩分を含む（古い青みがかったものは塩分が抜けている）。
4. **ぬるい水をこまめに飲む。** 寒さの中では喉の渇きを感じないが、呼気で何リットルもの水分を失う：尿が透明であることが目安になる。ぬるい水なら、体内で温めるために自分の熱を消費しない。
5. **脂肪と二倍のカロリーを摂る：** 寒さでは 4,000-6,000 kcal/日を消費する。脂肪が最重要（グラムあたりのエネルギーは二倍超）；就寝前の温かい食事は夜間の暖房になる。
6. **水を凍結から守る：** ボトルは逆さまにする（氷は上からできるため、ねじ口が固着しない）、日中は上着の内側に、夜は寝袋／避難場所の中に入れる。
7. **食料確保の計画としての氷上釣り：** 氷の下の水には冬じゅう魚がいる — 穴 + 餌付きの釣り糸（釣りガイド）；氷の厚さは必ず確認する（危険ガイド）。

## してはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| 喉が渇いて雪を握りこぶし分食べる | 飲む前に溶かしてぬるくする |
| 乾いた鍋で雪を強火で溶かす | 最初に少量の水を入れる。そうしないと鍋が焦げる |
| 「氷だから」と若い海氷を使う | 古い青みがかった氷または淡水氷だけを使う |
| 「溶かすのが大変だから」と水を配給制限する | 尿が透明になるまで飲む：寒冷環境での脱水は油断できない |
| 極寒で「軽い」低脂肪食にする | 脂肪と二倍の配給：寒さの代償はカロリーで支払う |
| ボトルを上向きで屋外に放置する | 逆さまにし、上着／寝袋の中に入れる |

## 夜間の雪のオーブン

- 寝る前にボトル／袋へ雪を入れ、寝袋に入れる（皮膚に直接当てない）：燃料を使わず、朝には水が得られる。
- 保温ボトル、または靴下で包んだボトル = 朝まで液体の水を保てる。

## 実践例：寒冷下での水と食料

**状況：** 雪の避難場所で待機して二日目；ストーブの燃料はタンク半分、液体の水は少量、クラッカー + ピーナッツバター一缶が残っている。

**実行：** 1. ガイドロープを使って、雪ではなく青みがかった氷を取りに外へ出る。 2. 手元の液体の水を使って開始し、何回かに分けて溶かす；ボトルに補充し、そのうち一本は逆さまにして寝袋へ入れる。 3. 就寝前に温かい配給を摂る：ピーナッツバターは最良の武器（脂肪）である。 4. 尿が透明になるまで、毎時ぬるい水を飲む。 5. 燃料が半分なら：調理よりも溶かすことを優先する（クラッカーに火は不要）。

**避ける：** 「その間に」雪をなめない、乾いた鍋で溶かさない、配給制限のために夜の食事を抜かない、ボトルを外に置きっぱなしにしない。

**段階的対応：** 燃料が尽きた場合：真昼の太陽の下に雪入りの黒い袋を置き、移動中は衣服の層の間にボトルを入れる；誰かが尿を出さなくなる、または混乱する場合は、緊急事態（低体温／脱水）として扱い、すべてのぬるい水をその人に優先する。
