# 大海与海岸的危险

大海不原谅无知：**离岸流杀的人比鲨鱼多**，潮水会困住你，脚下踩到的东西可能有毒。

## 关键步骤

1. **下水前先认出离岸流。** 两片浪区之间异常平静的水道、浑浊/带泡沫的水流向外海：不要在那里下水。被卷住时：平行于海滩游，绝不迎着它。
2. **敬畏潮汐。** 走悬崖底或去潮池之前，先看海藻线/水渍线（潮水会涨到那里）。涨潮+悬崖=死亡陷阱：回程要留出几小时余量。
3. **下水时拖着脚走。** 埋在沙里的魟鱼刺的是踩上去的脚，不是推开它的脚："拖步走"能把它吓走。
4. **不认识的不要碰。** 水母（搁浅"死了"也蜇人）、芋螺、鲜艳的小章鱼、海胆：规则很简单——好看又不动=多半有毒。
5. **在流血就离开水。** 只要有伤口出血就上岸：血会引来掠食动物，海水会感染伤口。用淡水冲洗、包扎，转伤口处理指南。
6. **水母蜇伤：用海水，不用淡水。** 用海水冲洗（淡水会让刺细胞释放更多毒液），用卡片边缘/刀背刮掉触须，多数情况局部热敷（热水20-45 min）；转咬伤蜇伤指南。
7. **风浪中的礁石和岩石：绝不背对大海。** "疯狗浪"每年都把人从岩石上卷走：靠近前先观察10分钟浪的规律。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 迎着离岸流硬游 | 平行于海滩游，再斜线游回 |
| 涨潮时去探悬崖底部 | 先看潮线，留足余量返回 |
| 往水母蜇伤处撒尿 | 海水冲洗+刮除触须+热敷 |
| 光脚走礁石/潮池 | 始终穿鞋；沙地上拖步走 |
| 捡芋螺/章鱼/水母"当纪念" | 不碰不认识的动物，死的也不碰 |
| 在岩石上背对海浪 | 观察浪的规律，留好退路 |

## 鲨鱼（真实风险其实很小）

- 避免在黎明/黄昏、带着出血伤口或在跳跃的鱼群之间游泳。
- 看到鲨鱼：动作放慢，身体竖直，不要拍水，盯着它慢慢退向岸边。
- 只有真的被碰到才打它的鼻/眼/鳃——几乎不会发生。

## 示例：大海的危险

**情况：** 你沿海滩走向一处岩石岬角钓鱼；悬崖下的通道现在是干的，天色渐晚。

**做法：** 1. 看悬崖上的海藻线：通道若在线以下，涨潮会淹没它。2. 确认潮水在涨还是退（盯着一块礁石看半小时）。3. 只在退潮时通过，并在潮向转变前返回。4. 面朝大海钓鱼，绝不背对。5. 全程穿鞋。

**避免：** 不要涨潮时"赶紧冲过去"，不要不看就踩潮池，不要碰搁浅的水母，不要站在浪打的边缘。

**升级：** 被潮水困在悬崖下时：立刻找能到达的最高点，启动网状网络SOS——爬高3 m能多撑几小时；顶着浪游向礁石是最后手段，且必须带浮具。
