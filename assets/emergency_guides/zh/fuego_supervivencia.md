# 不用火柴生火

火能提供热量、净化水、烹饪、照明，并**向救援人员发信号**。准备得好比点燃更重要。

## 关键步骤

1. **在第一颗火星前准备好一切。** 火绒 + 细柴 + 中等柴 + 粗柴，全部备好、干燥，并放在手边。失败的火中有 90% 死于准备不足，而不是缺少火星。
2. **收集真正的火绒。** 干燥且蓬松：内层树皮、揉碎的干草、衣物上的棉絮、口袋绒毛、用刀刮出的极细木屑。一大把（葡萄柚大小）。
3. **保护生火点。** 干燥底座（树皮或平石）、挡风墙，若有毛毛雨则利用天然顶盖——但烟要能排出。
4. **产生火星/炭火**（见下方方法）直接落在火绒上。
5. **轻柔且持续地吹气。** 当火绒冒烟时，把它像鸟巢一样捧在手中，从下方轻轻吹——典型错误是用力吹而把它吹灭。
6. **从细到粗添加燃料。** 像火柴一样的小枝 → 像铅笔 → 像手指 → 像手腕。每个尺寸都要充分燃烧后再加下一种。
7. **绝不要让火无人看管**，并备好水/土以完全扑灭（埋着的余烬会引发火灾）。

## 不用火柴的方法

### 铈铁棒（你套装里的）
- 用刀背缓慢而用力地刮，几乎贴着火绒。
- 3000 °C 的火星：潮湿和有风时也能用。

### 放大镜 / 透镜（只在强阳光下）
- 放大镜、望远镜镜片、装有清水的瓶底。
- 将光点集中到最小，照在深色火绒上，并且不要移动。

### 电池 + 钢丝绒或铝箔纸
- 钢丝绒接触 9V 电池两极 = 立即形成炭火。
- 口香糖包装纸（铝+纸）裁成中间很窄的形状，连接 AA 电池两极。

### 摩擦（弓钻——最后手段）
- 只适用于非常干燥且柔软的木材（柳木、雪松、干丝兰）。
- 需要技巧和数小时练习：如果以前没有练习过，不要指望它。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 没把所有柴火准备好就点火 | 在火星前准备 3 种尺寸的柴 |
| 火绒“差不多干” | 寻找干燥处：树干内部、岩石下方 |
| 把粗柴堆在刚出生的火苗上 | 从细到粗，木柴之间留空气 |
| 在悬垂树枝下或干根上生火 | 清理周围和上方 1.5 m |
| 用燃料/酒精助燃 | 绝不要：会导致烧伤和失控火焰 |
| 丢下“几乎熄灭”的余烬 | 加水 + 翻动 + 覆土，摸起来变冷 |

## 火作为救援信号

- **3 堆火呈三角形** = 国际求救信号。
- 白天：烟——向旺火中加入绿叶或橡胶。
- 夜晚：火焰——在可见空地中保持火势旺盛且较大。

## 实用示例：不用火柴生火

**情况：** 天色将晚，你全身潮湿，只带着小刀和铈铁棒。

**要做：** 1. 在火星之前：从干木内部取火绒 + 准备好 3 种尺寸的柴。 2. 干燥底座和挡风墙。 3. 在火绒巢上缓慢而用力地刮铈铁棒。 4. 从下方轻轻吹，并从细到粗添加燃料。

**避免：** 不要在未准备柴火时点火，不要用力吹第一点炭火，不要使用燃料，不要让火无人看管。

**升级处理：** 如果多次尝试后仍点不着且气温下降，放弃生火：进入庇护所，隔离地面，并共享体温；白天再试。
