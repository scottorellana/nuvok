# 咬傷と刺傷

> ⚠️ このガイドは専門的な医療の代替ではありません。できるだけ早く医療支援を求めてください。

## ヘビ

### してはいけないこと（迷信は毒より多く人を死なせる）

- ❌ 傷を切らない、毒を吸わない、止血帯を巻かない、氷や電気ショックを当てない、アルコールやコーヒーを与えない。
- ❌ ヘビを捕まえよう、または殺そうとしない（二度目の咬傷）。遠くからの写真で十分。無理なら色と形を覚える。

### 手順

1. **その人をヘビから遠ざける。** 座らせる。落ち着かせる：パニックは心拍を速め、毒を広げる。
2. 腫れる前に、咬まれた手足の**指輪、ブレスレット、靴を外す**。
3. **手足を固定する。** 柔らかい副木で、心臓より低い位置に保つ。脚の場合は歩かせない（担いでもらう）。
4. **腫れの縁と時刻をペンで印を付ける**。15 minごとに繰り返す（医師に毒の進行速度を示す）。
5. 水と石けんでやさしく洗う。ゆるくガーゼで覆う。
6. **抗毒素のある病院へ緊急搬送する**（可能なら事前に電話して在庫を確認する）。抗毒素が唯一の実質的治療である。
7. 「痛くない」または乾いた咬傷に見えても：最低6〜8 hは観察する。

## 犬／猫／人／コウモリ

1. **今すぐ大量の水と石けんで10〜15分、** 傷の中に流水を当てて洗う — これが狂犬病予防と感染予防で最も重要な処置である。
2. 圧迫して出血を抑える。ガーゼで覆う。
3. **必ず同じ日に医師へ：** ほとんどは抗生物質（特に猫と人の咬傷）と、**狂犬病**（ワクチン）および破傷風の評価が必要。コウモリ＝反証されるまで狂犬病とみなす。痕が見えなくても同じ。
4. 動物に飼い主がいる場合：飼い主の情報とワクチン状況を確認し、10日間観察してもらう。

## サソリ／蠍

1. 洗い、布で包んだ冷却を局所に行い、ラベルに従って市販の鎮痛薬を使用する。
2. **小さな子ども、または局所の痛みを超える症状**（流涎、大量発汗、かすみ目、目や舌の異常な動き、呼吸困難）→ 緊急で病院へ（抗毒素が必要な場合がある）。
3. 局所の痛みだけの成人：4〜6時間観察する。

## ミツバチ／スズメバチ

1. **ミツバチの針：カードの縁や爪でこすって今すぐ取り除く**（ピンセットでつままない：さらに毒を絞り出す）。一秒一秒が重要。
2. 洗う。包んだ冷却を10〜15 min行う。ラベルに従って市販の鎮痛薬および／または抗ヒスタミン薬を使用する。
3. 一度に多数刺された（群れ）、または口／喉を刺された → 緊急で医師へ。

## 🚨 アナフィラキシー（重度アレルギー — どの刺傷、食べ物、薬でも起こりうる）

**疑う所見：** 数分以内に全身のじんましん、唇／舌／まぶたの腫れ、喘鳴または呼吸困難、喉の締めつけ感、かすれ声、嘔吐、めまい、または失神が現れる。

1. **エピネフリン／アドレナリン自己注射器があれば（EpiPen）：今すぐ使う。** 太ももの外側に、必要なら衣服の上から打つ。ためらわない：待つことは命取りだが、注射は命取りではない。
2. **改善しても必ず緊急搬送**（4〜8 hで再発することがある）。
3. 脚を高くして寝かせる（呼吸が苦しければ半座位、妊娠中なら左側臥位）。
4. 経口抗ヒスタミン薬はじんましんには役立つが、エピネフリンや病院の代わりにはならない。
5. 呼吸が止まった → CPR。

## 悪化のサイン（すべての咬傷・刺傷）

- 急速に進む腫れ、全身のじんましん、呼吸時の喘鳴 → アナフィラキシーとして扱う。
- 発熱、膿、数日後に増す痛み → 感染：医師へ。

## 実践例：咬傷と刺傷（ヘビ、犬、サソリ、ハチ）

**状況：** 農場で、誰かが咬まれた／刺された後に突然の痛みを感じ、動物が何か分からない。

**行う：** 1. 現場の安全を確保し、特定の一人に救急へ電話するよう頼む。 2. ガイドの大きな手順を順番どおりに進め、最も劇的に見える手順へ飛ばない。 3. 使えるなら手袋、バリア、清潔な布を使う。 4. 毎分再評価する：呼吸、意識、出血、体温、または悪化。

**避ける：** 高度な手技を即興で行わない。損傷が疑われる場合は首／脊柱を動かさない。混乱している人に食べ物／飲み物を与えない。完璧な装備を探して通報を遅らせない。

**エスカレート：** 正常に呼吸していない、胸痛がある、止まらない出血、混乱、広範囲の熱傷、毒の可能性、妊娠後期、または複数の被害者がいる場合は、直ちに電話するか搬送する。

**クイックチェック：** ガイドを閉じる前に、何が起きたか、何をしたか、何が残っているか、誰が責任者として残るかを声に出して言う。この例はガイド付きの練習である。手順を自分の環境に合わせ、利用できる場合は専門的支援を優先する。
