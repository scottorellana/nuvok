# 沙漠危险

沙漠中致命的东西很少是电影里出现的那些：真正危险的是**突发暴涨洪水、你把手放下去的地面，以及你搭床的溪流**。

## 关键步骤

1. **绝不要在干河道中扎营。** 突发暴涨洪水是沙漠中的沉默杀手：30 km 外一场你甚至看不到的雨，夜里就可能送来一道水墙。始终睡在高地上，即使溪流看起来是最舒适、最平坦的地方。
2. **如果河道开始发出声响或闻到湿土味，跑向高处。** 不要穿越有流动水的溪流：几分钟内就会从水洼变成激流。
3. **触碰前先看。** 蛇和蝎子会在你想要的阴影中休息：石头下、柴火下、裂缝中。搬石头和柴火时要朝你自己这边滚动（虫兽会向另一边逃），绝不要把手伸进看不见的地方。
4. **每天早晨抖靴子和衣物。** 蝎子夜里会寻找你的热量。靴子倒置 + 敲击鞋跟后再穿：这是必须的仪式。
5. **带手杖行走并重重踩地。** 震动会提醒蛇；大多数咬伤发生在踩到或把手放上去时。如果你看到一条：不要动，然后慢慢后退——绝不要摆弄它，即使“死了”也不行（头部会反射性咬人）。
6. **沙尘暴：停下、遮盖、等待。** 在它到来前标记你的方向（石头箭头），用布遮住鼻子和嘴，保护眼睛，背对风靠在遮挡物旁，并等待：在风暴中行走会迷路。
7. **尊重夜间寒冷。** 经历 40 °C 的一天后，凌晨可能接近 0 °C：沙漠低体温确实存在（高温与庇护指南）。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 在“又平又舒服”的干溪流中扎营 | 始终在高地，远离河道 |
| 把手/脚伸进裂缝、洞或石头下 | 先看，把石头朝自己滚动 |
| 不抖靴子就穿上 | 每次都倒置并敲击鞋跟 |
| 摆弄一条“死”蛇 | 头部数小时后仍会反射性咬人 |
| 在沙尘暴中行走 | 停下、标记方向、遮盖并等待 |
| 切开/吸吮蛇咬伤 | 固定、标记时间并转到咬伤指南 |

## 如果被蛇咬

1. 远离蛇；坐下并保持冷静（心跳加快会扩散毒液）。
2. 立即取下受伤肢体上的戒指/手表/靴子（会肿胀）。
3. 将肢体固定在心脏高度或更低；用笔标记时间和肿胀边缘。
4. 不要用止血带、切开、吸吮或冰敷。
5. 尽量少走；如可能让别人运送你 → 咬伤与蜇伤指南。

## 蝎子蜇伤

- 局部剧痛：清洗，用布包裹后局部冷敷，使用你急救包中的止痛药。
- 观察 4 h：流涎、复视、痉挛或呼吸困难 = 急需抗毒血清，启动 SOS。
- 幼童被蝎子蜇伤始终属于急症。

## 实用示例：沙漠危险

**情况：** 干旱地带黄昏；唯一平坦且挡风的地面是一条柔软沙地的干溪流。

**要做：** 1. 拒绝它：上升 3-5 m 到最近的高台地，即使不那么舒适。 2. 搭营前，检查周围石头和裂缝，把石头朝你自己滚动。 3. 把靴子倒置放在庇护所内。 4. 用石头箭头标记方向，以防清晨有风暴。 5. 准备保暖：凌晨会冷。

**避免：** 不要因为舒适就在河道中睡觉，不要把靴子留在外面，不要在黑暗中把手伸到石头下，不要在沙尘暴来临时行走。

**升级处理：** 如果尽管如此你被暴涨洪水追上：丢下一切并爬到最高处（不要穿越水流）；如果咬伤后肿胀快速进展或呼吸困难，启动 mesh 的 SOS 并应用咬伤指南——这是与毒液赛跑。
