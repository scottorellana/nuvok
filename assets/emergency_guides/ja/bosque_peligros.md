# 森の危険

森であなたを狩るものはほぼいません。**事故のほとんどは自分が原因** — どこを踏むか、どこに手を入れるか、どこで眠るかです。

## 重要ステップ

1. **踏む場所とつかむ場所を見る。** ヘビ咬傷の90%は足と手：倒木は上に乗ってから（向こう側を見ずに跨がない）、穴・石の下・落ち葉に手を入れない。
2. **音があなたの盾。** 自然な物音を立てて歩く：ほとんどの動物は気配で避けてくれます。危険なのは驚かせること。
3. **使う前に必ず振る。** 朝はブーツ・服・ザックを振る：サソリやクモは夜、温もりを求めて入り込みます。
4. **休む前に頭上を確認。** 引っかかった枯枝（ウィドウメーカー）、ハチの巣、木のアリ — 枯枝は獣より多く人を殺します。
5. **ヘビに遭遇：静止して後退。** ゆっくり2歩下がる；食べられない相手に毒を使いたくないのです。「どかすため」でも絶対に触らない。死んだヘビも（咬反射）。
6. **ハチの群れ：まっすぐ遠くへ走る。** 最低200〜300m、可能なら茂みを抜けて；水に飛び込まない（出てくるのを待たれます）。顔と首を守る。
7. **重い咬傷・刺傷は**咬傷・刺傷ガイドへ：固定し、時刻を記録。止血帯と毒の吸い出しは絶対にしない。

## してはいけないこと

| ❌ 間違い | ✅ 正しい |
|----------|----------|
| 見えない場所に手足を入れる | まず見る、棒でかき分ける |
| 落ち葉の地面に直接寝る | 枝で床を上げる+周囲を点検 |
| 「親とはぐれた」子どもの動物に近づく | 母親はすぐ近く：今すぐ離れる |
| 毛虫・派手な色のカエル・乳液の出る植物に触る | 鮮やかな色=化学的警告 |
| 茂みの中をパニックで走る | しっかり歩く：転倒が事故第1位 |
| 寝床のそばに食料を吊るす | 食料は50m以上離して高く：動物を寝床に招かない |

## 本当の危険、順位つき

1. **転倒と捻挫** — 野外の真の事故第1位。
2. **落ちてくる枯枝** — 常に頭上を確認。
3. **昆虫**（ハチ、アリ、マダニ、蚊）— 哺乳類全部より入院者が多い。
4. **ヘビ** — 足元を見れば避けられる。
5. **かぶれる植物とトゲ** — 洗わないと感染。
6. **大型哺乳類** — リストの最後：向こうが避けます。

## マダニとヒル

- マダニ：ピンセットで頭部をつかみ、ゆっくりまっすぐ引き抜く。焼かない、アルコールに漬けない（吐き戻します）。
- ヒル：口元に爪を滑り込ませて剥がす；引きちぎらない。
- 咬まれた日付を記録：数日内の発熱=医療機関へ。

## 例：森の危険

**状況：** 夕暮れ、薪を集めており、倒木の間に深い落ち葉。

**行動：** 1. 手を入れる前に長い棒で落ち葉をかき分ける。2. 倒木に乗り、向こう側を見てから降りる。3. 普通に音を立てて薪を集める。4. 寝る前にブーツを振り、シェルターの頭上を確認。

**回避：** 夜の薪集めをしない、穴に手を入れない、巣に触れない、シェルター内に食料を置かない。

**エスカレーション：** ヘビに咬まれた、群れに多数刺された（またはアレルギー兆候：顔の腫れ、喘鳴）場合、直ちに咬傷/刺傷ガイドへ移り、メッシュのSOSを発信。
