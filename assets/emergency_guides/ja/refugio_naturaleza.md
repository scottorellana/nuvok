# 自然の中のシェルター

**3のルール：**寒さ／風／雨への曝露により、**3時間**で死亡することがある。シェルターは水や食料よりも前に優先する。

## 重要な手順

1. **早めに決断する。** 少なくとも日没の2時間前にはシェルター作りを始める。暗闇ではすべてに三倍の時間がかかる。
2. **正しい場所を選ぶ。** 平坦で乾いた地面、風を避けられ、材料（枝、葉）の近く。上を確認する：垂れ下がった枯れ枝（「未亡人作り」）が一本もないこと。
3. **まず地面を断熱する。** 地面は空気よりも多くの熱を奪う。屋根を考える前に、松の枝、乾いた葉、または草を20〜30 cmの層に敷く。
4. **小さく作る。** 理想的なシェルターは自分の体よりわずかに大きい程度である：自分の体温で内部を暖める。大きなシェルターは寒いシェルターである。
5. **リーン・トゥ（片流れ）を組む。** 丈夫な丸太または枝を、腰の高さで二本の木の間に支える；風上側からそれに斜めの枝を立てかける；その上に細い枝を編み込む。
6. **瓦のように層を重ねて屋根をふく。** 葉、樹皮、草、または松の枝を下から上へ重ね、各層が前の層を覆うようにする — そうすれば雨は外へ流れ落ちる。最小厚：30 cm（光が透けて見えてはいけない）。
7. **風上側を閉じ、シェルターに目印を付ける**。救助隊に見えるよう、目立つもの（色の付いた衣類、枝の十字）を使う。

## シェルターを作ってはいけない場所

| ❌ 誤り | ✅ 正しい |
|----------|------------|
| 沢や峡谷の底 — 冷たい空気が下りて滞留し、遠くの雨でも浸水する | 斜面の低い位置、中腹 |
| 枯れ枝や枯れ木の下 | 作る前に樹冠を確認する |
| 風にさらされた丘の頂上 | 岩や密な植生の陰 |
| 快適そうに見えても、涸れた水路 | 水路や岸から最低60 m離れる |
| 巣、巣穴、または動物の通り道のそば | 足跡や糞のない場所 |

## 手元にあるものに応じた種類

### タープまたはプラスチックがある場合
- 二本の木の間にロープ＋その上にタープをA字に張る＝10分でシェルター。
- 端を石または枝で固定する。

### デブリ・ハット（道具なし、寒冷な天候）
- 骨組み：一本の長い梁を二又の枝に支える（恐竜の肋骨の形）。
- 側面の肋骨状の枝を30 cmごとに配置＋乾いた葉を60〜90 cm、上と中に詰める。
- 這って中に入り、入口をザックまたは葉でふさぐ：それが自然の寝袋である。

### 雪
- 絶対に雪の上で直接寝てはいけない：松の枝を厚く敷く。
- 枝の屋根をかけ、その上に雪をのせた溝は、風を遮って断熱する。

## 熱を保つ

- 衣服は常に乾いた状態に：濡れた衣服は命を奪う。寝る前に着替えるか、絞る。
- 火のそばで温めた石（絶対に赤熱させない）を布で包み、シェルター内に入れる。
- 寒さが厳しい場合は、断熱材の上で胎児姿勢で眠る。

## 実践例：自然の中のシェルター

**状況：** 山林で夜になり、寒く、村まで到達できない。

**行うこと：** 1。今すぐ行う：残りの明るい時間は2時間、それをシェルターに充てる。 2。低い乾いた斜面、上に枯れ枝がない場所。 3。葉と枝を集める：まず地面に30 cmの寝床を作る。 4。風に向けて小さなリーン・トゥを作り、30 cmの屋根を層状に重ねる。

**避けること：** 暗闇で歩き続けない、むき出しの地面で寝ない、涸れた水路や枯れ枝の下に作らない、大きなシェルターを作らない。

**エスカレーション：** 誰かに低体温症（制御できない震え、混乱）が見られる場合は、身体を寄せ合っての保温と火を優先する；メッシュのSOSを作動させ、移動は夜明けまで待つ。
