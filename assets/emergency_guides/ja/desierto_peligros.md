# 砂漠の危険

砂漠で命を奪うのは映画に出てくるものではありません。**鉄砲水、手を置く場所、そして寝床にした涸れ川**です。

## 重要ステップ

1. **涸れ川で絶対に野営しない。** 鉄砲水は砂漠の静かな殺し屋：見えもしない30km先の雨が、夜中に水の壁を送り込みます。どんなに平らで快適に見えても、必ず高い場所で眠る。
2. **川床が鳴り出したり濡れた土の匂いがしたら、高所へ走る。** 流れのある川床を渡らない：数分で水たまりが激流になります。
3. **触る前に見る。** ヘビとサソリはあなたが欲しい日陰で休んでいます：石の下、木の下、割れ目。石や木は自分の方へ転がして動かし（生き物は反対側へ逃げる）、見えない場所に手を入れない。
4. **毎朝ブーツと服を振る。** サソリは夜、あなたの体温を求めます。履く前にブーツを逆さに＋かかとを叩く：必須の儀式。
5. **杖を持ち、強く踏んで歩く。** 振動がヘビに警告します。咬傷の多くは踏んだり手を置いたりした時。見つけたら：静止し、ゆっくり後退——「死んでいて」も絶対に触らない（頭は反射で咬みます）。
6. **砂嵐：止まり、覆い、待つ。** 来る前に進行方向の印（石の矢印）を作り、布で鼻と口を覆い、目を守り、風に背を向けて遮蔽物に寄り、待つ：砂嵐の中を歩くことは遭難です。
7. **夜の寒さを敬う。** 40°Cの一日の後、夜明け前は0°C近くまで下がる：砂漠の低体温症は実在します（暑さとシェルターのガイド）。

## してはいけないこと

| ❌ 間違い | ✅ 正しい |
|-----------|-----------|
| 「平らで快適」な涸れ川で野営する | 必ず高所、川筋から離れる |
| 割れ目・穴・石の下に手足を入れる | まず見る。石は自分の方へ転がす |
| ブーツを振らずに履く | 毎回逆さにしてかかとを叩く |
| 「死んだ」ヘビを触る | 頭は数時間後も反射で咬む |
| 砂嵐の中を歩く | 止まり、方向を記し、覆って待つ |
| 咬まれた傷を切る／吸う | 固定し、時刻を記録し、咬傷ガイドへ |

## ヘビに咬まれたら

1. ヘビから離れ、座って落ち着く（速い鼓動は毒を回す）。
2. 指輪・時計・ブーツを今すぐ外す（腫れてくる）。
3. 咬まれた手足を心臓と同じ高さかそれ以下で固定。時刻を記録し、腫れの縁をペンで印す。
4. 止血帯・切開・吸引・氷は一切ダメ。
5. 歩くのは最小限。可能なら運んでもらう → 咬傷・刺傷ガイドへ。

## サソリに刺されたら

- 激しい局所痛：洗い、布越しに冷やし、キットの鎮痛薬。
- 4時間観察：よだれ、複視、けいれん、呼吸困難＝抗毒血清が至急必要、SOSを起動。
- 小さな子どもがサソリに刺されたら常に緊急事態。

## 例：砂漠の危険

**状況：** 乾燥地帯で日暮れ。平らで風のない唯一の場所は柔らかい砂の涸れ川。

**行動：** 1. そこは拒否：3〜5m上の最寄りの高台へ登る（快適でなくても）。2. 設営前に周囲の石を自分の方へ転がして割れ目を確認。3. ブーツは逆さにしてシェルター内へ。4. 朝に砂嵐が来た場合に備え、石の矢印で方向を記す。5. 防寒を準備：夜明け前は冷える。

**回避：** どんなに快適でも川床で寝ない。ブーツを外に置かない。暗闇で石の下に手を入れない。砂嵐が来たら歩かない。

**エスカレーション：** それでも鉄砲水に遭ったら：すべて捨てて最も高い場所へ登る（水を横切らない）。咬傷の腫れが急速に広がるか呼吸が苦しくなったら、メッシュのSOSを起動して咬傷ガイドへ——毒との競争です。
