# 緊急菜園

食料庫は数週間で尽きる；今日正しいものを播けば、**菜園は 20-30 日で見返りを生み始める**。これは園芸ではない：カロリーのロジスティクスである。

## 重要な手順

1. **速いものを今日播く：** ラディッシュ（20-30 日）、葉物野菜 — フダンソウ、ホウレンソウ、カラシナ、摘み取りレタス（30-45）、インゲン豆／サヤインゲン（50-60）、キュウリとズッキーニ（45-60）。食料庫で芽を出したジャガイモ = 種いも（「芽」のある切片、60-90 日）。
2. **袋入りでない種子：** 市場／食料庫のものが使える — 豆、レンズ豆、未加工のトウモロコシ、トマト（種を 2 日発酵させて乾かす）、唐辛子、パパイヤ、アヨテ。焙煎済み／精白済みのものは発芽しない。
3. **段階播き：** 2 週間ごとに同じ作物をもう一回播く — 一度に食べ過ぎてその後飢える代わりに、継続的に収穫する。
4. **日照 + 水が場所を決める：** 6+ 時間の日照、再利用水の近く（強い石けんを含まない生活排水のカスケード）、そしてどんな容器でもよい：タイヤ、袋、壊れたバケツ、薄板の水槽。
5. **素早く生きた土にする：** 土 + 堆肥／古い糞肥 + 腐った葉。キャンプの堆肥（皮、冷えた灰）が循環を養う — 有機物は何も捨てない。
6. **投資を守る：** 鶏や犬に対して簡単な囲い（枝、網、袋）を作り、夜明け／夕方に根元へ直接灌水する（正午は蒸発し、焼ける）。
7. **植物を殺さずに葉を収穫する：** フダンソウ／カラシナの外葉を切り、中心を残す — 同じ株が何か月も生産する。収穫物から最良の種を保存する：菜園 2 は無料で始まる。

## してはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| 「腹を満たすから」とトウモロコシだけを播く | 速いものを先に（ラディッシュ／葉物）；トウモロコシは 90-120 日かかる |
| すべてを一度に播く | 2 週間ごとに段階的に播く |
| 正午に勢いよく水をやる | 夜明け／夕方に根元へ |
| 石けん／塩素入りの生活排水を菜園へ使う | すすぎ水、または強い化学薬品なしの洗浄水だけ |
| 数枚の葉のために株全体を引き抜く | 外葉：株は生産を続ける |
| 皮や灰を捨てる | 堆肥：それは 2 か月目の肥料である |

## メートル当たりのカロリー（空間の優先順位）

1. ジャガイモ／サツマイモ：m² 当たりカロリーの王者。
2. インゲン豆／サヤインゲン：タンパク質 + 窒素固定（土を改善する）。
3. カボチャ／アヨテ：収量があり、何か月も保存できる。
4. 葉物野菜：病気を避けるための速いビタミン源。

## 実践例：緊急菜園

**状況：** 災害後 2 週目；寄付された食料は一か月分あり、キャンプの隣に日当たりのよい空き地がある。

**実行する：** 1。今日：5×5 m を片付け、ラディッシュ + カラシナ + 食料庫で芽を出すもの（ジャガイモ、豆）を播く。2。市場のトマト：種を発酵させ、缶の苗床へ。3。枝の囲いと、すすぎ水による灌水当番。4。2 週間後：第二弾と苗床からの移植。5。空き地の角に共同堆肥場。

**避ける：** 始めるために「良い種」を待たない、空き地全体にトウモロコシを播かない、石けん水で灌水しない、空き地を囲いなしにしない。

**規模拡大：** 収穫前に寄付が止まる場合：空いている各メートルでカロリー（ジャガイモ／豆／アヨテ）を優先し、川があれば漁／罠を起動し（ガイド）、メッシュを介して近隣と収穫物の交換を調整する — 菜園の多様性は全員の保険である。
