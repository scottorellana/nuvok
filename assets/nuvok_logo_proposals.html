Concepto 1 — Beacon N

La letra N formada por líneas que emiten señal. Las ondas superiores representan el beacon/SOS. Fondo degradado navy→teal oscuro.

Minimalista · Tech

Concepto 2 — Shield N

Una N protegida dentro de un escudo. Combinación directa de seguridad y tecnología. Más robusto, ideal para el dispositivo físico.

Protector · Sólido

Concepto 3 — Pulse N

La N dibujada como una línea de pulso/latido. Conecta con salud, SOS, señal de vida y monitoreo. Ideal para el aspecto médico/emergencia.

Vital · Dinámico
