# 安全渡河

河流杀死的徒步者比动物更多。**最勇敢的决定几乎总是不要渡河。**

## 决定前：评估

- **深度：** 有水流且超过膝盖 = 真实危险。超过大腿 = 不要渡河。
- **速度：** 往水里丢一根树枝；如果它移动得比你走路还快，水流会把你冲倒。
- **河底：** 圆石和苔藓 = 滑道。沙/砾石 = 更好。
- **上游：** 山里在下雨吗？洪水会在几分钟内到达，毫无预警。
- **出口：** 看对岸：必须有容易上岸的出口，不要是陡崖或灌木丛。

## 关键步骤

1. **找最佳点，而不是最近点。** 沿岸走：河流最宽的部分通常最浅、最慢。弯道外侧水深。
2. **松开背包的腰带。** 胸扣和腰带都解开：如果你跌倒，背包必须能自行脱离（装满水会把你拖沉）。
3. **找一根结实的手杖**（到你胸口高度）。它将是你的“第三条腿”。
4. **正面对着水流进入，前进时侧身。** 水流应冲击你上游侧的腿；侧身、沿下游方向斜向前进。
5. **始终有两个支点着地。** 一次只移动一个支点：脚-脚-杖。拖着脚走，不要抬脚。
6. **团队：抓住肩膀成链，** 最强的人在上游破开水流，最弱的人在中间。
7. **到对岸后：擦干并保暖。** 渡河后的寒冷会导致低体温；换衣并活动。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 水过大腿还渡河 | 找其他点或等水位下降 |
| “为了不弄湿靴子”而赤脚渡河 | 穿着靴子：河底会割伤并造成脱位 |
| 渡河时把自己系在固定绳上 | 水流会把你压到绳上并拖沉；只能使用带辅助释放的绳索 |
| 在看起来狭窄的地方渡河 | 狭窄 = 深且快；宽 = 浅 |
| 在湿石头之间跳跃 | 用技巧涉水；湿石头是脚踝陷阱 |
| 在洪涨或突然浑浊的水中渡河 | 等待：洪水会在数小时内退去 |

## 如果你被水流冲走

1. **立即丢开背包**。
2. **仰面，双脚朝下游，** 张开双臂：让脚撞开岩石，而不是你的头。
3. **不要试图在深水急流中站起来**：脚会卡在岩石间，水流会把你折倒（脚部卡困导致溺水——经典致命错误）。
4. 当你感觉水流变弱时，**斜向游**向岸边。
5. 到岸后：**处理低体温**——干衣、保暖、糖分。

## 儿童

- 每名儿童配一名成人，儿童在成人下游侧，抓住成人腰带。
- 如果水超过儿童膝盖：不要渡河——抱过去，或不渡河。

## 实用示例：安全渡河

**情况：** 小径在一条山河前中断，水到你的膝盖并且流得很快。

**做：** 1. 沿岸走到最宽的河段。 2. 松开背包扣带，并找一根到胸口的手杖。 3. 正面对着水流，侧身沿下游斜向前进，一次移动一个支点。 4. 上岸后：换干衣并活动。

**避免：** 如果水超过大腿或水突然变浑，不要渡河；不要跳湿石头；不要把自己系在固定绳上；不要赤脚渡河。

**升级处理：** 如果有人落水或水位突然上涨，其他人都不要再下水：从岸边伸出手臂和杆子，绝不要在水流中组成救援人链；启动 mesh 的 SOS。
