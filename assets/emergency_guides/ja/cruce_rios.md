# 川を安全に渡る

川は動物よりも多くのハイカーを死なせます。**ほとんどの場合、最も勇敢な判断は渡らないことです。**

## 判断する前に：評価する

- **深さ：** 流れがある状態で膝より上 = 実際の危険。太ももより上 = 渡らない。
- **速さ：** 枝を水に投げる；あなたより速く進むなら、流れに倒されます。
- **川底：** 丸い石と苔 = 滑り場。砂／砂利 = より良い。
- **上流：** 山で雨が降っているか？ 増水は予告なく数分で来ます。
- **出口：** 対岸を見る：簡単に上がれる場所でなければならず、崖や藪であってはなりません。

## 重要手順

1. **最も近い場所ではなく、最良の場所を探す。** 岸を歩く：川の最も広い部分は、たいてい最も浅く遅い。カーブの外側は深い。
2. **バックパックの腰ベルトを外す。** 胸と腰を外しておく：転倒したら、バックパックは自然に外れなければならない（水で満たされると沈められます）。
3. **丈夫な杖を手に入れる**（胸の高さ）。あなたの「三本目の脚」になります。
4. **流れに正面を向けて入り、進むときは横向きに。** 水は上流側の脚に当たるようにする；横歩きで、下流へ斜めに進む。
5. **常に二点を接地。** 支点は一つずつ動かす：足・足・杖。足は引きずり、持ち上げない。
6. **グループでは：肩をつかんで鎖状に、** 最も強い人が上流側で流れを割り、最も弱い人を中央に置く。
7. **反対側に着いたら：乾かし、保温する。** 渡渉後の寒さは低体温症を起こす；衣服を替え、動く。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 水が太ももより上で渡る | 別の場所を探す、または水位が下がるのを待つ |
| 「靴を濡らさないため」に裸足で渡る | 靴を履いたまま：川底は切り、脱臼させる |
| 固定ロープに自分を結びつけて渡る | 流れがロープに押しつけて沈める；補助解除できるロープのみ |
| 川が狭く見える場所で渡る | 狭い = 深く速い；広い = 浅い |
| 濡れた石から石へ跳ぶ | 技術を使って徒渉する；濡れた石は足首の罠 |
| 増水中または突然濁った水を渡る | 待つ：増水は数時間で下がる |

## 流れにさらわれた場合

1. **バックパックをすぐに手放す。**
2. **仰向けで、足を下流へ、** 腕を広げる：岩に当たるのは頭ではなく足です。
3. **深い流れで立とうとしない：** 足が岩の間に挟まり、流れで身体が折り曲げられる（足の閉じ込めによる溺水 — 古典的な致命的ミス）。
4. **流れが弱まったと感じたら、岸へ斜めに泳ぐ。**
5. 岸に上がったら：**低体温症を処置する** — 乾いた衣服、保温、糖分。

## 子ども

- 子ども一人につき大人一人。子どもは大人の下流側で、ベルトをつかむ。
- 水が子どもの膝を越える場合：渡らない — 抱えて渡るか、渡らない。

## 実践例：川を安全に渡る

**状況：** 登山道が山の川で途切れており、水は膝まで来ていて速く流れている。

**行う：** 1. 岸を歩き、最も広い区間まで行く。 2. バックパックのバックルを外し、胸の高さの杖を手に入れる。 3. 流れに正面を向け、下流へ斜めに横向きで、一つの支点ずつ進む。 4. 出たら：乾いた衣服と運動。

**避ける：** 太ももを越える場合や水が突然濁った場合は渡らない。濡れた石を跳ばない。固定ロープに自分を結びつけない。裸足で渡らない。

**エスカレーション：** 誰かが水に落ちた、または水位が急に上がった場合、他の誰も入らない：岸から腕や棒を使い、流れの中で人間の鎖は決して作らない；mesh の SOS を起動する。
