# 基础太阳能

没有电网时，**一块太阳能板 + 一块汽车电池就是社区电站**：手机（mesh 靠它们生存）、夜间照明和收音机——前提是连接得当。

## 关键步骤

1. **收集街区里的部件：** 热水器/花园灯/房屋上的太阳能板，汽车电池（即使不能启动发动机，也能给手机充电数周）、车载逆变器（12V→USB/110V）、铜线。
2. **最低可行系统：** 太阳能板 →（若有则接控制器）→ 12V 电池 → 车载 USB / 小型逆变器。没有控制器：只在有太阳的几小时连接太阳能板，并在有万用表时测量电池不要超过约 ~14V；宁可少充几小时，也不要把电池煮沸。
3. **始终遵守极性：** 红/+ 接 +，黑/– 接 –。接反会烧毁逆变器，并可能使电池爆裂。从第 1 天起用胶带标记电线。
4. **朝向与清洁：** 太阳能板对准直射阳光（若在北半球则朝南），倾角 ≈ 你的纬度，无阴影，连一根电线的影子也不行（一个小阴影会拖垮整块板），每天早晨清除灰尘。
5. **优先分配瓦数：** 第 1 位是 mesh 手机和手电筒（通信与安全），第 2 位是收音机，第 3 位是一盏夜间公用 LED 灯。小系统绝不要接冰箱/电熨斗：一小时内就会耗死电池。
6. **照顾铅酸电池：** 不要深度放电（如果 LED 灯亮度明显下降，就切断），每天充电，放在阴凉通风处，绝不要放在有人睡觉的封闭房间内（充电时会产生氢气）。
7. **有规则的社区充电站：** 时间表、每班一名负责人、贴好标签的手机排队——20 部手机有序充好电，比 3 户人家抢一个插头更有价值。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 把太阳能板直接接到手机 | 始终通过电池/控制器或车载 USB |
| 接反极性“看看能不能用” | 标记电线并核对两次 |
| 电池在床边充电 | 阴凉通风，远离火花和卧室 |
| 把电池放到灯都熄灭 | 早点切断：深度放电会毁掉它 |
| 把冰箱接到小系统 | 只接手机/LED/收音机；瓦数不够 |
| 太阳能板有“小阴影但仍会充电” | 局部阴影 = 面板几乎报废：重新摆放 |

## 能产出多少（诚实数字）

- 50 W 太阳能板在良好日照下 ≈ 每天 15-20 次手机充电。
- 使用过的汽车电池 ≈ 无太阳时可支撑 2-4 天的手机+LED。
- 太阳能花园灯 = 给 1 部手机应急夜间充电器（如果你懂得拆用它的 USB）。

## 实用示例：太阳能

**情况：** 无电网第 2 周；街区凑到 2 块 50 W 太阳能板、一块皮卡电池和一个车载逆变器。

**做法：** 1. 在中央院子设站：太阳能板放在无阴影阳光下，倾斜放置，电池置于阴凉通风处。 2. 电线标记好，太阳能板→电池→逆变器/USB。 3. 在白板上写规则：充电时间、每班负责人、mesh 优先。 4. 每天下午早些切断，保护电池。 5. 黎明用干布清洁太阳能板。

**避免：** 不要“接一会儿”冰箱，不要把电池放在太阳下或封闭房间里，不要允许非规定时间私接，不要用湿手触摸接线柱。

**升级处理：** 如果电池膨胀、有臭鸡蛋味或沸腾：断开所有设备，通风并移走它——这是爆炸风险；没有电池时，太阳能板只能在白天直接接车载 USB，mesh 按时段配给通信。
