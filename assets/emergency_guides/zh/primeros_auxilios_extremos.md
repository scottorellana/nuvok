# 关键急救：MARCH/XABCDE 算法

> ⚠️ 本指南不能替代专业医疗救治或现场培训。它用于在最初几分钟、资源有限的情况下，在你启动求助或转运的同时采取行动。

## 绝对优先级

在真实紧急情况下，不要试图“什么都做”。按以下顺序做：

```text
0. 现场安全：不要让自己成为另一名伤者。
1. 大出血：血液喷射而出或浸透衣物。
2. 气道：能呼吸吗？有阻塞吗？
3. 呼吸：呼吸正常吗？胸部有开放性伤口吗？
4. 循环 / 休克：皮肤冰冷、脉搏微弱、意识混乱。
5. 神经系统：无反应、抽搐、头部受撞击。
6. 暴露 + 体温：寻找隐藏伤情并避免寒冷/高温。
```

这结合了院前创伤中使用的 MARCH/XABCDE 的非专业人员版本，以及面向非专业人员的急救原则。

## 不该做什么

| ❌ 错误 | ✅ 正确 |
|---|---|
| 因为小伤口“看起来很糟”就先处理它们 | 先处理会在几分钟内致命的问题：出血、气道、呼吸 |
| 无必要地移动颈部/背部受伤者 | 只有在有火灾、坍塌、交通危险或呼吸停止时才移动 |
| 给重伤者喝水、饮酒或吃药 | 如果意识混乱、呕吐、有创伤或可能需要手术，则不要经口给予任何东西 |
| 用铁丝/细绳当止血带 | 使用宽布 4-5 cm 或商用止血带 |
| 拔出刺入体内的物体 | 在其周围固定；它们可能正在堵住出血点 |

## 步骤 0 — 安全与指挥

1. 观察 3 秒：交通、电线、燃气、火、武器、坍塌、水、烟。
2. 有手套就戴；没有的话，把塑料袋套在手上。如果什么都没有，也要行动：生命优先。
3. 指向一个人：“你，打急救电话”。指向另一个人：“你，拿急救包/AED/布/手电筒”。
4. 如果你独自一人，打开免提，一边通话一边处理。

## 步骤 1 — 大出血

如果血液喷射、搏动性流出、浸透衣物或形成血泊，就采取行动。

1. 用纱布、干净 T 恤或你的手直接用力按压出血点。
2. 如果是腹股沟/腋窝/颈部的深伤口：把布/纱布塞入腔隙直到填满，并在上方按压。
3. 如果是手臂或腿，且无法快速控制、无法持续按压，或有截肢：在伤口上方 5-8 cm 处使用止血带，不要放在关节上。收紧直到出血完全停止，并记录时间。
4. 在医院外不要松开止血带。

## 步骤 2 — 气道

1. 如果能说话或哭泣，说明气道开放。
2. 如果无反应：查看口腔。只取出可见物体；不要盲目清扫。
3. 无脊柱损伤怀疑：轻柔仰头抬颏。
4. 可能有颈部/背部损伤：如果你会，做托下颌；如果不呼吸，开放气道和心肺复苏优先于脊柱保护。

## 步骤 3 — 呼吸

1. 如果不正常呼吸或只是喘息：做心肺复苏。
2. 胸部有“吸气”样开放性伤口：用塑料/袋子/保鲜膜覆盖，并在 3 边粘住，使空气能排出但不能进入。如果呼吸困难加重，抬起一边几秒钟。
3. 松开紧身衣物；如果清醒且无脊柱创伤，采取舒适体位。

## 步骤 4 — 休克

征象：皮肤冰冷、苍白、出汗；脉搏快；口渴；意识混乱；虚弱。

1. 让患者躺下。
2. 上下都保暖：地面会带走热量。
3. 只有在没有疼痛、骨折、骨盆/脊柱/头部创伤，也没有呼吸困难时，才抬高双腿。
4. 不要经口给予任何东西。
5. 紧急转运。

## 步骤 5 — 头部、脊柱、抽搐

- 强烈撞击、跌落、事故、颈部/背部疼痛、无力/麻刺感：在发现时的姿势稳定头部，只有在绝对必要时才整体移动。
- 抽搐：防止撞伤，计时，不要往口中放任何东西。结束后若能呼吸，转为侧卧。
- 无意识但有呼吸且无脊柱损伤怀疑：安全侧卧位。

## 步骤 6 — 暴露与低体温

1. 寻找隐藏伤情，但不要不必要地脱光衣物。
2. 迅速重新覆盖。创伤 + 寒冷会加重出血和休克。
3. 在患者身下使用毯子、夹克、纸板、背包或隔热垫。

## 安全的临时替代

| 需求 | 可临时使用 | 避免 |
|---|---|---|
| 加压 | T 恤、毛巾、干净尿布、直接用手 | 移除浸透的层 |
| 止血带 | 宽布 + 坚硬木棍 | 电线、细绳、铁丝、细绳索 |
| 夹板 | 纸板、木板、直树枝、卷起的杂志 | 把骨头掰直 |
| 颈托/脊柱 | 头部两侧放毛巾/衣物 | 拉扯颈部或让患者坐起 |
| 胸部封闭贴 | 塑料袋、包装材料、胶带 | 若恶化则避免把 4 边完全密封 |
| 保暖 | 毯子、夹克、塑料、身体下方垫纸板 | 留在冰冷地面上 |

## 科学依据

基于 AHA 2025 关于 CPR/AED 的公开原则、STOP THE BLEED/ACS 关于出血处理的原则、ATLS 2025 创伤框架，以及 PHTLS/NAEMT 关于初始评估和早期转运、IFRC/Red Cross 急救原则。未复制专有课程；而是把优先事项转化为面向非专业人员的安全步骤。

## 实用示例：关键急救：MARCH/XABCDE 算法

**情境：** 在偏远地区，一人严重受伤，转运将超过 30 分钟。

**做法：** 1. 确保现场安全，并指定一名具体人员拨打急救电话。 2. 按指南的大步骤顺序执行，不要跳到看起来最戏剧性的步骤。 3. 如有手套、屏障物或干净布料可用，就使用。 4. 每分钟重新评估：呼吸、意识、出血、体温或是否恶化。

**避免：** 不要临时尝试高级操作；如怀疑损伤，不要移动颈部/脊柱；不要给意识混乱者食物/饮料；不要因寻找完美装备而延误呼救。

**升级处理：** 如果不正常呼吸、有胸痛、出血不止、意识混乱、大面积烧伤、可能中毒、妊娠晚期或有多名伤者，立即呼救或转运。

**快速检查：** 结束本指南前，大声说出发生了什么、你做了什么、还缺什么以及谁继续负责。本示例是引导性练习；请根据你的环境调整步骤，并在有专业帮助时优先获取。
