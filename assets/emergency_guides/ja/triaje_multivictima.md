# トリアージ — 誰を最初に対応するか？

> 多数の負傷者と少数の救助者がいる緊急事態のための簡略化 START 法。

## 意思決定ツリー

```
                        歩いて話せるか？
                       /                \
                     はい               いいえ
                     │                  │
                  🟢 緑              呼吸しているか？
                  (待機可能)        /        \
                                   はい       いいえ
                                   │          │
                              大量出血か？    気道を開く
                              /         \       頭を傾けて
                            はい        いいえ  今、呼吸しているか？
                            │           │      /          \
                        🟠 オレンジ  🟡 黄色   はい        いいえ
                        (出血)       (安定)     │            │
                                              脈はあるか？   │
                                              /          \    いいえ
                                            はい         いいえ │
                                         🟠 オレンジ   ⚫ 黒   │
                                                                      │
                                                    🔴 赤
                                                  (今すぐCPR)
```

## トリアージ分類

| 色 | 状態 | 行動 | 例 |
|-------|--------|--------|----------|
| 🔴 **赤** | 重篤、即時の援助で生存可能 | 最初に対応 | 呼吸していない（気道開放下）、重度ショック |
| 🟠 **オレンジ** | 重症、援助が必要だが 1h 待てる | 出血を止める | 重度出血、開放骨折 |
| 🟡 **黄色** | 安定、数時間待てる | 固定、観察 | 閉鎖骨折、軽い創傷 |
| 🟢 **緑** | 軽症、歩ける | 自己対応 | 小さな切り傷、打撲 |
| ⚫ **黒** | 気道を開いた後も反応しない | 生存者を優先 | 回復しない心停止 |

## 黄金律

1. **多くの傷病者がいるとき、一人の患者に時間を失わない**
2. **15 分ごとに再評価する** — 緑が赤に変わることがある
3. **各被害者に印を付ける** 色で（テープ、マーカー、衣服）
4. **生存者全員の対応が終わるまで、黒を動かさない**

## 60 秒プロトコル

| 手順 | 時間 | 行動 |
|------|--------|--------|
| 1 | 0-10s | 叫ぶ：**「歩ける人は誰ですか？」** → その人たちは緑 |
| 2 | 10-30s | 残った人たち：呼吸しているか？ していない人 → 気道を開く |
| 3 | 30-50s | 呼吸している人たち：大量出血しているか？ → オレンジ |
| 4 | 50-60s | その他 → 黄色。気道確保後も呼吸しない人 → 黒 |

> 💡 目的は全員を救うことではない。できるだけ多くを救うことである。

## 実践例：多数傷病者トリアージ（誰を最初に対応するか？）

**状況：** 地震の後、複数の人が助けを求めており、あなたには小さな救急箱しかない。

**行うこと：** 1. 現場の安全を確保し、特定の人に緊急通報を依頼する。 2. ガイドの大きな手順を順番に従い、より劇的に見える手順へ飛ばさない。 3. 利用可能なら手袋、バリア、または清潔な布を使う。 4. 毎分再評価する：呼吸、意識、出血、体温、または悪化。

**避けること：** 高度な手技を即席で行わない、損傷が疑われる場合は首／脊椎を動かさない、混乱している人に食べ物／飲み物を与えない、完璧な装備を探すために通報を遅らせない。

**エスカレート：** 正常に呼吸していない、胸痛がある、出血が止まらない、混乱、広範囲の熱傷、毒物の可能性、妊娠後期、または複数の被害者がいる場合は、すぐに通報するか搬送する。

**クイックチェック：** ガイドを終える前に、何が起きたか、何をしたか、何が残っているか、誰が責任者として残るかを声に出して言う。この例はガイド付き練習である；手順をあなたの環境に適応させ、専門的な援助が存在する場合はそれを優先する。
