# 安全な川の水

川は無限の水を与える――**そして病気になる無限の方法も与える**。濁り、寄生虫、そして上流に何があるかが、それがあなたを救うか倒すかを決める。

## 重要な手順

1. **川の上流を考える。** 町、家畜、農地、死んだ動物はあるか。水は上流の物語を語る。速く流れる石の多い区間から採水し、腐ったよどみからは決して採らない。
2. **清潔な側から採る。** 石の上を流れる動いている水 ＞ 静かな岸辺。容器を中間の深さまで沈める：表面は浮遊物を運び、底は沈殿物を運ぶ。
3. **濁りを最初に沈ませる。** 泥水：1-2 時間（または一晩）静置し、上の ⅔ だけを使う。塩素と煮沸は泥があるとうまく働かない。
4. **層でろ過する。** 切ったボトルを逆さにする：布、火から得た砕いた炭、細かい砂、砂利。ろ過は見えるものを取り除く――消毒はしない。
5. **ろ過後は必ず消毒する。** 1 分煮沸（高地では 3 min）または 2 滴の 5% 塩素を一リットルあたり + 30 min（沈殿させた濁水：倍量、計算機を参照）。
6. **計画 C として太陽（SODIS）。** 透明な PET ボトルを満たし、反射する表面の上で直射日光に 6 時間置く：紫外線が消毒する。澄んだ水のみ。
7. **清潔な容器を守る。** 浄化してから同じ汚れたカップで補充すると、すべてが台無しになる：「未処理」と「飲用」を分け、処理済みの水でねじ口をすすぐ。

## してはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| 「流れていてきれいに見えるから」と直接飲む | 流れていることはジアルジアもコレラも殺さない：必ず消毒する |
| 泥水に直接塩素を入れる | 先に沈殿／ろ過する；泥が微生物を守る |
| 岸のそばの静かなよどみから採る | 速く流れる石の多い区間で、中間の深さから |
| ろ過して安全だとみなす | 自作フィルターは消毒しない：その後に煮沸または塩素処理する |
| 飲用容器を未処理のカップで補充する | 未処理／飲用を厳格に分ける |
| 「急いでいるから」とグループの下痢を無視する | 経口補水液を今すぐ（計算機）――喉の渇きよりも脱水を進める |

## 川の水の段階

1. **最良：** 川へきれいに下る、小さく速い支流。
2. **良好：** 速い区間の川の水を、沈殿 + 煮沸したもの。
3. **普通：** 沈殿させた濁水 + ろ過 + 倍量の塩素。
4. **最後の手段：** 岸辺の井戸――川から 2-5 m の所を掘る：砂が前ろ過する（それでも消毒する）。

## 実践例：川の水

**状況：** チョコレート色に増水した川のそばのキャンプ；ボトルの水は尽き、グループには子どもがいる。

**行う：** 1. 水際から 3 m の場所に岸辺の井戸を掘り、砂でろ過されて満たされるのを待つ。 2. その間に：速い区間の水を 2 鍋分、沈殿させる。 3. 火から得た炭でボトルフィルターを組み立てる。 4. すべてを 1 分煮沸する、または火がなければ倍量の塩素を使う。 5. 容器に印を付ける：未処理 vs 飲用。

**避ける：** 子どもに未処理のまま「ほんの一口」でも飲ませない、泥に直接塩素を入れない、飲用水を未処理のカップで再汚染しない、よどみから採らない。

**エスカレーション：** グループ内に下痢または嘔吐がある：計算機の比率で経口補水液を今すぐ作り、中毒のガイドへ進む；下痢に血が混じる、または高熱がある場合は、避難の優先事項――メッシュを起動する。
