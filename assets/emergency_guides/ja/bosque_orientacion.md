# 森で迷わないために

迷ったと感じた瞬間の黄金律：**止まる** — 止まり、考え、資源を確認し、計画する。パニックで歩く遭難者は救助から遠ざかり、止まった者が生き残ります。

## 重要ステップ

1. **疑った瞬間に止まる。** 座って水を飲み、10回深呼吸。パニックの最初の1時間が、命取りの10kmを生みます。
2. **考える：最後に確信できた場所はどこか？** 分岐、川、大きな岩。何分前か？それが道までの最大距離です。
3. **資源を確認。** 電池、水、防寒、残り日照。日照3時間未満なら：今すぐシェルター、ナビは明日。
4. **計画：とどまるが原則。** 誰かがルートを知っている、またはメッシュSOSを出したなら、その場に：固定目標は移動目標より10倍早く見つかります。
5. **動くなら直線で。** 目印なしの森では人は円を描きます：常に前方の木を2本合わせ、1本目に着いたら3本目を合わせる。下りの流水はたいてい人里へ通じます。
6. **足跡を残す。** 20〜30mごとに：進行方向を指す折り枝、石の矢印、布切れ。救助の助けになり、引き返す道にもなります。
7. **見え、聞こえる存在に。** 何でも3回=国際救難信号：笛3回（笛はツールに）、火3つ、閃光3回。数分おきに繰り返す。

## してはいけないこと

| ❌ 間違い | ✅ 正しい |
|----------|----------|
| 疑いながら「もう少しだけ」歩く | 即停止：疑いの一歩ごとに救助から遠ざかる |
| 夜間に歩く | 夕暮れにはシェルター；夜は捻挫の製造機 |
| 「時間を取り戻す」ため道を外れて近道 | 自分の目印をたどって引き返す |
| 電波探しで電池を使い切る | 時間を区切って電源オン：高所で1時間に1回 |
| 峡谷で盲目的に川をたどる | 水は道標。ただし滝と峡谷は迂回 |
| 「道を探すため」に隊を分ける | 隊は絶対に分かれない |

## コンパスなしの方位（ナビゲーションガイド参照）

- **太陽：** 東から昇り西へ沈む；正午は南を指す（北半球）。
- **影の棒：** 棒を立て影の先端に印、15分後にまた印：2点を結ぶ線が西→東。
- **アプリのコンパス**（ツール）は電波なしで動作。
- 方位を決めたら信じ抜く：「あっちの気がする」が最大の敵。

## 例：森で迷わないために

**状況：** 果実を採りに道を外れ、振り返るとすべてが見知らぬ景色。日照は残り4時間。

**行動：** 1. 座って10回深呼吸。2. 再構築：道は上り方向、約15分前。3. 現在地に枝で大きなXを作る。4. 木を直線に合わせて上りへ歩き、20mごとに印。5. 30分で道が現れなければ印をたどってXへ戻り、シェルターと信号の準備。

**回避：** 「探索」で回り歩かない、楽だからと沢へ下りない、電池を使い切らない、夕暮れ後に歩き続けない。

**エスカレーション：** 負傷・日没・悪天なら探索中止 — シェルター+3信号+メッシュSOS；一瞬でも電波が入れば緊急番号へ発信（発信ボタン）。
