# 砂漠の暑さとシェルター

砂漠は二度殺す：**真昼の暑さと夜明け前の寒さ**。シェルターと時間割があなたの生存です。

## 重要ステップ

1. **一日を逆転させる。** 移動は夜明け・夕暮れ・（月があれば）夜だけ。10時〜16時は完全な日陰で静止。最も命を救うルールです。
2. **服は着たまま。** ゆったりした明るい色の長袖＋頭と首を覆う：布が日差しを遮り、汗を留めて体を冷やします。シャツを脱ぐと脱水が早まり、皮膚が焼けます。
3. **地面から離れる。** 真昼の地面は30cm上の空気より15〜20°C熱い。ザック、枝、積んだ石の上に横になり、砂に直接寝ない。
4. **空気層のある二重屋根。** 布やタープを20〜30cm離して二枚張ると直射日光より最大15°C下がる。一枚では生ぬるい日陰にしかならない。
5. **あるものを使う。** 大岩の北側の陰、岩の張り出し、車（下はダメ：金属が熱を放射する。横の日陰側で）は、作るものより優れています。
6. **日没前に夜の準備。** 砂漠は35°Cから5°C以下まで下がる：日中に薪を集め、風上側を閉じ、寝るための乾いた一枚を残しておく。
7. **仲間の熱中症を見張る。** 汗のない熱く乾いた肌、混乱、ふらつく足取り：即日陰へ、服を濡らし、あおぐ——熱中症ガイドへ。

## してはいけないこと

| ❌ 間違い | ✅ 正しい |
|-----------|-----------|
| 「進むため」に真昼に歩く | 夜明け・夕暮れ・夜に移動する |
| 暑いから服を脱ぐ | ゆったりした明るい服を着たまま、頭を覆う |
| 熱い砂に直接寝る | 地面から30cm離す |
| 日なたの車内に避難する | 車の横の日陰、風通しよく |
| 夜を無視する（「砂漠は暑い」） | 日没前に防寒と火を準備する |
| 行動中に渇くまで待つ | 動きながら少量ずつ規則的に飲む |

## 20分の緊急シェルター

1. 自然のくぼ地か大岩の日陰側を探す。
2. タープや毛布を高い岩から低い杭2本へ張る（午後の日差しに対する片流れ）。
3. 二枚目（予備のシャツ、別の布）を一枚目の20〜30cm上に。
4. 床：ザック、枝、平らな石——素の砂は絶対にダメ。
5. 開口部はそよ風の方向へ。オーブンのように密閉しない。

## 砂漠の夜

- 本物の寒さ：40°Cの一日の後でも低体温症は起こる。
- 小さな安定した火 > 大きな焚き火。薪は貴重。
- 火のそばで温めた石を布で包み、シェルターの中へ。
- 夜明けにブーツと服を確認：サソリはあなたの体温を求めてくる（危険ガイド）。

## 例：暑さとシェルター

**状況：** 乾燥地帯のハイキングで道に迷った。午前11時、太陽は真上、町は見えない。

**行動：** 1. 今すぐ止まる：大岩の陰を探す。2. タープと予備シャツで二重屋根を張り、体を地面から離す。3. 少量ずつ飲み、16〜17時まで動かない。4. 夕暮れに薪を集めて夜を準備し、使える光のあるうちだけ進む。5. 日陰からメッシュのSOSを起動。

**回避：** 真昼に歩き続けない。シャツを脱がない。換気のない車や洞窟に入らない。夜の準備を後回しにしない。

**エスカレーション：** 汗のない熱く乾いた肌で混乱し始めたら熱中症——今すぐ強力な冷却（服に水＋あおぐ）をして熱中症ガイドへ。けいれんが始まったら、けいれんガイドへ。
