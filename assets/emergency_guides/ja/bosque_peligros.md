# 森の危険

森では、あなたを狩るものはほとんどありません。**事故の大半は自分自身が引き起こします** — どこを踏むか、どこに手を入れるか、どこで眠るかです。

## 重要な手順

1. **どこを踏むか、どこをつかむかを見なさい。** ヘビ咬傷の 90% は足と手に起きます。倒木は（見えない反対側へ踏み越えるのではなく）その上を踏み、穴の中、石の下、落ち葉の間には絶対に手を入れない。
2. **音 = あなたの盾。** 自然な音を立てて歩きなさい。ほとんどすべての動物は、あなたが来るのを聞けば避けます。危険なのは不意をつくことです。
3. **使う前にすべて振り払う。** 朝、ブーツ、衣服、バックパックを振り払うこと。サソリやクモは夜に暖かさを求めます。
4. **避難する前に頭上を確認する。** 垂れ下がった枯れ枝（「未亡人メーカー」）、蜂の巣、木の上のアリの巣 — ピューマより枝のほうが多く人を殺します。
5. **ヘビに遭遇したら、動かず後退する。** ゆっくり後ろへ二歩。ヘビは食べられないものに毒を使いたくありません。「どかすために」絶対に触らない。死んでいても触らない（咬みつき反射）。
6. **スズメバチ／ミツバチの群れ：まっすぐ遠くへ走る。** 最低 200-300 m、可能なら茂みを抜ける。水には飛び込まない（出てくるのを待つ）。顔と首を覆う。
7. **咬傷または重い刺傷がある場合**、咬傷・刺傷のガイドへ移る：固定し、時刻を記録し、止血帯も吸引も一切しない。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 見えない場所に手や足を入れる | まず確認し、物を動かすには棒を使う |
| 落ち葉の中の地面に直接寝る | 枝で高床の寝床を作り、周囲を確認する |
| 「置き去りにされた」子どもの動物に近づく | 母親が近くにいる：今すぐ離れなさい |
| 毛のある毛虫、色の鮮やかなカエル、乳液の出る植物に触る | 明るい色 = 化学的警告 |
| 藪の中をパニックで走る | しっかり歩く：転倒が事故 #1 |
| 眠る場所のそばに食べ物を吊るす | 食べ物は 50+ m 離し、高くする：動物を自分の寝床に招かない |

## 実際の危険、順番

1. **転倒と捻挫** — 山野で実際に起きる事故 #1。
2. **落下する枯れ枝** — 上を常に確認する。
3. **昆虫**（スズメバチ、アリ、マダニ、蚊）— すべての哺乳類を合わせたより入院が多い。
4. **ヘビ** — 足元を見ていれば避けられる。
5. **かぶれる植物ととげ** — 清潔にしなければ感染する。
6. **大型哺乳類** — リストの最後：向こうがあなたを避けます。

## マダニとヒル

- マダニ：頭部からピンセットでつかみ、ゆっくりまっすぐ引いて取る。焼いたり、アルコールで窒息させたりしない（逆流する）。
- ヒル：口の部分に爪を滑り込ませてはがす。引きちぎらない。
- 刺された日付を記録する：その後数日以内の発熱 = 医療機関を受診。

## 実践例：森の危険

**状況：** 夕方になり、薪を探している。倒木の間に深い落ち葉がある。

**行うこと：** 1. 手を入れる前に、長い棒で落ち葉を動かす。 2. 各倒木の上を踏み、下りる前に反対側を見る。 3. 普通の音を立てながら薪を集める。 4. 眠る前に、ブーツを振り払い、避難場所の頭上を確認する。

**避けること：** 夜に薪を集めない、穴に手を入れない、巣や蜂の巣に触らない、避難場所に食べ物を置かない。

**エスカレーション：** ヘビが咬んだ場合、または群れが多数の刺傷で攻撃した場合（またはアレルギーがある：顔の腫れ、呼吸時のヒューヒュー音）、ただちに咬傷／刺傷のガイドへ移り、mesh の SOS を起動する。
