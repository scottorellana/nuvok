# 拯救生命的绳结

五种绳结覆盖生存中 95% 的需求：救援、捆扎、拉紧、连接和固定。**今天就用一根细绳练习它们**——紧急情况下双手会发抖，没有时间学习。

## 关键步骤

1. **单套结（bowline）——救援绳结。** 固定绳圈，不会在所环抱的物体上收紧：用于提升人员或将其固定。“蛇从井里出来，绕过树，又回到井里”。即使承重后也容易解开。
2. **卷结（clove hitch）——快速固定到柱子。** 在树干/柱子上做两圈交叉缠绕。用于开始和结束搭建结构（庇护所、木筏）。注意：间歇性拉扯会使其松动——用一个半结收尾。
3. **拉紧结（taut-line hitch）——可调节的绳索。** 一种滑动结，在受力时会咬住：用于拉紧篷布、庇护所风绳、晾衣绳。可用手滑动调节，受载后会自行锁住。
4. **双渔人结——连接两根绳。** 延长绳索的安全方式，即使绳径不同、绳子潮湿也可用。两个绳结彼此抱紧；结形紧凑且不会滑脱。
5. **方形绑扎（square lashing）——把木棍十字连接。** 用于结构搭建：庇护所、木筏、担架、三脚架。起始卷结 + 每个轴向 3 圈缠绕 + 2 圈勒紧缠绕 + 末端卷结。

## 何时用哪一种

| 我需要…… | 绳结 |
|-----------|------|
| 提升/下降/固定一个人 | 单套结 |
| 开始或结束固定到柱子的捆扎 | 卷结 + 半结 |
| 拉紧篷布或庇护所风绳 | 拉紧结 |
| 用另一根绳延长绳索 | 双渔人结 |
| 牢固连接两根木棍（担架、木筏、庇护所） | 方形绑扎 |

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 用活结提升人员 | 单套结：绳圈不会在胸部收紧 |
| 相信一个你不能闭着眼睛重新打好的绳结 | 在需要它之前练习 20 次 |
| 用单结（“鞋带结”）连接绳索 | 双渔人结；单结受载会滑脱 |
| 绳结后留下少于 10 cm 的绳尾 | 留出充足绳尾：绳结受载时会“吃”绳 |
| 用受损绳索承载人员 | 检查整根绳；一股断裂 = 不可用于救援 |

## 绳索护理

- 沙粒和阳光会毁坏绳索：卷好保存，避光并保持清洁。
- 潮湿时会损失约 10-15% 的强度；打结时要留有余量。
- 承载人体重量时按 10× 安全余量计算：80 kg → 至少使用 800 kg 的绳索。

## 实用示例：拯救生命的绳结

**情况：** 一名同伴掉进 3 米深的沟里，你有质量良好的绳索。

**操作：** 1. 单套结：固定绳圈，不会在他的胸部收紧。2. 将绳圈从他的腋下穿过。3. 用卷结 + 半结把你的绳端锚定到一棵树上。4. 将绳子绕过肩部，用行走方式提升，不要只靠手臂硬拉。

**避免：** 不要给人员使用活结，不要临时打你不熟练的绳结，不要用受损绳索提升，不要留下少于 10 cm 的绳尾。

**升级处理：** 如果人员无法抓握，或跌落时头部/脊柱受到撞击，不要用绳索移动他：在原位稳定他（创伤指南），并通过紧急频道求助。
