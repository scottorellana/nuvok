# 沙漠中的水

在沙漠中，水就是生命：没有水，在极端高温下你只剩 **1-2 天**。每一个决定都以汗水衡量。

## 关键步骤

1. **喝掉你已有的水。** 典型的致命错误是“省着喝”：人们会在水壶里还有水时死于脱水。你的身体比你的水瓶更会储存水。
2. **限量的是汗，不是水。** 只在黎明、黄昏或夜间移动；其余时间在阴影中休息。正午行走每小时消耗 1 升水。
3. **在干河道中寻找。** 在干涸溪流的外弯处挖 30-60 cm，那里沙子看起来更深色或有植被生长。如果沙子变湿，等待水渗入坑中。
4. **跟随生命迹象。** 黎明/黄昏的鸟会朝水源飞；昆虫群、汇聚的动物足迹以及绿色植被斑块都表示附近有水。
5. **黎明收集露水。** 太阳升起前，用吸水布拖过植被并拧出水；在寒冷夜晚，金属表面和平滑岩石也会凝结水汽。
6. **检查岩石蓄水处。** 岩层中有阴影的凹洞和裂缝（天然水罐）可在降雨后数周内保存雨水。
7. **只要能净化，就始终净化。** 天然水罐或挖掘井中的水：煮沸或使用你急救包中的氯滴剂（2 滴/升，5%，30 min）。沙漠中的腹泻就是判决。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 口渴行走时“保存”水 | 口渴时饮水；限量体力消耗 |
| 喝仙人掌汁——会杀人的神话 | 大多数会导致呕吐和腹泻：你会失去更多水 |
| 正午行走寻找水 | 黎明/黄昏寻找；正午待在阴影中 |
| 喝尿或散热器水 | 会加速脱水并造成中毒 |
| 储备少于 1 升时进食 | 消化会消耗水：没有水就不要吃 |
| 把一切寄托于太阳能蒸馏器 | 产量很低（一天一杯）；是辅助，不是救命稻草 |

## 太阳能蒸馏器（辅助，不是奇迹）

1. 在有湿气的土壤（干河道）中挖一个宽 60 cm × 深 40 cm 的坑，或放入捣碎的绿色植被。
2. 在坑底中央放一个干净容器。
3. 用透明塑料覆盖坑口，并用石头/沙子封住边缘。
4. 在塑料中央、正对容器上方放一颗小石子：锥形会让凝结水滴入容器。
5. 等待 6-12 h。产量约为每天 1 杯：如果依赖它们，就做多个。

## 危险脱水迹象

- 尿色深，或 8+ 小时没有尿。
- 站起时头晕、搏动性头痛。
- 皮肤被捏起后不回弹，口腔黏腻且无唾液。
- 意识混乱或易怒 → 转到中暑指南：这是立即的紧急情况。

## 实用示例：沙漠中的水

**情况：** 你的车辆在沙漠道路上抛锚；每人剩 1 升水，救援可能超过一天才到。

**要做：** 1. 留在车辆旁（阴影 + 可见性）。 2. 口渴就喝，不要“省着喝”。 3. 在第一道和最后一道光线时寻找附近干河道，并在外弯处挖掘。 4. 用你拥有的塑料为每人搭一个太阳能蒸馏器。 5. 标记你的位置并启动 mesh 的 SOS。

**避免：** 不要在正午行走，不要喝仙人掌汁或尿，不要在水很少时进食，不要在未标记方向的情况下远离车辆。

**升级处理：** 如果有人停止出汗、意识混乱或倒下，就是中暑：立即到阴影处，弄湿其衣服，扇风，并转到该指南——这是沙漠中的头号紧急情况。
