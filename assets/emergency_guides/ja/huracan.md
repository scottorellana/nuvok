# ハリケーン

## ハリケーンの前
1. **警報を監視する** — ラジオ／テレビと公式通知を聞く
2. **窓を補強する** — 板または防護シャッターで
3. **木を剪定する** — 落下し得る枝を取り除く
4. **排水溝を清掃する** — よく排水されるよう確保する
5. **ガソリンタンクを満たす** — 後で燃料が不足する

## ハリケーンの間
1. **屋内にとどまる** — ハリケーンの目の間も外に出ない
2. **窓から離れる** — 窓のない内側の部屋を使う
3. **すべてのドアを閉める** — 家の中の圧力を下げる
4. **屋根が破損した場合** — マットレスまたは毛布で身を覆う
5. **外に出ない** — 静まったように見えても、目である可能性がある

## ハリケーンの後
1. **公式の「安全確認」を待つ** — 電柱／倒壊物がある可能性がある
2. **懐中電灯を使う** — ろうそくを点けない（ガス漏れ）
3. **冠水した道路を避ける** — 下に何があるかわからない
4. **被害を写真に撮る** — 保険のため
5. **Boil water** — 飲用可能と確認されるまで水を沸騰させる

## サファ・シンプソン・スケール
- **Cat 1**（74-95 mph）：軽微な被害
- **Cat 2**（96-110 mph）：広範な被害
- **Cat 3**（111-129 mph）：壊滅的
- **Cat 4**（130-156 mph）：破滅的
- **Cat 5**（157+ mph）：完全な破壊

## 実例：ハリケーン

**状況：** 24 時間後にハリケーンが来ると発表され、まだ家を準備する時間がある。

**行うこと：** 1. 30 秒立ち止まり、主な危険を定義する。 2. 水、防寒具、照明、通信手段、安全な経路を集める。 3. 今リスクを減らす最も単純な行動を実行する。 4. 他の人が続けられるように、実施済みのことをメモ／チェックリストに印を付ける。

**避けること：** 計画なしにバッテリーを消耗しない、流れている水を渡らない、知らない植物を食べない、グループから離れない、暗くなるまでシェルター設営を待たない。

**エスカレーション：** 天候が悪化する、体温が下がる、安全な水が不足する、脆弱な子ども／高齢者がいる、または方向を見失う場合は、計画を変更する。

**クイックチェック：** ガイドを閉じる前に、何が起きたか、何をしたか、何が残っているか、誰が責任者として残るかを声に出して言う。この例はガイド付きの練習である；手順を自分の環境に合わせ、専門的な援助が利用できる場合はそれを優先する。
