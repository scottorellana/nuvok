# 最初の 72 時間

衝撃が過ぎたら、**コミュニティが政府そのもの**となる 72 時間が始まる：外部からの支援は遅れる——あなたたちが秩序立って行うことは、百の場当たり的対応に値する。

## 重要な手順

1. **時間 0-1：人。** 家族の点呼（メッシュの集合地点）、負傷者はガイドに従って対応（複数いる場合はトリアージ）、そして損傷した構造物には再立ち入りしない（倒壊ガイド）。
2. **時間 1-6：屋外の危険。** ガスを閉止し、ケーブルは 10 m の位置に印を付け、危険な構造物は赤い布で表示する——メッシュの戦術地図上に地区の危険マップを作る。
3. **時間 6-12：正直な在庫確認。** 家族ごと、および共有分として：水、食料、医薬品、工具、発電機、そして技能（看護師、石工、電気技師）。書かれたものは争わない。
4. **時間 12-24：水と衛生を最優先。** 処理済みの水源を確保し（コミュニティ水ガイド）、必要に迫られて場当たり的に作る前に緊急用トイレを設ける（衛生ガイド）——そうしなければ、流行は 3 日目に始まる。
5. **日 2：役割と交代制。** 単純な調整（組織化ガイド）：水、健康、夜間の安全、脆弱な人々の調査（高齢者、乳児、持病のある人と、その薬の数の確認）。
6. **日 2-3：通信と合図。** メッシュは電波がなくても地区をつなぐ；物理的な情報拠点（黒板／壁）に、無事な人、捜索中の人、必要なもののリストを掲示する——パニックと噂を減らす。
7. **黄金律：まず安定化し、その後に再建する。** 安全な水が不足している間に 1 日目から屋根を修理するようなことはしない；最初の 3 日間の順序が、その月を決める。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 各家族が単独で「自分たちのことを解決」する | 1 日目に共通の在庫確認と役割を決める |
| 物のために損傷した家へ戻る | 余震を受ける価値のある物などない |
| 衛生を「後回し」にする | 1-2 日目までにトイレを作る：流行は待たない |
| 最初にボトル入りの水をすべて使い切る | 今すぐ水源を処理し、ボトル入りは備蓄する |
| 噂と怒鳴り声での意思決定 | 情報掲示板 + 固定された短い会合 |
| 黙ってため込む | 書かれ、分配されたものの方が長持ちし、争いを避ける |

## 72 h のコミュニティ救急箱

- 家ごとの人のリスト（および誰がいないか）——メッシュで共有する。
- 水：水源 + 処理 + 計量した分配。
- 健康：救急箱をまとめる + 使い方を知っている人 + アプリのガイド。
- エネルギー：全員の電話用の発電機一台 > 明かりのついた五軒の家。

## 実践例：最初の 72 時間

**状況：** 夜明けに強い地震；あなたの街区には損傷した家が 3 軒、軽傷者が一人おり、どの当局も到着していない。

**行う：** 1. 一軒ずつ点呼し、負傷者をガイドに従って手当てする。 2. 街区のガスを閉止し、ケーブルと亀裂をメッシュの地図に印付けする。 3. 15 min の会合：在庫確認、共有の水、大きな敷地の奥に溝式トイレ。 4. 交代制：水、子ども／高齢者、夜間見回り。 5. 角に掲示板：誰が無事か、何が足りないか、次の会合。

**避ける：** 亀裂のある家に入らない、ゴミを水のそばで燃やさない、高齢者を調査対象から漏らさない、組織化するために「誰かが来るのを」待たない。

**拡大対応：** 重傷者または閉じ込められた人がいる場合：トリアージ／倒壊ガイド + 近隣の街区へのメッシュのSOS——そして 2-3 日目に複数の家で下痢が出た場合、水が機能していない：水源を変え、トイレと塩素を今すぐ強化する。
