# 安全河水

河流提供无尽的水——**也提供无尽让你生病的方式**。浑浊度、寄生虫以及上游有什么，决定它是救你还是击倒你。

## 关键步骤

1. **思考上游。** 有没有村镇、牲畜、农田、死动物？水会讲述上游的故事。从水流快、多石的河段取水，绝不要从腐败的回水处取水。
2. **从干净一侧取水。** 石头上流动的水 > 岸边静水。把容器沉到中等深度：水面会带来漂浮物，水底有沉淀物。
3. **先让浑浊物沉降。** 泥水：静置 1-2 小时（或整夜），只使用上方 ⅔。氯和煮沸在有泥时效果差。
4. **分层过滤。** 剪开的瓶子倒置：布、火中碾碎的木炭、细沙、砾石。过滤能去除可见物——不能消毒。
5. **过滤后始终消毒。** 煮沸 1 分钟（高海拔 3 min）或每升加入 2 滴 5% 的氯 + 30 min（已沉降的浑水：双倍剂量，见计算器）。
6. **太阳作为 C 方案（SODIS）。** 透明 PET 瓶装满，放在反光表面上接受直射阳光 6 小时：紫外线会消毒。仅适用于清澈水。
7. **照管干净容器。** 净化后又用同一个脏杯子重新装水，会毁掉一切：分开“生水”和“饮用水”，并用处理过的水冲洗螺口。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 直接喝，“因为水在流动而且看起来干净” | 流动不能杀死贾第虫或霍乱：始终消毒 |
| 直接给泥水加氯 | 先沉降/过滤；泥会保护微生物 |
| 从岸边的静止回水处取水 | 选择水流快、多石的河段，在中等深度取水 |
| 过滤后就认定安全 | 自制过滤器不能消毒：之后煮沸或加氯 |
| 用生水杯给饮用水容器重新装水 | 严格分开生水/饮用水 |
| 因“时间紧”而忽视队伍腹泻 | 立即使用口服补液盐（计算器）——腹泻造成的脱水比口渴更严重 |

## 河水处理阶梯

1. **最好：** 流入河流的小而快、清洁的支流。
2. **好：** 快流河段的河水，沉降 + 煮沸。
3. **一般：** 浑水沉降 + 过滤 + 双倍氯。
4. **最后选择：** 岸边井——距河流 2-5 m 开挖：沙子会预过滤（仍需消毒）。

## 实用示例：河水

**情境：** 营地在一条上涨、呈巧克力色的河流旁；瓶装水用完了，队伍里有儿童。

**要做：** 1. 在距水边 3 m 处挖一个岸边井，让水经沙子过滤后注入。 2. 同时：把快流河段取来的 2 锅水静置沉降。 3. 用火中的木炭制作瓶式过滤器。 4. 所有水煮沸 1 分钟；若没有火，则使用双倍氯。 5. 标记容器：生水 vs 饮用水。

**避免：** 不要让孩子喝未经处理的“就一小口”，不要直接给泥水加氯，不要用生水杯重新污染饮用水，不要从回水处取水。

**升级：** 队伍中有人腹泻或呕吐：立即按计算器比例配制口服补液盐，并转到中毒指南；如果腹泻带血或高热，这是撤离优先事项——启动 mesh。
