# 冷蔵なしで食品を保存する

冷蔵庫がなければ、細菌との競争になる。**塩、煙、太陽、砂糖**は人類の冷蔵庫であり、何かを食べてはならない時を知ることは技術の半分である。

## 重要な手順

1. **まず最初に悪くなるものを食べる：** 生の肉／魚（数時間）、乳製品（1日）、調理済み食品（暑い中で1日）。米、豆、缶詰、根菜は後回しにする。週の献立は腐敗が決める。
2. **天日乾燥（果物、ハーブ、トマト、唐辛子）：** 清潔な網／板の上に薄く切ったものを置き、直射日光と風に当て、蚊帳布で覆い、日に2回裏返す。毎晩屋根の下に入れる。曲がらずに割れるようになれば完了（2～4日）。
3. **干し肉（タサホ）：** 脂肪なしの1 cmの細切りにし、全面に塩を付け、日光／風に吊るすか弱い煙の上に置き、黒っぽく硬くなるまで乾かす（2～3日）。脂肪は乾かない。酸敗するため、すべて取り除く。
4. **魚の塩蔵：** 背開きにし、内側と外側に厚い塩の層を付け、重しをして一晩積み、その後天日乾燥する。塩は安いが、中毒は安くない。
5. **燻製＝乾燥＋風味＋保護皮膜：** 硬木（オーク、果樹、乾燥マングローブ）の冷たい／弱い煙（調理しない）を数時間当てる。樹脂の多い木（松）や有毒な木は絶対に使わない。
6. **宝物のように保管する：** すべてを十分に乾かし、底に塩／灰を入れたふた付き容器に入れ、高く、暗く、風通しのよい場所に置く。毎週確認する。カビの生えた一片が瓶全体を汚染する。
7. **異議なしの廃棄ルール：** 酸っぱい／アンモニア臭、ぬめり、肉のカビ、膨らんだ缶や泡立つ缶＝捨てる。復興時の集団食中毒は第二の災害である。

## やってはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| 「量を稼ぐ」ために厚い塊を乾かす | 薄い細切りにする。厚いものは中から腐る |
| 乾燥させる肉に脂肪を残す | 脂肪なし。酸敗して一片をだめにする |
| 松／塗装木材で燻製する | 自然の硬木のみ |
| 変なにおいのするものを「少しだけ」試す | 異議なしで廃棄 |
| 「ほぼ乾いた」として湿ったまま保存する | 割れるほど乾燥させる。そうでなければ日光に戻す |
| 膨らんだ缶を「念のため煮て」使う | ボツリヌス：開けずに捨てる |

## 貧しい人のその他の冷蔵庫

- **ジールポット：** 素焼き鉢を別の鉢の中に入れ、間に湿った砂を入れ、上に湿った布をかぶせる。野菜は約10 °C下がる（余分に数日）。
- **地中：** 根菜（じゃがいも、キャッサバ、にんじん）は、乾いた砂を入れた箱／穴に入れ、涼しく暗く保つ。数週間から数か月。
- **蜂蜜／砂糖と酢漬け：** 瓶が清潔で密封されていれば、果物と野菜は数か月もつ。

## 実践例：食品の保存

**状況：** 停電から2日が経ち、隣人の牛が事故に遭った。肉が30 kgあり、日差しは強い。

**行うこと：** 1. 今日中に作業を分担する。骨を外し、脂肪をすべて取り除き、1 cmの細切りにする。 2. たっぷり塩をし、蚊帳を付けた枠に吊るし、日光と風に当てる。 3. 風下でオークの弱火を使い、燻製の分を作る。 4. 夜：すべて屋根の下で覆う。 5. 3日目：硬くなったものを塩入りの瓶へ。脂肪は煮てラードにする（すぐ揚げ物に使う。生のまま保存しない）。

**避けること：** 脂肪付きで乾かさない、湿った細切りを積み重ねない、肉を夜の屋外に放置しない、割れずに曲がるものは一切保存しない。

**拡大対応：** 保存食を食べた後に誰かが嘔吐または下痢をした場合：経口補水液（計算機）＋食中毒ガイド。そして疑わしいロットはすべて捨て、受け取った人にメッシュで知らせる。食べ物を失う方が、人を失うよりよい。
