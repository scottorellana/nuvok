# 沼地の水と昆虫

沼地の逆説：**飲めない水と、ワニより多く人を殺す昆虫に囲まれている** — デング熱とマラリアが、その週の現実の危険である。

## 重要手順

1. **沼地のよどんだ暗い水は絶対に飲むな**。完全な段階を踏まない限り：沈殿させる → ろ過する（布+木炭+砂）→ 沸騰させる（ここでは塩素より良い：有機物が塩素を消費する）。
2. **動いている、または落ちてくる水を探す：** 流れ込む支流、雨（沼地で最良の水源 — すべての豪雨で捕集する）、高い位置のブロメリア／木の穴（同様にろ過して沸騰させる）。
3. **群れ = 煙。** 上に青葉を載せた絶えない火：煙が常時の忌避剤である。眠る台を煙が横切るようにキャンプする。
4. **夜明けと日暮れには皮膚を覆う**（ヤブカのピーク時間）：長袖、ズボンの裾を靴下の中に入れる、首と頭を覆う。露出した皮膚に泥を塗ると緊急時のバリアとして機能する。
5. **高く、防護して眠る：** 水／泥の上に台 + どんな布でも蚊帳として使う（顔にシャツをかけるだけでも何もないよりまし）。夜の沼地の地面はヘビのものだ。
6. **キャンプの繁殖場所を排水する：** 20 mにある、よどんだ水の入った容器／穴はどれも数時間でヤブカを繁殖させる — 空にするか覆う。
7. **沼地での発熱 = 警報。** 刺された数日後の発熱 + 体の痛み：反証されるまでデング熱／マラリアとして扱う — 積極的な水分補給（計算機の経口補水液）、デング熱を疑う場合はイブプロフェン／アスピリンは不可（出血）：パラセタモールのみ、そして避難。

## してはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| 「シャツでろ過した」暗い水を飲む | 必ず沈殿 + ろ過 + 沸騰 |
| 葉や浮遊物がある水を塩素消毒する | 有機物は塩素を無効にする：沸騰させる |
| 「一晩だけ」と地面で眠る | 高い台 + 煙 + 顔に布 |
| 出血するまで刺し跡をかく | 泥／局所の冷却；破れた皮膚は数時間で感染する |
| デング熱が疑わしい発熱にイブプロフェンを使う | パラセタモールのみ + 経口補水液 + 避難 |
| キャンプのそばに水の入った缶／穴を残す | 20 mの繁殖場所を空にする、または覆う |

## 緊急時の忌避剤

- 青葉を入れた火の煙（最強）。
- 露出した皮膚に薄い層で乾いた泥。
- 風下で眠る（ヤブカは風に逆らって狩る）。

## 実践例：水と昆虫

**状況：** マングローブ地帯で立ち往生して二日目；ボトル水は尽き、昨夜ヤブカが集団を生きたまま食った。

**実行：** 1. 午後の豪雨に備えてシートを用意（水源 #1）。2. その間：流れ込む支流の水を、沈殿させ、ろ過し、沸騰させる。3. 高くした就寝台 + 青葉で煙の多い焚き火を常時維持。4. 全員がピーク時間に覆い、手と首に泥を塗る。5. 20 mにある水入りの缶と穴をすべて空にする。

**避ける：** よどんだ水面から飲まない、地面すれすれで眠らない、血が出るまでかかない、夜明けに火を消さない。

**エスカレーション：** 集団の誰かに高熱 + 目の奥の痛み：デング熱を疑う — パラセタモール（イブプロフェン／アスピリンは絶対不可）、継続的な経口補水液、日陰、そしてメッシュのSOSを起動して優先避難。
