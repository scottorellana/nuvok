# 崩落と倒壊建物

倒壊後、**最大の危険は二次崩落**です — そして不適切な自発的救助は救助者を死なせます。秩序と聴くことは、力より多くを救います。

## 重要な手順

1. **閉じ込められたら：空気を守る。** 鼻と口を布で覆う（粉じんは窒息させ、目を見えなくする）、火をつけない（ガス）、最初から叫ばない：配管または床板を 3 回、まとまりごとに叩き、聞く。声は消耗する。金属は伝わる。
2. **見えないまま動かない。** 転がる前に手で探る：動くことで自分の生存空間を不安定にすることがある。光／空間があれば、各支持点を試しながら落ち着いてそちらへ動く。
3. **外から：止まって聞く。** 10-15 min ごとに、組織的に完全な静寂（エンジン停止）を作る：3 回の叩く音 = 生存者。聞こえた場所に印を付ける。
4. **がれきの山に登らない。** あなたの体重で下の生存空間が潰れる。端から作業し、人間の鎖で一つずつ取り除き、重量を支えているものを絶対に引っ張らない。
5. **余震：全員が外へ、離れる。** 最初の倒壊後、損傷したものはさらに落ち続ける。合意した退避路と構造物を見張る監視員を置いた作業区域にする。
6. **確認済みを表示する。** 捜索した各区域に、日付／時刻付きで見える印（塗料、布）を付ける：重複した労力は別の場所で命を犠牲にする。
7. **閉じ込められた人に水と声を。** 接触できたら：可能なら水を渡し、名前で話しかけ、救助が進んでいると伝える — 気力が重要な時間を支える。四肢圧挫 >15 min：医療準備なしに解放してはいけない（クラッシュ症候群）— mesh で医療指示を求める。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 名前を叫びながらがれきの上を走る | 端、組織的な静寂、叩く音を聞く |
| 「邪魔な」梁を引っ張る | 重量を支えているものは、支保なしに動かさない |
| 見るためにマッチ／ライターをつける | 懐中電灯のみ：たまったガスは爆発する |
| 何時間も圧迫された手足を一気に解放する | まず医療準備（クラッシュ症候群） |
| 書類／ペットのために戻って入る | 損傷したものは余震でさらに落ち続ける |
| 閉じ込められている時に叫び続ける | 金属を 3 回叩く、定期的なまとまり、空気を節約する |

## 生存空間キット（地震地域に住む場合）

- ベッドの下：閉じた靴、懐中電灯、ホイッスル、水のボトル。
- がれきの下では、ホイッスルは千回の叫びに匹敵する。
- 家族で合意：屋外の集合場所（mesh の集合場所ガイド）。

## 実践例：倒壊建物

**状況：** 地震後、隣家が部分的に倒壊した。誰かの声が聞こえ、助けようと近所の人が集まってくる。

**行うこと：** 1. 組織する：エンジンと無線を切り、完全な静寂、応答の 3 回の叩打 — 場所を特定する。 2. 余震の監視員 + 全員の退避路。 3. 端から人間の鎖で一つずつ取り除く。 4. 接触：水、名前、励まし；圧挫があれば mesh で医療ガイドを求める。 5. 確認済み区域に印を付け、疲れた人を交代させる。

**避けること：** がれきの山に登らない、荷重のかかった柱／梁を動かさない、火をつけない、監視員なしで作業しない。

**エスカレーション：** ガスの臭いがする、または配管がシューという音を立てている場合：周囲を避難させ、電気も火も使わず、安全なら元栓を閉める（都市の危険ガイド）；強い余震では、再評価するまで全員外へ。
