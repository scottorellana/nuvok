# 极寒与雪地避难所

在深度零下环境中，**雪不再是敌人：它是你的建筑材料**。外面 -30 °C 时，雪洞内部可保持约 0 °C。

## 关键步骤

1. **在陷入困境之前就避难。** 在白茫风或 -20 °C 中，双手还能正常工作的有效时间很短：趁体力和光线还有余量时决定避难，不要拖到极限。
2. **雪沟（最快）：** 身体长度 + 40 cm 的沟，顶部用雪块/滑雪板/树枝覆盖 + 上面覆雪，低入口用背包堵住。工作 30-60 min。
3. **紧实坡面雪洞（最暖）：** 隧道向上通往一个穹顶状空间；睡眠平台高于入口（冷空气向下并向外排出）。墙厚 30+ cm。
4. **通气孔，否则你不会醒来。** 在顶部开一个拳头大小的孔，插一根棍子穿过，并时不时移动棍子以保持通畅。密闭避难所中的 CO₂ 会在睡眠中致命。
5. **工作时不要出汗。** 边建边出汗 = 衣服湿 = 延迟性低体温症。工作时脱掉一些层，结束后再穿上。进入前抖掉衣服上的所有雪。
6. **地面隔热要加三倍：** 树枝/背包/盘好的绳子作垫 — 身体下方的冰比空气夺走更多热量。靴子和手套如果潮湿，绝不可穿着/戴着睡觉：放在胸前、外套内。
7. **冻伤（frostbite）：用体温，不用火。** 手指/鼻子/耳朵发白变硬：放在自己或同伴的腋下/腹股沟处，严禁揉搓（冰晶会割伤组织）。如果行进中可能再次冻结，绝不要解冻。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| “因为冷”把避难所密封得不透气 | 通气孔始终打开并监视 |
| 穿着外套大汗淋漓地建造 | 工作时脱层；结束后保持干燥 |
| 用雪摩擦冻伤皮肤 | 直接用体温取暖，不摩擦 |
| 穿着潮湿的靴子睡觉 | 放在胸前：用你的热量慢慢烘干 |
| 避难所很大“为了舒服” | 小而低：你的体热必须能充满它 |
| 在白茫风中离开避难所去辨别方向 | 使用固定的导向绳或在里面等待 |

## 白茫风（whiteout）

- 如果世界消失：避难或保持不动。在白茫中行走 = 转圈和裂缝。
- 任何外出都要有固定在避难所上的绳索（5 步外的厕所也会迷失）。
- 高处标记避难所（杆 + 布）：你睡觉时雪会掩埋入口。

## 实用示例：极寒

**情况：** 雪地摩托在 -25 °C 时故障；风开始增强，村镇在 20 km 外。

**做：** 1. 立即决定：没有人在暴风雪中步行 20 km — 在机器旁避难（它是可见信号）。 2. 在背风侧挖雪沟，用座椅/帆布 + 雪作顶。 3. 挖掘时脱掉一些层；进入时抖掉雪并穿上所有干的衣物。 4. 用棍子做通气孔 + 下方三重隔热。 5. 发出 mesh 的 SOS 信标并等待：他们会在机器所在地寻找你。

**避免：** 不要试图步行“很快就到”，不要密封顶部，不要穿湿衣服睡觉，不要离开机器（你的可见点）。

**升级：** 如果有人停止发抖、含糊说话，或想在露天“睡一会儿”：严重低体温症 — 立即查看低体温症指南，在避难所内皮肤贴皮肤取暖，并且在他恢复清醒前，他的任何决定都不算数。
