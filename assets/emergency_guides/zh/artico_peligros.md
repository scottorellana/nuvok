# 冰雪危险

冰会骗人：**昨天能承受的，今天不一定能承受**；暴风雪会在几分钟内抹去整个世界，冻伤会在无痛中咬伤你。

## 关键步骤

1. **踏上冰面前先读懂冰：** 透明/蓝色 = 强；乳白色 = 强度减半；灰色/深色或上面有雪 = 不可。透明新冰上的最低要求：步行 10 cm，雪地摩托 20 cm。用杆敲击：空洞声 = 退回。
2. **警惕永久薄弱点：** 河流入口/出口、湖下水流、岩石和码头旁、有气泡或潮湿裂缝的冰。湖中央并不保证安全。
3. **分开横渡并有计划：** 一次一人或间隔 10+ m，绳索准备好，背包扣松开，冰锥（或两把螺丝刀/钥匙）挂在脖子上。
4. **如果掉入冰窟：** 控制喘气（1 min），面向你来时的方向（那片冰曾承受过你），双臂搭上边缘，水平踢腿并扎入冰锥，像海豹一样滑出。不要站起来：滚离洞口。
5. **出水后：湿衣服要更换或在雪中翻滚**（干雪会吸收衣服中的水分），并立即避难 + 生火 — 你的双手可用时间只有几分钟（低体温症指南）。
6. **暴风雪：在迷路之前停下。** 能见度下降 = 立即避难（寒冷指南）。在白茫中行走最终会转圈、掉进裂缝或进入开放水域。
7. **成对监测冻伤：** 强风中每 15 min 检查同伴面部（鼻子/脸颊出现蜡白斑 = 冻伤开始：用温暖的手覆盖，更好地遮盖，不要揉搓）。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 穿越上面有雪的冰面，“看起来很结实” | 雪会隐藏并削弱冰面：探测或绕行 |
| 人群挤在一起穿越 | 一次一人或相隔很远，绳索准备好 |
| 出水后立刻站起来 | 滚离洞口，然后爬行 |
| 穿着湿衣服“硬扛”来变干 | 更换或在干雪中翻滚 + 立即生火 |
| 摩擦同伴发白的脸颊 | 轻柔供热，不摩擦，并遮盖 |
| 在暴风雪中行走，“只有 2 km” | 避难：白茫会连你的足迹都抹去 |

## 自制冰锥

1. 两枚大钉子/螺丝刀/尖头钥匙。
2. 能握在拳头里的手柄（缠布）。
3. 用绳子把它们连接并穿过袖子内侧：它们挂在每只手腕处，无需寻找即可使用。

## 实用示例：冰面危险

**情况：** 为了缩短去村子的路，必须穿过一片冰封湖；昨晚下了雪，看不见冰面。

**做：** 1. 诚实决定：上面有新雪 = 冰面不可读 — 沿岸绕行，即使多花 2 小时。 2. 如果某一段无法避免：探测积雪，直到看到 10+ cm 的透明冰。 3. 一次一人、保持间距、冰锥挂脖、扣带松开。 4. 听到空洞声或看到乳白冰：沿你的足迹原路返回。 5. 到另一侧后，检查面部和双手。

**避免：** 不要一起穿越，不要相信别人留下的旧足迹，如果冰面发出干裂“轰响”不要继续，不要因为“碍事”就取下冰锥。

**升级：** 如果有人落水：不要跑向洞口 — 爬着接近以分散重量，递出绳子/树枝/展开的外套，并把他朝他来时的方向拉出；之后就是与低体温症赛跑：避难、干衣、取暖，并使用低体温症指南和 mesh 的 SOS。
