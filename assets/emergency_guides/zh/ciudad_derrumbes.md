# 坍塌和建筑物倒塌

倒塌之后，**最大的危险是第二次坍塌**——而错误的自发救援会害死救援者。有秩序并倾听，比蛮力更能救命。

## 关键步骤

1. **如果你被困：保护你的空气。** 用布遮住鼻子和嘴（粉尘会使人窒息并致盲），不要点火（燃气），并且一开始不要喊叫：分组敲击管道或楼板 3 次，然后倾听。嗓音会耗尽；金属声能传播。
2. **不要盲目移动。** 翻滚前先摸索：移动可能会使你的生命空隙失稳。如果有光/空间，冷静地朝它移动，每一步都先试探支撑。
3. **在外面：停下并倾听。** 每 10-15 min 组织一次完全安静（关闭发动机）：3 次敲击 = 有人活着。标记听到的位置。
4. **不要攀爬瓦砾堆。** 你的体重会压垮下面的生命空隙。从边缘作业，按人链一件件移除，绝不要拉动承重物。
5. **余震：所有人撤出并远离。** 第一次倒塌后，受损结构还会继续掉落。工作区要有约定好的逃生路线，并安排观察员盯着结构。
6. **标记已搜索区域。** 在每个已搜索区域做可见标记（油漆、布条），写上日期/时间：重复劳动会让别处失去生命。
7. **给被困者水和声音。** 如果能接触：如可能给他水，叫他的名字，告诉他救援正在推进——士气能支撑关键的数小时。肢体被压 >15 min：没有医疗准备不要释放（挤压综合征）——通过 mesh 请求医疗指示。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 在瓦砾上奔跑并大喊名字 | 从边缘、组织安静、倾听敲击 |
| 拉动“碍事”的梁 | 没有支撑加固时，任何承重物都不移动 |
| 点燃火柴/打火机照明 | 只用手电：积聚的燃气会爆炸 |
| 突然释放被压了数小时的肢体 | 先做医疗准备（挤压综合征） |
| 为文件/宠物返回进入 | 受损结构会随余震继续坠落 |
| 如果你被困就不停喊叫 | 在金属上敲 3 次，定期分组，节省空气 |

## 生命空隙工具包（如果你住在地震区）

- 床下：包脚鞋、手电、哨子、一瓶水。
- 瓦砾下的哨子胜过千次喊叫。
- 家庭约定：室外集合点（mesh 集合点指南）。

## 实用示例：建筑物倒塌

**情况：** 地震后，邻居家的房屋部分倒塌；能听到有人，邻居们赶来想帮忙。

**做：** 1. 组织：关闭发动机和无线电，完全安静，3 次回应敲击——定位点位。 2. 设置余震观察员 + 所有人逃生路线。 3. 从边缘用人链一件件移除。 4. 接触：水、名字、鼓励；如果有挤压伤，通过 mesh 请求医疗指导。 5. 标记已搜索区域，并替换疲劳人员。

**避免：** 不要爬上瓦砾堆，不要移动承重柱/梁，不要点火，不要在没有观察员的情况下作业。

**升级处理：** 如果闻到燃气味或听到管道嘶嘶声：疏散周边，不使用任何电器或明火，如安全则关闭总阀（城市危险指南）；遇到强余震时，所有人撤出，直到重新评估。
