# 地震

## 震动期间
1. **不要跑** — 远离窗户、玻璃和可能掉落的物体
2. **保护自己** — 躲在结实的桌子下或靠近室内墙
3. **抓牢** — 抓住固定物，直到震动结束
4. **如果你在车里** — 停在安全地点，远离桥梁和电线杆
5. **如果你在街上** — 远离建筑物、电线杆和电线

## 震动之后
1. **确认自身安全** — 检查自己是否受伤
2. **预期余震** — 余震可能持续数小时或数天
3. **远离受损建筑物** — 不要进入不稳定结构
4. **如果被困，寻求帮助** — 敲击空心物体，仅在万不得已时呼喊
5. **使用手电筒** — 如果可能有燃气泄漏，不要点火柴

## 事前准备
- [ ] 确认家中的安全区域（桌子下、室内墙旁）
- [ ] 将高大家具固定到墙上
- [ ] 准备好可取用的手电筒、哨子和急救包
- [ ] 知道如何关闭燃气、水和电
- [ ] 进行家庭演练

##应急包建议
- 带备用电池的手电筒
- 应急哨
- 完整急救包
- 水（每人每天 1 加仑，至少 3 天）
- 不易腐坏的食物
- 电池收音机
- 重要文件放在防水袋中

## 实用示例：地震

**情况：** 在一次演练中，家人在客厅，必须在不跑向门口的情况下作出反应。

**做法：** 1. 停下 30 秒，确定主要危险。 2. 集合水、保暖物、照明、通信工具和一条安全路线。 3. 执行现在能降低风险的最简单行动。 4. 在备注/清单中标记已完成事项，以便他人能够继续。

**避免：** 不要没有计划地耗电；不要穿越流动的水；不要吃不认识的植物；不要与团队分开；不要等天黑才搭建庇护所。

**升级：** 如果天气恶化、体温下降、缺少安全水源、有儿童/老年人等脆弱者，或失去方向感，就改变计划。

**快速检查：** 关闭指南前，大声说出发生了什么、你做了什么、还缺什么、谁负责留下处理。本示例是引导式练习；根据你的环境调整步骤，并在有条件时优先寻求专业帮助。
