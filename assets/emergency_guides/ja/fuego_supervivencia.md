# マッチなしで火を起こす

火は暖を取り、水を浄化し、調理し、照明となり、**救助者へ合図を送る**。点火することよりも、正しく準備することのほうが重要である。

## 重要手順

1. **最初の火花の前にすべてを準備する。** 火口＋細い薪＋中くらいの薪＋太い薪を、手の届く場所に、乾いた状態で用意しておく。失敗する火の 90% は、火花不足ではなく準備不足で消える。
2. **本物の火口を集める。** 乾いてふわふわしたもの：内側の樹皮、細かくほぐした乾いた草、衣服の綿、ポケットの綿ぼこり、ナイフで削った極細の削りくず。大きなひとつかみ（グレープフルーツ大）。
3. **火を起こす場所を保護する。** 乾いた土台（樹皮または平らな石）、風よけの壁、霧雨なら自然の屋根 — ただし煙が自由に抜けるようにする。
4. **火花／おき火を作る**（下の方法を参照）火口へ直接。
5. **やさしく一定に息を吹きかける。** 火口から煙が出たら、巣のように手で持ち上げ、下からやさしく吹く — 典型的な失敗は強く吹いて消してしまうことである。
6. **細いものから太いものへ燃料を足す。** マッチ棒くらい → 鉛筆くらい → 指くらい → 手首くらい。次の太さへ進む前に、それぞれの太さが十分に燃えていなければならない。
7. **決して放置しない**。完全に消すために水／土を手元に置く（埋めたおき火は火災を起こす）。

## マッチなしの方法

### フェロセリウム（キットにあるもの）
- ナイフの背で、火口にほとんど触れる位置で、ゆっくり強くこする。
- 3000 °C の火花：濡れていても風があっても機能する。

### 虫眼鏡／レンズ（強い日光がある場合のみ）
- 虫眼鏡、双眼鏡のレンズ、澄んだ水を入れたボトルの底。
- 光点を最小サイズまで暗い火口の上に集中させ、動かさない。

### 電池＋スチールウールまたはアルミ箔
- スチールウールを 9V 電池の両極に触れさせる＝即座におき火。
- ガムの包み紙（アルミ＋紙）を、AA電池の両極の間で細いくびれになるよう切る。

### 摩擦（弓ぎり式 — 最後の手段）
- 非常に乾燥した柔らかい木（ヤナギ、スギ、乾いたユカ）の場合のみ。
- 技術と何時間もの練習を要する：事前に練習していなければ当てにしない。

## してはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| すべての薪を用意せずに点火する | 火花の前に薪の 3 種類の太さを準備する |
| 火口が「まあまあ乾いている」 | 乾いたものを探す：丸太の内部、岩の下 |
| 生まれたばかりの炎の上に太い薪を積む | 細いものから太いものへ、材料の間に空気を入れる |
| 垂れ下がった枝の下、または乾いた根の上で火を起こす | 周囲と上方の 1.5 m を片付ける |
| 燃料／アルコールで加速する | 絶対にしない：火傷と制御不能な炎上 |
| 「ほぼ消えた」おき火を放置する | 水＋かき混ぜる＋土、触って冷たい状態にする |

## 救助信号としての火

- **三角形に配置した 3 つの火**＝国際的な遭難信号。
- 昼：煙 — 生きた火に青葉またはゴムを加える。
- 夜：炎 — 見通しのよい空き地で火を保ち、大きくする。

## 実例：マッチなしで火を起こす

**状況：** 日が暮れ、濡れており、ナイフとフェロセリウムしか持っていない。

**行うこと：** 1. 火花の前に：乾いた丸太の内部から火口＋3 種類の太さの薪を準備する。 2. 乾いた土台と風よけの壁。 3. フェロセリウムを火口の巣の上でゆっくり強くこする。 4. 下からやさしく息を吹きかけ、細いものから太いものへ燃料を足す。

**避けること：** 薪を準備せずに点火しない、最初のおき火に強く息を吹きかけない、燃料を使わない、放置しない。

**エスカレーション：** 何度試しても火がつかず気温が下がる場合は、火をあきらめる：シェルターに入り、地面から断熱し、体温を共有する；日中の光で再試行する。
