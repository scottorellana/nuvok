# 熱傷

> ⚠️ このガイドは専門的な医療に代わるものではありません。可能な限り早く医療の助けを求めてください。

## 重症度の分類

| グレード | 外観 | 痛み | 例 | 医師？ |
|-------|-----------|-------|---------|----------|
| **1ro** | 赤い、乾いている、水疱なし | 痛む | 日焼け | 大きい場合 |
| **2do** | 水疱、湿っている、赤い | 非常に痛む | 沸騰した湯 | 常に |
| **3ro** | 白い／炭化している、乾いている | **痛まない**（神経が死んでいる） | 直接の火炎 | 緊急 |
| **4to** | 骨／筋肉が見える | 痛まない | 電気、長時間の火炎 | 重篤 |

## 直ちに行うこと

```
1. 熱傷の原因を止める
   └── 熱／電気／化学物質から離す

2. 冷やす（凍らせない）
   ├── ぬるい／冷たい流水で 15-20 分
   ├── 直接氷を当てない（皮膚をさらに傷つける）
   └── 氷水を使わない（低体温を引き起こす可能性がある）

3. 衣服／装身具を外す
   ├── くっついているものの周囲を切る（引き剥がさない）
   └── 腫れる前に指輪と腕時計を外す

4. 覆う
   ├── 滅菌ガーゼまたは清潔な布で、ゆるく覆う
   ├── 綿を使わない（くっつく）
   └── クリーム、歯磨き粉、ラード、氷を使わない

5. 疼痛緩和
   └── 鎮痛薬（パラセタモール／イブプロフェン）
```

## 熱傷に絶対に付けてはいけないもの

| ❌ 使わない | 理由 |
|------------|---------|
| 直接の氷 | 組織を凍らせ、損傷を悪化させる |
| 歯磨き粉 | 刺激し、熱を閉じ込める |
| ラード／油 | 熱を閉じ込め、感染を引き起こす |
| 綿 | 傷にくっつく |
| 破れた水疱への抗菌クリーム | 細菌を閉じ込める可能性がある |

## いつ緊急に病院へ行くか？

| 重症のサイン | 理由 |
|-------------------|-------|
| どのような 3er 度熱傷でも | ショックと感染のリスク |
| 手のひらより大きい 2do 度 | 脱水のリスク |
| 顔、手、足、性器、関節 | 動きを制限する可能性がある |
| 環状熱傷（四肢を取り囲む） | 腫れたときに循環を遮断する可能性がある |
| 化学熱傷または電撃傷 | 目に見えない内部損傷 |
| 非常に若い人または高齢者 | 皮膚がより脆弱 |

## 化学熱傷

1. 可能であれば手袋を使用する
2. 洗う前に乾いた化学粉末を**払い落とす**
3. 大量の水で **20+ 分** 洗い流す
4. 汚染された衣服を慎重に脱がせる
5. **中和剤を塗布しない**（反応によりさらに熱が発生する）

## 電撃傷

> ⚠️ 外側では小さな電撃傷でも、内側では非常に大きいことがあります

| 行動 | 詳細 |
|--------|---------|
| 触れる前に電流を遮断する | あなたが感電しても誰の助けにもならない |
| 2 か所の傷を探す | 電流の入口と出口 |
| 心臓を評価する | 不整脈を引き起こす可能性がある → ECG が必須 |

## 実践例：熱傷

**状況：** 台所で、熱い水が一人の前腕にかかり、皮膚が強く痛んでいる。

**行うこと：** 1. 現場の安全を確保し、特定の一人に救急へ電話するよう依頼する。 2. より劇的に見える手順へ飛ばさず、ガイドの大きな手順を順番に従う。 3. 手袋、バリア、または清潔な布が利用可能なら使用する。 4. 毎分再評価する：呼吸、意識、出血、体温、または悪化。

**避けること：** 高度な手技を即興で行わない、損傷が疑われる場合は首／脊柱を動かさない、混乱している人に食べ物／飲み物を与えない、完全な装備を探すために通報を遅らせない。

**エスカレーション：** 正常に呼吸していない、胸痛がある、止まらない出血がある、混乱がある、広範囲の熱傷、毒物の可能性、妊娠後期、または複数の傷病者がいる場合は、直ちに電話するか搬送する。

**迅速チェック：** ガイドを閉じる前に、何が起きたか、何をしたか、何が残っているか、誰が責任者として残るかを声に出して言う。この例はガイド付きの実践である；手順をあなたの環境に合わせ、専門的な助けが得られる場合はそれを優先する。
