# 山の危険

山は時刻の誤りを罰する：**午後の雷、崩れる雪、そして体を毒する高度**は事前に知らせる — それを読めなければならない。

## 重要な手順

1. **雷雨：正午前に下る。** 山では雷雨は午後に発達する：正午に山頂到達、または引き返す。髪が逆立つ、または空気がブーンと鳴るなら：落雷は差し迫っている。
2. **雷の姿勢。** 山頂、孤立木、ケーブル、稜線から離れる：ザック（絶縁体）の上でしゃがみ、足をそろえ、集団は互いに 15 m 離れる — 決して抱き合わず、横にならない。
3. **雪崩：荷重のかかった 30-45° の斜面を避ける。** 新雪（降雪後 24-48 h）、空洞の「ワンフ」と鳴る板状雪、吹きだまりのある風下斜面：稜線または平坦な谷を迂回する。選択肢がなければ一人ずつ渡る。
4. **雪崩に流されたら：** ストック／大きなザックを放し、縁へ向かって「泳ぎ」、止まり始めたら：顔の前に手を置いて空気の袋を作り、片腕を上へ伸ばす。
5. **高山病：唯一の治療は下ること。** 2,500 m 以上で頭痛 + 吐き気 + 疲労があれば、停止し、水分を取り、それ以上登らない。混乱、ふらつき、または安静時の息苦しさ = 夜でもただちに下る、数時間で致死的になる。
6. **落石：** 朝のヘルメット — 石を接着していた氷は太陽で融ける。狭いルンゼでは：素早く、一人ずつ、止まらず、上に注意する。叫び声「落石！」 = 壁に張りつき、ヘルメットなしで上を見ない。
7. **下山は登りより多く人を殺す：** 事故の大半は下りで、疲れて急いでいる時に起こる。集中し、水分を保ち、明るいうちに下る。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 雷雲が発達しているのに山頂へ向かう | 正午前に山頂、または撤退 |
| 最も高い木の下で雷を避ける | 低い場所でしゃがみ、集団は離れる |
| 荷重のかかった雪斜面を集団で渡る | 一人ずつ、間隔を空ける、または迂回する |
| 高所での頭痛を無視する | 停止し、水分を取る；悪化すれば下る |
| より高い所で寝て高山病を「我慢する」 | その日の最高到達点と同じか、それより低い所で常に寝る |
| 疲労で走って下る | 事故の 70% は下山中に起こる |

## 硬い雪とガレ場の通過

- 朝の硬い雪：足でステップを切り、ストックを山側に突き、「もし滑ったらどこで止まるか？」を常に自問する。
- ガレ場（不安定な崖錐）：安定した大きな石を踏み、斜めに進み、集団はジグザグに、決して縦一列にならない（一人が別の人の上に石を落とす）。

## 実践例：山の危険

**状況：** 午前 11 に登りの中間にいる；西に黒い雲が発達し、3,000 m を越えた所で同行者が頭痛と吐き気を訴えている。

**行うこと：** 1. 即時判断：山頂は終わり — 今日、山はノーと言った。 2. 雷雨の前に、既知のルートで下る。 3. 高山病の人は同行者を付けて先に下り、水分を取る。 4. 雷雨に追いつかれたら：ザックの上でしゃがみ、互いに離れ、稜線から離れる。 5. 下で再集合し、症状を評価する。

**避けること：** 「雨の前に山頂へ走る」ことをしない、一本だけの木の下に避難しない、高山病の人を一人にしない、雷雨が迫る中で落石のあるルンゼを下らない。

**エスカレーション：** 高山病の人がふらつく、または混乱するなら、浮腫（HACE）である：必要なら担いで即時下山 + メッシュの SOS；雷が誰かに落ちた場合、その人に触れても安全 — ただちに CPR（CPR ガイド）。
