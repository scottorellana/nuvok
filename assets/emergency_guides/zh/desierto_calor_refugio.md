# 沙漠中的高温与庇护所

沙漠会杀人两次：**正午热死，凌晨冻死**。你的庇护所和作息时间就是你的生存。

## 重要步骤

1. **颠倒你的一天。** 只在黎明、黄昏和（有月光时）夜间行动。10点到16点：完全待在阴凉处静止不动。这是救命第一规则。
2. **衣服要穿在身上。** 宽松、浅色、长袖衣物+遮住头颈：布料挡住阳光并留住汗水给身体降温。脱掉上衣会脱水更快并晒伤皮肤。
3. **离开地面。** 正午地面比30厘米高处的空气热15-20°C。躺在背包、树枝或垒起的石头上，绝不要直接躺在沙子上。
4. **双层顶棚留空气层。** 两层布/篷布相隔20-30厘米，比直射阳光下低15°C；单层只有温热的阴影。
5. **利用现成的东西。** 大岩石的背阴面、岩石突出部或你的车辆（不要在车底：金属辐射热量；在车旁的阴影侧）都胜过自己搭建。
6. **日落前准备过夜。** 沙漠可能从35°C降到5°C以下：白天捡好柴火，把庇护所迎风面封住，留一层干衣服睡觉用。
7. **观察同伴是否中暑。** 皮肤干热无汗、意识混乱、步态不稳：立即遮阴、打湿衣服、扇风——并转到中暑指南。

## 不要做的事

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 正午行走"赶路" | 黎明/黄昏/夜间行动 |
| 因为热而脱衣服 | 宽松浅色衣物穿身上，遮住头部 |
| 直接躺在滚烫的沙子上 | 离地30厘米 |
| 躲进太阳下的车厢里 | 在车旁阴影处，保持通风 |
| 忽视夜晚（"沙漠嘛，热"） | 日落前备好保暖和火 |
| 活动时等口渴才喝水 | 行动中小口规律地喝 |

## 20分钟应急庇护所

1. 找天然洼地或大岩石的背阴面。
2. 把篷布/毯子从高处岩石拉到两根矮桩（斜面挡住午后阳光）。
3. 第二层（备用衬衫、另一块布）架在第一层上方20-30厘米。
4. 地面：背包、树枝或平石——绝不直接用沙地。
5. 开口朝向微风；千万别封成烤箱。

## 沙漠之夜

- 真冷：40°C的白天之后可能失温。
- 小而稳定的火 > 大篝火；柴火稀缺。
- 火边烤热的石头用布包好放进庇护所。
- 黎明检查靴子和衣物：蝎子夜里会寻找你的体温（危险指南）。

## 示例：高温与庇护所

**情况：** 在干旱地带徒步迷路；上午11点，烈日当头，看不到城镇。

**做法：** 1. 立即停下：找大岩石的背阴面。2. 用篷布和备用衬衫搭双层顶，身体离地。3. 小口规律喝水，静待到16-17点。4. 黄昏时：捡柴、备夜，只在光线可用时移动。5. 在阴凉处启动网状网络SOS。

**避免：** 不要正午继续走，不要脱上衣，不要待在不通风的车里/洞里，不要把过夜留到临时应付。

**升级：** 如果有人皮肤干热无汗、意识混乱：就是中暑——立即强力降温（衣服浇水+扇风）并转到中暑指南；若出现抽搐，转到抽搐指南。
