# 严重出血

> ⚠️ 本指南不能替代专业医疗救治。请尽快寻求医疗帮助。

一个人可能在**少于 5 分钟**内因失血而死亡。在确认呼吸之后，止血是最紧急的事。

## 快速评估

| 出血类型 | 危险吗？ | 处理 |
|-----------------|------------|--------|
| 喷射或搏动性流出（动脉） | 🚨 数分钟内致命 | 立即压迫 |
| 持续流出，浸透衣物 | 🚨 严重 | 立即压迫 |
| 少量滴血，自行凝固 | ⚠️ 较轻 | 清洗并包扎 |
| 瘀青但没有血流出 | ✅ 内部 | 观察休克 |

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 拿掉浸透的布 | 在上面再放另一块 |
| 拔出刺入的物体 | 用周围的绷带将其固定 |
| 在颈部/躯干/头部使用止血带 | 只用于手臂和腿 |
| 松开已经放置的止血带 | 只在医院由医护人员松开 |
| 清洗喷射出血的伤口 | 先止血 |

## 治疗升级

```
步骤 1：防护
├── 手套或塑料袋（他人的血液 = 疾病）
└── 如果没有：仍然行动，生命优先
     │
     ▼
步骤 2：暴露
├── 剪开或撕开衣物
└── 你需要看见血从哪里流出
     │
     ▼
步骤 3：强力直接压迫 ← 如果你能维持压迫，从这里开始
├── 将纱布/干净布料放在出血点上
├── 用你的全部体重压住（会痛，这是可以的）
├── 至少 10 分钟不要抬起来查看
└── 如果浸透 → 在上面再加一块布并继续压迫
     │
     ▼ 手臂/腿部没有止住吗？
步骤 4：如果是手臂/腿且出血量巨大
└── 如果不能快速止住、发生截肢，或你无法维持压迫，应尽早使用止血带
     │
     ▼ 如果是颈部/腋窝/腹股沟交界处或深部伤口
步骤 5：填塞（颈部、腹股沟、腋窝）
├── 将纱布/布料塞入洞内
├── 用手指一直塞到底部
└── 在上方压迫
     │
     ▼ 如果手臂/腿仍在出血
步骤 6：止血带
├── 4-5 cm 的结实布料（绝不要用铁丝）
├── 在伤口上方 5-8 cm
├── 打结 → 放木棍 → 再打结 → 旋转直到出血停止
├── 固定木棍，防止松开
└── 记录时间
```

## 止血带——细节

| 参数 | 数值 |
|-----------|-------|
| 材料 | 宽度为 4-5 cm 的布料（领带、卷起的T恤） |
| 绝不要 | 铁丝、细绳、细皮带 |
| 位置 | 伤口上方 5-8 cm，更靠近心脏；如果看不见伤口，就在肢体高位并扎紧 |
| 避免 | 放在关节上（肘、膝） |
| 目标 | 出血完全停止 |
| 时间 | 写在止血带上或伤者额头上 |

> ⚠️ 使用时会非常疼——这是正常的，说明它在起作用

## 失血性休克表

| 阶段 | 体征 | 处理 |
|------|---------|--------|
| 代偿期 | 焦虑、皮肤冰冷 | 止血、让其躺下 |
| 进展期 | 苍白、出汗、口渴、脉搏快 | 抬高双腿、保暖 |
| 严重期 | 意识混乱、脉搏微弱、嘴唇发青 | 紧急转运 |

## 何时寻求帮助/转运

- 严重出血、使用止血带或填塞时**始终** → 紧急送医院
- 轻微出血：如果伤口不闭合、是咬伤，或物体肮脏/生锈（破伤风），应就医

## 实用示例：严重出血（无法停止的出血）

**情境：** 在院子里，有人被金属板割伤，血液在数秒内浸透一条毛巾。

**做：** 1. 确保现场安全，并指定某个人呼叫急救。2. 按本指南的大步骤依次执行，不要跳到看起来最戏剧化的步骤。3. 如果有手套、屏障或干净布料，就使用它们。4. 每分钟重新评估：呼吸、意识、出血、体温或是否恶化。

**避免：** 不要临时发挥高级操作；如果怀疑有损伤，不要移动颈部/脊柱；不要给意识混乱者食物/饮料；不要因寻找完美装备而延迟呼救。

**升级：** 如果呼吸不正常、胸痛、出血不止、意识混乱、大面积烧伤、可能中毒、妊娠晚期或有多名伤者，请立即呼叫或转运。

**快速核对：** 在关闭指南前，大声说出发生了什么、你做了什么、还缺什么以及谁继续负责。本示例是引导性练习；请根据你的环境调整步骤，并在有专业帮助时优先寻求专业帮助。

## 科学依据与临时替代

- 基于 STOP THE BLEED/ACS：直接压迫、对交界部位深部伤口进行填塞，以及对危及生命的四肢出血使用止血带。
- 临时止血带必须足够宽（4-5 cm），并收紧到出血停止；铁丝、细绳或电缆会增加损伤且通常会失败。
- 不要移除浸透的层，也不要松开放置好的止血带；在上面添加材料，记录时间并转运。
