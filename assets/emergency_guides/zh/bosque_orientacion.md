# 在森林中不迷路

发觉自己迷路那一刻的黄金法则：**停** — **停**下、**想**清楚、**看**资源、**定**计划。惊慌行走的迷路者越走离救援越远；停下来的人活了下来。

## 关键步骤

1. **一有疑惑立刻停下。** 坐下、喝水、深呼吸10次。惊慌的第一个小时会走出让你没救的10公里。
2. **想：你记得的最后一个确定地点是哪里？** 岔路口、河流、大石头。多久之前？那就是你离路径的最大距离。
3. **看清你的资源。** 电量、水、保暖、剩余日光。日光不足3小时：立刻搭庇护所，导航留到明天。
4. **定计划：留在原地几乎总是赢。** 如果有人知道你的路线，或你已启动网状网络SOS，就留下：固定目标比移动目标快10倍被找到。
5. **决定移动就走直线。** 森林里没有参照物人会绕圈：永远对齐前方两棵树；到第一棵后再对齐第三棵。顺流而下的水通常通向人烟。
6. **标记你的路线。** 每20-30米：折断树枝指向前进方向、石头箭头、布条。既帮助救援，也能原路返回。
7. **让自己可见可听。** 任何东西3次=国际求救信号：3声哨（工具里有哨子）、3堆火、3次闪光。每隔几分钟重复。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 心里存疑还"再走一段" | 立即停下：存疑的每一步都在远离救援 |
| 夜间赶路 | 黄昏就搭庇护所；黑夜制造扭伤 |
| 离开路径抄近路"赶时间" | 沿自己标记的路线原路返回 |
| 不停尝试信号耗尽电量 | 分时段开机：高处、每小时一次 |
| 在峡谷里盲目顺水走 | 水是向导，但要绕开瀑布和峡谷 |
| 分头"找路" | 队伍绝不分开 |

## 无指南针定向（导航指南有详解）

- **太阳：** 东升西落；正午指向南方（北半球）。
- **影子法：** 立一根棍，标记影尖，等15分钟再标记：两点连线为西→东。
- **应用内的指南针**（工具）无信号也能用。
- 定好方位就要相信它："感觉是那边"是最大的敌人。

## 示例：在森林中不迷路

**情况：** 你为摘野果离开了路径，回头时一切都变陌生了；还剩4小时日光。

**做法：** 1. 坐下深呼吸10次。2. 回想：路径在上坡方向，约15分钟前。3. 用树枝在当前位置摆一个大X。4. 对齐树木直线向上坡走，每20米做标记。5. 30分钟没找到路径，就沿标记回到X处，准备庇护所和信号。

**避免：** 不要绕圈"探索"，不要图省力下沟，不要耗尽电量，不要在黄昏后继续走。

**升级：** 受伤、天黑或天气恶化：停止找路 — 庇护所+3信号+网状网络SOS；只要有片刻手机信号，就拨打急救电话（拨打按钮）。
