# 沼泽中的水和昆虫

沼泽的悖论：**周围全是不能喝的水，还有比鳄鱼更致命的昆虫**——登革热和疟疾才是这一周的真正危险。

## 关键步骤

1. **绝不要饮用静止、发黑的沼泽水**，除非完成全套流程：沉淀 → 过滤（布+木炭+沙）→ 煮沸（在这里比氯更好：有机物会消耗氯）。
2. **寻找流动或落下的水：** 汇入的支流、雨水（沼泽中最好的水源——每场暴雨都要收集），以及高处的凤梨科植物/树洞积水（同样要过滤并煮沸）。
3. **虫群 = 烟。** 持续生火，并在上面放绿色叶子：烟就是你的持续驱虫剂。让烟穿过睡眠平台上方的营地。
4. **黎明和黄昏遮盖皮肤**（蚊子高峰时段）：长袖、裤脚塞进袜子、遮住颈部和头部。把泥涂在暴露皮肤上可作为应急屏障。
5. **睡在高处并有防护：** 水面/泥面上方的平台 + 任何布料作为蚊帐（用衬衫盖住脸也比没有强）。夜间的沼泽地面属于蛇。
6. **排除营地内的孳生点：** 任何在 20 m 有静水的容器/坑洞都能在数小时内孳生蚊子——倒空或盖住它们。
7. **沼泽中发热 = 警报。** 被叮咬数日后出现发热 + 全身疼痛：按登革热/疟疾处理，直到证实不是——积极补液（按计算器配制口服补液盐），若怀疑登革热（出血风险）不要用布洛芬/阿司匹林：只用对乙酰氨基酚，并撤离。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 喝“用衬衫过滤过”的黑水 | 始终沉淀 + 过滤 + 煮沸 |
| 对有树叶/漂浮有机物的水加氯 | 有机物会使氯失效：煮沸 |
| “只睡一晚”在地面上 | 高平台 + 烟 + 脸上盖布 |
| 把叮咬处抓到出血 | 局部泥/冷敷；破损皮肤会在数小时内感染 |
| 疑似登革热发热时用布洛芬 | 只用对乙酰氨基酚 + 口服补液盐 + 撤离 |
| 在营地旁留下有水的罐子/坑洞 | 在 20 m 倒空或盖住孳生点 |

## 应急驱避方法

- 用绿色叶子产生的篝火烟（最有效）。
- 在暴露皮肤上涂一层薄薄的干泥。
- 顺风睡觉（蚊子会逆风寻找目标）。

## 实用示例：水和昆虫

**情况：** 在红树林区域被困第二天；瓶装水已经用完，昨晚蚊子把整个小组叮得很惨。

**操作：** 1. 准备好篷布迎接下午暴雨（水源 #1）。2. 同时：取汇入支流的水，沉淀、过滤并煮沸。3. 抬高的睡眠平台 + 持续用绿色叶子制造浓烟的篝火。4. 所有人在高峰时段遮盖身体，手和颈部涂泥。5. 倒空每个在 20 m 有水的罐子和坑洞。

**避免：** 不要喝静止水面的水，不要贴地睡觉，不要把皮肤抓到出血，不要让火在黎明时熄灭。

**升级处理：** 小组中任何人出现高热 + 眼后痛：怀疑登革热——对乙酰氨基酚（绝不要用布洛芬/阿司匹林）、持续口服补液、阴凉处休息，并通过 mesh 的 SOS 优先撤离。
