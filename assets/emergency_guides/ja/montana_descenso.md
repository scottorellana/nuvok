# 山で道に迷い下降すること

山で道に迷ったとき、「どこでもいいから下る」という本能は命取りになる：**沢は狭まり、滝は上から見えず、霧は世界を消し去る**。

## 重要な手順

1. **迷った瞬間に止まる。** STOPの原則：座る、息を整える、観察する、計画する。道に迷ったまま歩くと誤差が増大する；救助隊はあなたの最後に確認された地点から捜索する。
2. **可能なら来た道を引き返す。** 自分がどこにいたかを確実に知っていた最後の地点は非常に重要である：登り返すことになっても、つらくても、そこへ戻る。
3. **霧または夜＝野営。** 山で視界のないまま移動することは、沢を相手にしたロシアンルーレットである。避難場所（寒冷ガイド）を確保して待つ：山の霧は通常、夜明けに晴れ間が出る。
4. **下降するには：稜線または尾根筋、沢は絶対に避ける。** 水路は滝や壁に挟まれて行き詰まる。幅の広い稜線や尾根筋は緩やかに下り、視界もある。
5. **水を追うのは距離を保つ場合に限る。** 下流の川は人のいる場所へつながる、確かにそうだ――しかし峡谷の中ではなく、谷を見下ろす幅の広い斜面を歩く。
6. **自分の足跡を標示する。** 石積み、交差させた枝、矢印：戻らなければならない場合や捜索される場合、あなたの痕跡が情報を伝える。
7. **急斜面では一歩ごとに確認する。** 強い傾斜では三点支持、下降時は斜面に正対し、迷ったら遠回りを探す――ここで足首を骨折すればすべてが変わる。

## 何をしてはいけないか

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 「沢を下る、水はどこかへ出る」 | 幅の広い稜線と尾根筋；水は距離を保つ |
| 濃い霧の中または夜間に歩く | 避難場所を確保し、視界を待つ |
| 迷っているのに「もう少しだけ」進む | STOP：止まる、考える、既知の地点へ戻る |
| 壁に背を向けて下降する | 斜面に正対し、三点支持 |
| 「二方向を探索するため」に離れる | 集団は常に一緒；最大でも視界内 |
| 恥ずかしさから疑念を黙っている | その場で伝える：全員で進行方向を確認する |

## 救助隊への合図

- 3 回の何か＝救助要請：3 回の笛、3 回の閃光、3 個の火。
- 避難場所の近くの開けた区域に、コントラストの大きい大型の合図を作る（衣服、雪上の枝）。
- 笛は声より遠くまで届き、あなたを消耗させない（救助合図ガイド）。

## 実践例：山で道に迷った場合

**状況：** 下山中、霧で登山道が消えた；「正しい」と思いながら一時間進んだが、どこにも見覚えがない。

**実行：** 1. その場でSTOP：これ以上下りに一歩も進まない。 2. 登ってきた道をたどり直せるか？ 一時間かかっても、最後の確実な目印まで戻る。 3. 霧が濃く閉ざしたら：中腹で避難場所を確保し、夜明けを待つ。 4. 視界があれば：傾斜の緩い幅広の尾根筋を選び、目印を付ける。 5. メッシュのSOSを有効にし、開けた場所では数分ごとに笛を吹く。

**避ける：** 「水音がする」沢を下らない、夜に歩かない、急斜面で近道を即興で選ばない、絶えず電波を探して携帯電話の電池を消耗しない（ビーコンモード）。

**エスカレーション：** 誰かが転倒して歩けない場合：斜面下方へ動かしてはいけない――安定化する（骨折／外傷ガイド）、その場で避難場所を確保し、メッシュ＋集中した合図があなたの唯一の任務となる。
