# 山地危险

山会惩罚挑错时辰的人：**午后的闪电、松动的积雪、毒害身体的海拔**都会提前预警——你得会读。

## 关键步骤

1. **雷暴：中午前下撤。** 山里的雷暴在午后成形：中午前登顶，否则回头。头发竖起或空气嗡嗡作响：闪电即将落下。
2. **防雷姿势。** 远离山顶、孤树、线缆和山脊：蹲在背包上（绝缘），双脚并拢，全组彼此拉开15 m——绝不搂抱也绝不躺下。
3. **雪崩：避开30-45°的挂雪坡。** 新雪（降雪后24-48 h）、踩上去发出空洞"whumpf"声的雪板、背风侧的积雪坡：从山脊或平坦谷底绕行。实在没得选就一个一个过。
4. **被雪崩卷走时：** 甩掉雪杖/大背包，朝流体边缘"游"，减速的瞬间：一只手护在脸前撑出气室，另一只手臂朝上举。
5. **高原反应：唯一的药是下撤。** 2,500 m以上头痛+恶心+乏力=停下、补水、不再上升。意识混乱、走路摇晃或静息时喘不上气=立刻下撤，哪怕是夜里，几小时内致命。
6. **落石：** 清晨戴头盔——把石头冻结在一起的冰会被太阳晒化。狭窄石槽：快速通过、一个一个走、不停留、盯紧上方。听到喊"落石！"=贴紧岩壁，没戴头盔不要抬头看。
7. **下山比上山更致命：** 大多数事故发生在下撤路上，又累又急。下山要专注、补水、趁有光。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 顶着正在集结的积雨云冲顶 | 中午前登顶，否则撤退 |
| 在最高的树下躲闪电 | 低处蹲姿，全组分散 |
| 全组一起横穿挂雪坡 | 一个一个过，拉开距离，或绕行 |
| 在高海拔硬扛头痛 | 停下补水；恶化就下撤 |
| 睡到更高处去"熬过"高原反应 | 睡觉高度永远不高于当天最高点 |
| 累了就跑着下山 | 70%的事故发生在下撤 |

## 硬雪坡与碎石坡的通过

- 清晨硬雪：踢出台阶，雪杖插在山上侧，并且永远自问"滑倒了我会停在哪？"
- 碎石坡（松动堆积）：踩稳固的大石头，斜线行进，全组走之字形，绝不上下排成一条竖线（上面的人会踢落石头砸到下面的人）。

## 示例：山地危险

**情况：** 上午11点你爬到半山；西边乌云翻涌，3,000 m以上一名同伴头痛恶心。

**做法：** 1. 立即决断：登顶取消——今天这座山说了不。2. 趁雷暴没到，沿已知路线下撤。3. 高原反应的人先下，有人陪同，边走边补水。4. 雷暴追上：蹲在背包上，彼此分开，远离山脊。5. 到低处集合，再评估症状。

**避免：** 不要"抢在下雨前冲个顶"，不要躲到那棵唯一的树下，不要让高原反应的人独自行动，不要顶着雷暴从落石槽下撤。

**升级：** 高原反应者摇晃或神志不清，就是高原脑水肿（HACE）：立即下撤，必要时抬着走+网状网络SOS；有人被闪电击中，触碰他是安全的——立刻做心肺复苏（见心肺复苏指南）。
