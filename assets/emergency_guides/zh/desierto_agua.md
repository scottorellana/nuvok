# 沙漠中的水

在沙漠里，水就是生命：没有水，在酷热中只能撑**1-2天**。每个决定都要用汗水来衡量。

## 重要步骤

1. **把手里的水喝掉。** 经典的致命错误是"省着喝"：很多人渴死时水壶里还有水。身体储水比水壶更有效。
2. **节省汗水，而不是节省水。** 只在黎明、黄昏或夜间行动；其余时间在阴凉处休息。正午行走每小时消耗1升水。
3. **在干河床找水。** 在干涸河道的外弯处挖30-60厘米，那里沙子颜色更深或长有植物。若沙子变湿，等水渗入坑中。
4. **跟随生命的迹象。** 黎明/黄昏的鸟朝水飞；昆虫群、汇聚的动物足迹和绿色植被都说明附近有水。
5. **黎明收集露水。** 日出前用吸水布在植物上拖拽后拧出；寒夜里光滑的岩石和金属表面也会凝结水珠。
6. **检查岩石积水潭。** 岩石阴影下的凹坑和裂缝能在雨后数周保存雨水。
7. **只要有条件就净化。** 积水潭或挖出的水：煮沸，或用急救包的氯滴（5%浓度每升2滴，等30分钟）。在沙漠里腹泻等于判死刑。

## 不要做的事

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 一边口渴行走一边"存水" | 渴了就喝；节省的是体力 |
| 喝仙人掌汁——害死人的迷思 | 大多数会引起呕吐腹泻：失水更多 |
| 正午顶着太阳找水 | 黎明/黄昏找水；正午待在阴凉处 |
| 喝尿或水箱水 | 加速脱水并中毒 |
| 存水不足1升还进食 | 消化耗水：没水就别吃 |
| 把希望全押在太阳能蒸馏器上 | 产量很低（每天约一杯）；是辅助不是救命 |

## 太阳能蒸馏器（辅助手段，不是奇迹）

1. 在湿润的地面（干河床）挖宽60厘米、深40厘米的坑，或放入捣碎的绿色植物。
2. 坑底中央放一个干净容器。
3. 用透明塑料布盖住坑，边缘用石头/沙子压实密封。
4. 在塑料布中央、正对容器的位置放一颗小石子：锥形让冷凝水滴进容器。
5. 等待6-12小时。每天约产一杯水：如果依赖它，就多做几个。

## 危险脱水的信号

- 尿色深或8小时以上无尿。
- 站起来头晕、头痛剧烈。
- 捏起的皮肤不回弹，口干无唾液。
- 意识混乱或烦躁 → 立即转到中暑指南：这是紧急情况。

## 示例：沙漠中的水

**情况：** 车辆在沙漠公路上抛锚；每人只剩1升水，救援可能超过一天才到。

**做法：** 1. 留在车辆旁（阴凉+易被发现）。2. 渴了就喝，不要"省"。3. 在清晨和傍晚寻找附近干河床，在外弯处挖坑。4. 用现有塑料给每人做一个太阳能蒸馏器。5. 标记位置并启动网状网络SOS。

**避免：** 不要正午行走，不要喝仙人掌汁或尿液，水不足时不要进食，不要在没有标记方向的情况下离开车辆。

**升级：** 如果有人停止出汗、意识混乱或倒下，就是中暑：立即遮阴、打湿衣服、扇风，并转到中暑指南——这是沙漠的头号急症。
