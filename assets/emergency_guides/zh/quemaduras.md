# 烧伤

> ⚠️ 本指南不能替代专业医疗护理。尽快寻求医疗帮助。

## 严重程度分类

| 程度 | 外观 | 疼痛 | 示例 | 是否看医生？ |
|-------|-----------|-------|---------|----------|
| **1度** | 发红、干燥、无水疱 | 疼痛 | 晒伤 | 如果面积大 |
| **2度** | 有水疱、湿润、发红 | 非常疼 | 沸水 | 总是需要 |
| **3度** | 白色/炭化、干燥 | **不疼**（神经坏死） | 直接火焰 | 紧急 |
| **4度** | 可见骨/肌肉 | 不疼 | 电、长时间火烧 | 危急 |

## 立即该做什么

```
1. 停止烧伤
   └── 远离热源/电源/化学物质

2. 冷却（不要冷冻）
   ├── 温水/冷水流动冲洗 15-20 分钟
   ├── 不要直接用冰（会更伤皮肤）
   └── 不要用冰水（可能导致低体温）

3. 脱去衣物/首饰
   ├── 剪开粘住部位周围的衣物（不要扯下）
   └── 在肿胀前取下戒指和手表

4. 覆盖
   ├── 使用无菌纱布或干净布料，松散覆盖
   ├── 不要用棉花（会粘住）
   └── 不要用乳膏、牙膏、油脂、冰

5. 缓解疼痛
   └── 止痛药（对乙酰氨基酚/布洛芬）
```

## 绝对不要放在烧伤处的东西

| ❌ 不要使用 | 原因 |
|------------|---------|
| 直接用冰 | 会冻伤组织，造成更多损害 |
| 牙膏 | 刺激并困住热量 |
| 油脂/油 | 困住热量，导致感染 |
| 棉花 | 会粘在伤口上 |
| 用于破裂水疱的抗生素乳膏 | 可能困住细菌 |

## 什么时候需要紧急去医院？

| 严重信号 | 原因 |
|-------------------|-------|
| 任何 3 度烧伤 | 有休克和感染风险 |
| 大于手掌的 2 度烧伤 | 有脱水风险 |
| 面部、手、脚、生殖器、关节 | 可能限制活动 |
| 环形烧伤（环绕肢体） | 肿胀时可能切断血液循环 |
| 化学或电烧伤 | 看不见的内部损伤 |
| 非常年幼或年长者 | 皮肤更脆弱 |

## 化学烧伤

1. 如可能，戴手套
2. 清洗前先**刷掉**干燥的化学粉末
3. 用大量清水冲洗 **20+ 分钟**
4. 小心脱去受污染衣物
5. **不要使用中和剂**（反应会产生更多热量）

## 电烧伤

> ⚠️ 外表很小的电烧伤，内部可能非常严重

| 操作 | 细节 |
|--------|---------|
| 触碰前先切断电流 | 你自己触电帮不了任何人 |
| 寻找 2 处伤口 | 电流的入口和出口 |
| 评估心脏 | 可能导致心律失常 → 必须做心电图 |

## 实践示例：烧伤

**情况：** 在厨房里，热水泼到一个人的前臂上，皮肤剧烈疼痛。

**要做：** 1. 确保现场安全，并指定一名具体人员呼叫急救。 2. 按照指南中的大步骤依次进行，不要跳到看起来更戏剧化的步骤。 3. 如果有手套、屏障或干净布料，就使用它们。 4. 每分钟重新评估：呼吸、意识、出血、体温或是否恶化。

**避免：** 不要即兴进行高级操作；如果怀疑颈部/脊柱损伤，不要移动颈部/脊柱；不要给意识混乱者食物/饮料；不要为了寻找完美设备而延误呼叫。

**升级处理：** 如果没有正常呼吸、胸痛、出血不止、意识混乱、大面积烧伤、可能中毒、妊娠晚期或有多名伤者，请立即呼叫或转运。

**快速检查：** 在结束本指南前，大声说出发生了什么、你做了什么、还缺什么，以及谁继续负责。此示例是引导式练习；根据你的环境调整步骤，并在有专业帮助时优先选择专业帮助。
