# 在沼泽和红树林中移动

在沼泽里不是行走：**每一步都要谈判**。泥地消耗的体力是小路的 5 倍，而直线往往是最慢的路线。

## 关键步骤

1. **始终使用探路杖。** 2 m 的结实树枝：每一步在承重前都要先试探。看上去绿色、坚实的地方，可能只是深泥上的一层硬壳。
2. **踩根系和草丛，不踩空地。** 红树林根系和草丘能支撑；它们之间“开阔的路”是泥潭。即使要走之字形，也要从一丛到另一丛。
3. **陷入深泥：趴下。** 直立挣扎会陷得更深。分散重量：胸部压在探路杖或背包上，然后缓慢“游”回去，一次拔出一条腿。慢就是胜利；恐慌会把人埋住。
4. **红树林中的潮汐 = 你的时钟。** 在退潮时进入，在涨潮前离开：涨潮时的红树林会抹去地面和参照物。进入时标记你的最晚离开时间。
5. **固定方向，否则永远绕圈。** 没有参照物时，沼泽会让人绕圈走：用指南针/太阳固定方位，并每 50 步用远处物体（高树、天线）确认一次。
6. **水到腰部：拖着走，不要抬脚。** 让脚贴着底部滑行，可避免踩入坑洞，也避免每次从泥里“拔出”靴子的耗力。背包腰带松开，以便必要时丢弃。
7. **天黑前离开水中。** 夜间沼泽属于爬行动物和蚊子：搭干燥平台，生烟熏火驱虫，并穿封闭衣物（危险指南）。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 穿过“更直接”的泥地空地 | 从根到根，从草丛到草丛 |
| 直立对抗吞人的泥 | 趴下，分散重量，向后游出 |
| 在涨潮时进入红树林 | 退潮时进入，并留足时间离开 |
| 不确认方向就“直走” | 指南针/太阳 + 每 50 步确认远处参照 |
| 每一步都把脚抬出泥 | 脚贴着底部拖行 |
| 天黑后仍留在水里 | 天黑前搭干燥平台 + 生火 |

## 节奏和能量

- 在耗尽体力前休息：干地每小时 10 min；泥地会收利息。
- 补水量要是你以为所需的两倍：在潮湿环境中，你出汗比自己察觉的更多。
- 每次休息都检查腿和脚：水蛭和被水掩盖的伤口（取水蛭时用指甲沿其口部滑开，不要硬扯或烧灼）。

## 实用示例：在沼泽中移动

**情况：** 想穿过红树林抄近路去海岸；40 分钟后，泥从脚踝深变到膝盖深，潮水开始上涨。

**操作：** 1. 查看你的最晚时间：潮汐已经主导——放弃这条近路。2. 沿着自己的足迹和已知草丛原路返回。3. 每一步都把探路杖放在前面。4. 如果泥把你吞住：趴下，胸部压在探路杖上分散重量，一条腿一条腿出来。5. 到干地后：检查双腿、补水，并从陆地绕过红树林。

**避免：** 不要为了“赶快”而穿过直接的空地，不要在潮水上涨时继续前进，不要丢下探路杖，不要直立挣扎。

**升级处理：** 如果有人被困且无法用该技巧脱身：不要进入同一片泥——从稳固基点递出探路杖/绳索/打结的衬衫，并用树枝垫在其胸下分散重量；通过 mesh 的 SOS 发送你的精确位置。
