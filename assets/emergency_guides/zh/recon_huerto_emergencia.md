# 应急菜园

储备食物会在数周内耗尽；如果今天种对东西，**菜园会在 20-30 天开始回报**。这不是园艺：这是热量后勤。

## 关键步骤

1. **今天就种长得快的：** 萝卜（20-30 天）、绿叶菜——甜菜叶、菠菜、芥菜、采摘型生菜（30-45）、豆类/四季豆（50-60）、黄瓜和西葫芦（45-60）。储藏室里发芽的土豆 = 种薯（带“芽眼”的块，60-90 天）。
2. **没有包装的种子：** 市场/储藏室里的也能用——豆、扁豆、未加工玉米、番茄（种子发酵 2 天后晾干）、辣椒、木瓜、南瓜。烘烤过/抛光过的不会发芽。
3. **错峰播种：** 每 2 周再种同一作物的一批——持续收获，而不是一次吃撑然后挨饿。
4. **阳光 + 水决定地点：** 6+ 小时日照，靠近回用水（灰水瀑流，不含强力肥皂），任何容器都可用：轮胎、麻袋、破桶、铁皮槽。
5. **快速建立活土：** 土 + 堆肥/陈年粪肥 + 腐叶。营地堆肥（果皮、冷灰）供养循环——任何有机物都不丢弃。
6. **保护投资：** 简单围栏（树枝、网、麻袋）防鸡和狗；黎明/傍晚直接浇根部（正午会蒸发并灼伤）。
7. **收叶而不杀死植株：** 剪甜菜叶/芥菜的外层叶，留下中心——同一株能产数月。留存收获物中最好的种子：第 2 个菜园免费开始。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 只种玉米“因为顶饱” | 先种快的（萝卜/叶菜）；玉米需要 90-120 天 |
| 一次全部种下 | 每 2 周错峰播种 |
| 正午用水柱浇 | 黎明/傍晚浇根部 |
| 用含肥皂/氯的灰水浇菜园 | 只用无强力化学品的冲洗水或洗涤水 |
| 为了几片叶子拔掉整株 | 采外层叶：植株继续生产 |
| 丢掉果皮和灰 | 堆肥：这是第 2 个月的肥料 |

## 每平方米热量（空间优先级）

1. 土豆/红薯：每 m² 热量之王。
2. 豆类/四季豆：蛋白质 + 固氮（改善土壤）。
3. 南瓜/ayote：产量高，可保存数月。
4. 绿叶菜：快速提供维生素，避免疾病。

## 实用示例：应急菜园

**情况：** 灾后第 2 周；捐赠食物够一个月，营地旁有一块阳光充足的空地。

**做法：** 1. 今天：清理 5×5 m，种萝卜 + 芥菜 + 储藏室里会发芽的东西（土豆、豆）。 2. 市场番茄：发酵种子，装入罐头盒育苗。 3. 用树枝做围栏，并用冲洗水安排浇水轮班。 4. 2 周后：第二批播种并移栽育苗。 5. 在空地角落建立社区堆肥。

**避免：** 不要等“好种子”才开始，不要把整块空地都种玉米，不要用肥皂水浇，不要让空地没有围栏。

**升级处理：** 如果捐赠在收获前中断：在每一米空地优先种热量作物（土豆/豆/ayote），如果有河流则启动捕鱼/陷阱（指南），并通过 mesh 与街区协调用收成交换——菜园多样性是所有人的保险。
