# 沼泽危险

沼泽的危险很有耐心：**凯门鳄守在岸边，蛇守在树枝上，感染守在每一道泡过水的擦伤里**。

## 关键步骤

1. **敬畏开阔水域的岸线。** 凯门鳄/鳄鱼在水陆交界处捕猎，尤其在黎明/黄昏。取水和过河要选宽阔、视野好的位置，绝不在漂浮植物之间，夜里绝不碰浑水。
2. **逃生距离：离水5米**再扎营或收拾鱼（腥味会把它们招来）。绝不在热带浑水里"下去凉快凉快"。
3. **抓树枝前先看一眼。** 蛇就趴在你脸和手高度的树枝上休息。在沼泽里，先用杖拨开植被，身体再过去。
4. **鳄类攻击（守住第1-3条就极罕见）：** 攻击它的眼睛和吻部，制造声响猛打——猎物太难缠它们通常会松口。上了岸：走直线远离水边跑（在陆地它们追不远）。
5. **每道伤口当场清洗包扎。** 沼泽的水几小时就能让擦伤感染：饮用水/煮过的水+肥皂清洗，擦干，盖好。每天检查腿脚2次——这里一个水泡就是一扇门。
6. **水蛭：用指甲，不用火。** 指甲/刀背沿它的口器平推使其松口；火烧或硬拔会让它把胃里的东西吐进伤口（感染）。之后清洗包扎。
7. **小动物的暗钩：** 河魟（走路拖着脚），带硬刺的螃蟹和鲶鱼（别把手伸进洞里），红火蚁（歇脚前看清站的地方）。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 在水边扎营/收拾鱼 | 离水5+ m，内脏残渣远离营地 |
| 在浑水里"扑腾一下" | 热带浑水绝不下：你看不见正在看你的东西 |
| 不看就抓树枝 | 杖先到，眼再到，手最后到 |
| 硬拔/火烧水蛭 | 指甲沿口器推开，清洗包扎 |
| 无视"小小的"擦伤 | 全部清洗+包扎；每天检查2次 |
| 夜里沿岸边走 | 夜班是爬行动物的 |

## 等不得的感染信号

- 红肿扩散、局部发热、化脓、从伤口向上爬的红线。
- 伤口泡水后发烧。
- 行动：煮过的水+肥皂每天清洗2次，包扎，尽早撤离——热带的感染是跑着来的。

## 示例：沼泽危险

**情况：** 黄昏在水道边钓上了鱼；要收拾鱼、扎营地，还有人腿上叮着水蛭。

**做法：** 1. 营地设在离水10 m处，平台架高。2. 鱼拿到远处收拾，内脏残渣丢进下游的活水，不留在营地旁。3. 用指甲取下水蛭，煮过的水清洗后包扎。4. 生冒烟的火，全组检查双脚。5. 入夜后谁也不回岸边。

**避免：** 不要在黑水边上收拾鱼，不要火烧水蛭，不要把内脏丢在睡觉的地方旁边，天黑时不要让任何人单独去取水。

**升级：** 被蛇咬：固定伤肢，记下确切时间，转咬伤指南+网状网络SOS；伤口红肿扩散或发烧=优先撤离——在沼泽里，感染是一场你一放松它就赢的慢性急症。
