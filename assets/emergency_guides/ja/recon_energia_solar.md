# 基本的な太陽光エネルギー

電力網がなければ、**パネル一枚＋自動車用バッテリー一つが地域の発電所**になる。電話（メッシュはそれに依存する）、夜間照明、ラジオ。ただし、考えて接続する場合に限る。

## 重要な手順

1. **地区の部品を集める：** 温水器／庭園灯／住宅のパネル、自動車用バッテリー（エンジンを始動できなくても、電話は何週間も充電できる）、車用インバーター（12V→USB／110V）、銅線。
2. **最小実用システム：** パネル →（あればコントローラー）→ 12Vバッテリー → 車用USB／小型インバーター。コントローラーなし：パネルは日中の数時間だけ接続し、マルチメーターがあればバッテリーが約14Vを超えないことを測る。沸騰させるより、少ない時間の方がよい。
3. **極性を常に守る：** 赤／＋は＋へ、黒／−は−へ。逆にするとインバーターを壊し、バッテリーが破裂することがある。1日目からテープでケーブルに印を付ける。
4. **向け方と清掃：** パネルは直射日光へ向ける（北半球なら南）、傾きはおおよそ自分の緯度、影はケーブル一本の影も含めてかけない（小さな影でもパネル全体を落とす）。毎朝ほこりを清掃する。
5. **ワットの優先順位を決める：** 1番目はメッシュ用電話と懐中電灯（通信と安全）、2番目はラジオ、3番目は夜間の共同LED照明。小型システムで冷蔵庫／アイロンは絶対に使わない。バッテリーを一時間で殺す。
6. **鉛バッテリーを大切に扱う：** 深く放電させない（LEDの明るさが大きく落ちたら停止）、毎日充電する、風通しのよい日陰に置く、充電時に水素ガスが出るため、人が寝る閉め切った部屋には絶対に置かない。
7. **規則のある地域充電ステーション：** 時間、各シフトの担当者、ラベルを付けて並べた電話。秩序よく充電された20台の電話は、コンセントを奪い合う3軒の家より価値がある。

## やってはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| パネルを電話に直接つなぐ | 常にバッテリー／コントローラー、または車用USBを介する |
| 「動くか試す」ために極性を逆にする | ケーブルに印を付け、二度確認する |
| ベッドのそばでバッテリーを充電する | 風通しのよい日陰、火花と寝室から離す |
| 明かりが消えるまでバッテリーを放電する | 早めに止める。深放電はバッテリーを殺す |
| 小型システムに冷蔵庫をつなぐ | 電話／LED／ラジオのみ。ワットが足りない |
| 「それでも充電する」とパネルに小さな影をかける | 部分的な影＝パネルはほぼ死ぬ。移動する |

## どれだけ使えるか（正直な数字）

- 50 Wパネルは、良い日差しで一日あたり電話15～20回分の充電に相当。
- 使用済み自動車用バッテリーは、日光なしで電話＋LEDを約2～4日分。
- 庭園用ソーラーライト＝1台の電話用の緊急夜間充電器（分かるならUSBを流用する）。

## 実践例：太陽光エネルギー

**状況：** 電力網なしの2週目。地区は2枚の50 Wパネル、ピックアップのバッテリー、車用インバーターを集めた。

**行うこと：** 1. 中央の中庭にステーションを設置する。パネルは影のない日なたに置き、傾け、バッテリーは風通しのよい日陰に置く。 2. ケーブルに印を付け、パネル→バッテリー→インバーター／USB。 3. 黒板に規則を書く：充電時間、シフト担当、メッシュ優先。 4. バッテリー保護のため、毎日夕方早めに停止する。 5. 夜明けに乾いた布でパネルを清掃する。

**避けること：** 「少しだけ」と冷蔵庫をつながない、バッテリーを日なたや閉め切った部屋に置かない、時間外の無断接続を許さない、濡れた手で端子に触れない。

**拡大対応：** バッテリーが膨らむ、腐った卵のにおいがする、または沸騰する場合：すべてを切断し、換気して撤去する。爆発の危険がある。バッテリーなしでは、パネルは日中だけ車用USBへ直接使用し、メッシュは通信を時間帯で配給する。
