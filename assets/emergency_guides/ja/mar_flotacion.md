# 海で浮いて生き延びる

水中では泳いで生き延びるのではない：**浮いて体温を保つことで生き延びる**。泳ぐと消耗し、体が冷える。浮くことが計画である。

## 重要な手順

1. **まず浮く、泳がない。** 冷水ショックで 1-2 分間あえぐような呼吸になる：仰向けに浮き、呼吸し、何かを決める前にパニックが過ぎるのを待つ。
2. **浮くものはすべてつかむ。** クーラーボックス、ポリタンク、板、船体の残骸：あなたの体と海底の間では、どんな浮力体もあなたの筋力より価値がある。
3. **寒さに対する HELP 姿勢。** 救命胴衣または浮力体がある場合：膝を胸に寄せ、腕を交差して救命胴衣を強く抱き、動かない。熱喪失を最大 50% まで減らす。集団では：抱き合って円を作り、子どもを中央に置く。
4. **服は着たまま。** 脱衣するという迷信は命取りになる：衣服は体が温める水を保持し、短時間の浮力を与える。沈ませるものだけを外す（浮けない場合の重いブーツなど）。
5. **ズボンを浮き具にする。** 安定して浮いている場合にだけ脱ぐ：両足首をそれぞれ結び、頭上で腰部分から空気を入れて閉じる。数分ごとに空気を補充する。
6. **明確な目的がある場合にだけ泳ぐ。** 見えて到達可能な岸、追い風ならぬ追い潮、近くの浮遊物があるか？ エネルギーを節約して背泳ぎ／平泳ぎで泳ぐ。そうでなければ：動かずに浮いている — 救助者は固定点のほうを見つけやすい。
7. **離岸流：浜と平行に。** 海が沖へ引きずる場合、正面から闘ってはいけない：流れの筋を出るまで海岸線と平行に泳ぎ、斜めに戻る。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 遠い海岸へすぐ泳ぎ出す | 浮き、評価し、落ち着いて判断する |
| 「泳ぎやすくするために」服を脱ぐ | 服は着たまま：保温し、浮く助けになる |
| 離岸流に正面から逆らう | 浜と平行に進み、流れの筋を出る |
| 海水を「少しだけ」飲む | 絶対にしない：脱水を倍加させ、判断を曇らせる |
| 絶えず叫んで暴れる | 船が見えている時に、反射光／衣服で合図する |
| 集団や残骸から離れる | 残骸は浮き、空から見える |

## 水中で体温を保つ

- 水は空気より 25× 速く熱を奪う：低体温症があなたの持ち時間を決める。
- 「温まるために」泳がない：動きは最小限にし、体をまとめる。
- できるだけ体を水から浮力体の上に上げる：半身が水外に出るだけで持ち時間は倍になる。

## 実践例：海で浮く

**状況：** 小型ボートが海岸から 500 m の地点で転覆した。波があり、流れで浜から離されている。

**行うこと：** 1. 呼吸を制御できるまで仰向けに浮く。 2. 他の人と一緒に転覆した船体につかまる：それがあなたの島であり、合図でもある。 3. 集団で抱き合う姿勢を取り、子どもを中央に置く。 4. 流れが離岸流なら、泳力のある者が浜と平行に泳いで助けを探す；残りは船体にとどまる。 5. 携帯電話／金属でどの船にも光を反射させる。

**避けること：** 全員で流れに逆らって浜へ泳がない、服を脱がない、海水を飲まない、船体から離れない。

**エスカレーション：** 制御不能な震えや混乱（低体温症）がある場合、その人を船体の上にできるだけ水から出して乗せ、覆う；陸に上がったら低体温症のガイドへ移行する — 救助後の虚脱は現実に起こる。
