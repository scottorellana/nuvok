# 城市废墟中的危险

残破的城市杀人不出声：**过一会儿就闻不出来的燃气、水洼里的电线、"奇迹般"没倒的墙**——还有人群的恐慌。

## 关键步骤

1. **燃气：先用鼻子，再关阀门。** 臭鸡蛋味或嘶嘶声=什么都不要点（开关也别碰：会打火花）。开门开窗通风，关掉燃气总阀，撤出去，敲门通知邻居——不要按门铃。
2. **每根落地电线都当作带电**，直到电力公司说不带为止。保持一辆公交车的距离（10 m）；有水洼时，水会扩大带电范围。电线砸到你车上：待在车里等救援。
3. **每次余震后重新评估受损结构。** 柱子上的X形裂缝、地板不平、门关不上了=不进去睡。宁可在院里受罪，也别图快睡在楼板底下。
4. **没有消防队的火灾：赢在逃生，不在扑火。** 有烟=爬行（能呼吸的空气在下面），手背试门是热的=不开，湿布捂嘴。只扑纸篓大小的火；再大：撤离并隔离（出门随手关门）。
5. **白天移动，结伴，带着目的地。** 坍塌后街道全变了：避开受损结构下方的通道、倾斜的电杆和恐慌的人群。永远备两条备用路线。
6. **安全不逞英雄：** 保持低调，物资收好不外露，简单加固门（门楔、家具），邻里网络是最好的警报——彼此认识的街区才守得住（见社区组织指南）。
7. **记录并通报：** 拍下自家受损照片（留待日后），把道路/危险状况通过网状网络共享——你一条"桥塌了"的通报，能救后面来的人（战术地图）。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 开灯"检查燃气泄漏" | 不碰任何电器：通风、关阀、出去 |
| 跨过"没电了"的落地电线 | 保持10 m；确认前一律当带电 |
| "扛住了地震"就进去睡 | X形裂缝或门卡住=睡外面 |
| 火灾中打开发热的门 | 先用手背试；热=换出口 |
| 亮出发电机/存粮/武器 | 保持低调加邻里网络 |
| 逆着恐慌人流硬穿 | 贴人群边缘走，绝不迎着中心 |

## 城市危险应急清单

- 燃气阀和水阀：家里每个人都知道在哪、怎么关。
- 厨房备ABC干粉灭火器或一桶沙。
- 床边放包头鞋（防碎玻璃）+手电+哨子。
- 证件复印件装密封袋+应用里的ICE紧急信息卡。

## 示例：城市危险

**情况：** 地震后你那条街停电；邻居家门前有燃气味，湿漉漉的人行道上还搭着一根电线。

**做法：** 1. 心里给电线画出10 m圈，远远地大声警告——谁也不许蹚那滩水。2. 有燃气味的那家：敲门（别按门铃），让他们关总阀、通风、不碰开关。3. 保险起见把你家的燃气也关了。4. 把两处危险发布到网状网络的战术地图上。5. 今晚：查完裂缝再决定进屋睡。

**避免：** 不要打火机"照亮点"，不要拿"干"棍子去挑电线，不要让孩子在附近转悠，不要睡在有裂缝的房子里。

**升级：** 爆炸或火势已起：全街区逆风撤离，启用网状网络的集合点，转由烧伤/坍塌指南接管；触电伤员=没有反应就做心肺复苏（脱离电源后触碰是安全的）。
