Modo Emergencia

Comunicación sin internet via WiFi, Bluetooth y LoRa. Mensajes con confirmación de entrega.

Mapas Offline

Navegación con mapas descargados. GPS, rutas A*, POIs y overlays personalizados.

Biblioteca
