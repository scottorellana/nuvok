# 緊急時の食料：釣りと罠

**まず見通しを持つ：** 食料なしでも数週間は生き延びられるが、水なしでは数日、シェルターなしでは数時間しかもたない。食料は優先順位4である――避難場所、水、合図を確保する前に狩りで体力を使ってはならない。

## 重要手順

1. **まず水場へ行く。** 魚、カニ、川の巻貝は、山野で最も容易で安全なタンパク源である――哺乳類を狩るよりはるかに効率がよい。
2. **釣り針を即席で作る。** 曲げたピン、丈夫なトゲ、針金、鋭くした缶のプルタブ、骨を削った「V」字。釣り糸：コード（パラコード）の内芯、デンタルフロス、布の繊維を撚ったもの。
3. **無料の餌を見つける。** 湿った石／倒木の下のミミズ、昆虫、幼虫。最初の魚の残りは次の魚の餌になる。
4. **小魚用のボトルトラップを作る。** PETボトルの上三分の一を切り取り、胴体の中へ逆向きに差し込む（漏斗を内側へ向ける）。中に餌を入れ、石で沈める。魚は入るが出口を見つけられない。
5. **小川の淵の罠。** 岸に向けて半円形に石の壁を作り、入口を一つだけにする。魚を中へ追い込み、石で閉じる。
6. **罠を働かせたままにし、数時間ごとに確認する。** あなたがシェルターを作ったり合図を出したりしている間に罠が魚を捕る――それが利点である。
7. **すべてを十分に加熱する。** 魚と巻貝は必ず、火で不透明かつ固くなるまで加熱する：淡水には実在する寄生虫がいる。

## 食べても安全なもの（そして食べてはいけないもの）

| ❌ 危険 | ✅ 安全（加熱済み） |
|--------------|---------------------|
| 野生のキノコ――絶対に不可（致死性のものが食用に見える） | 十分に加熱した淡水魚 |
| 100%で識別できない植物 | 加熱した川のカニと巻貝 |
| 「普遍的食用テスト」――危険な神話 | 加熱したミミズと昆虫（明るい色のものを除く） |
| 浮いている死んだ魚、またはよどんだ水の魚 | 自分で捕獲した生きた魚 |
| 両生類（色のあるカエル／ヒキガエル） | 加熱したバッタ／コオロギ、とげのある脚は除く |
| 「鳥が食べているから」という未知のベリー | 絶対的な確信をもって認識できる果実のみ |

## 黄金律

- **完全な確信をもって認識できないなら、食べてはならない。** 空腹はつらいが、山野での中毒は命を奪う。
- **常に、加熱済み＞生。** 火は大半の寄生虫と細菌を無力化する。
- 新しい食べ物は初回に少量を食べ、数時間待つ。
- 水が先であることは変わらない：タンパク質の消化は水を消費する――水がないなら、タンパク質を食べてはならない。

## 最小限の刺し針（ゴージフック）

1. 骨／硬い木の細片を2〜3 cmに削り、両端を鋭くする。
2. 中央を釣り糸に結び付ける。
3. 餌の中に、長手方向に沿って隠す。
4. 魚が飲み込むと、細片が横に引っかかる――曲がった釣り針なしで機能する。

## 実践例：緊急時の食料

**状況：** 小川のそばで迷って三日目。シェルターと水は解決済みで、空腹がこたえている。

**行うこと：** 1. 中にミミズを入れたボトルトラップを、石で沈める。 2. 淵に半円形の石の壁を作る。 3. 合図を出しながら数時間ごとに確認する。 4. すべてを不透明で固くなるまで加熱する。

**避けること：** キノコや未知の植物を食べない、生の魚を食べない、一日を狩りに費やさない：罠は単独で働く。

**エスカレーション：** 何かを食べた後に嘔吐または下痢が現れたら、中毒ガイドへ進み、再水和を優先する。空腹で判断力が弱るなら、水と合図のそばに留まる。
