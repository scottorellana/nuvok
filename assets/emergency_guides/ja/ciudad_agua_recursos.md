# 都市の水と資源

サービスが止まった都市には、**手の届くところに何百リットルもの水が隠れています** — タンク、配管、給湯器の中です。どこにあり、どの順番で使うかを知ることは、探しに出るより価値があります。

## 重要な手順

1. **断水したら、今すぐすべてを満たす。** 最初の数分はまだ圧力がある：浴槽、鍋、ボトル。その後、元栓を閉める（配管内の清潔な水が抜けたり、逆流で汚染されたりするのを防ぐ）。
2. **家には隠れた水がある：** 給湯器／温水タンク（40-60 L：下のバルブ。上階の温水蛇口を開けて空気を入れる）、配管（家で最も低い蛇口を開ける）、トイレの貯水槽（便器ではなくタンク — 飲用化すること）、冷凍庫の氷。
3. **都市の水源の順番：** 1) ボトル水、2) 建物の給湯器とタンク、3) 貯水槽／地下貯水槽、4) プールと噴水は衛生用のみ、または基準をもって消毒した場合のみ（未知の化学物質）、5) 都市河川：最後の手段で、完全な浄化手順を用いる。
4. **都市の雨水も数に入る：** 中庭や屋上に防水シートと容器を置く。最初の数分は捨てる（屋根を洗い流すため）し、消毒する。
5. **疑わしい水はすべて消毒する：** 1 min 煮沸または塩素（計算機）。都市の「澄んだ」水には、破れた配管が地面から拾ったものが含まれていることがある。
6. **略奪なしの資源：近隣ネットワーク。** 近所の人と、誰が何を持っているかを整理する（コミュニティ組織のガイド）：建物のタンク + X さんの家庭菜園 + 隣人の薬局は、奪い合うより分け合うほうが価値があります。
7. **一人一日 3-4 L に配給する**（飲用 + 最低限の調理）：これで、4 人家族は 50 L の給湯器で約 3-4 日生きられる — さらに組織化する時間になる。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 便器の水を飲む | タンク（貯水槽）から取り、消毒する |
| 「塩素処理された」プールの水を飲む | 蓄積した未知の化学物質：衛生用のみ |
| 断水後に元栓を開けたままにする | 閉める：配管内の水を守る |
| 上の蛇口を開けずに給湯器を空にする | 上から空気が入るようにしないと何も出ない |
| 近所に黙ってため込む | 近隣ネットワーク：安全と資源がより長持ちする |
| 処理せずに壊れた配管の「澄んだ」水を飲む | 断水後は常に煮沸または塩素処理する |

## 限られた水での衛生

- ジャグと石けんで手洗い：うまく使った 0.5 L は、流しっぱなしの 3 L より良い。
- 食器／衣類のすすぎ水はトイレに再利用する（バケツから便器へ直接）。
- トイレ用の水がない：便器に二重袋 + 使用ごとに土／灰（衛生ガイド）。

## 実践例：都市の水

**状況：** 地震：地区全体で停電し、水道も止まっている。家族には小さなボトルが 6 本ある。

**行うこと：** 1. 最も低い蛇口を開け、配管に残った水を鍋に入れる。元栓を閉める。 2. 給湯器を排水する（下のバルブ + 温水蛇口を開ける）：+50 L。 3. トイレのタンクの水と氷を回収する。 4. 雨が降る場合に備え、中庭に防水シートを張る。 5. 近所の人と集まる：共用タンクの在庫確認と警備当番。

**避けること：** 飲用水を食器洗いに使わない、建物のプールの水を飲まない、共用タンクから各自が「取れるだけ取る」ことを許さない、消毒せずに飲まない。

**エスカレーション：** 複数の家で下痢が出たら、共用水は汚染されている：使用を中止し、全員が煮沸 + 経口補水液（計算機）へ移り、表示を付ける。mesh で近所全体に通知を伝える。
