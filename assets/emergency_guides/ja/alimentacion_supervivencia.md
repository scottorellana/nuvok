# サバイバル食料

## 黄金律

**「知らないものは、食べてはいけない」**

- 90% 野生植物は安全である
- 10% 残りはあなたを死に至らせる可能性がある

## 昆虫（食用）

### 安全（先に加熱する）
- コオロギ、バッタ
- アリ（特に葉）
- マゲイワーム
- セミ

### 食べてはいけない
- 毛のあるイモムシ
- 鮮やかな色の昆虫
- 針のあるミツバチ／スズメバチ
- 腐敗している死んだ昆虫

## 魚

### 処理方法
1. 内臓を直ちに取り除く
2. 頭と尾を取り除く
3. 清潔な水で洗う
4. 完全に加熱する

### 有毒な魚（食べない）
- フグ
- 一部の熱帯魚の種類

## 哺乳類の肉

### 処理技術
1. 完全に放血する
2. 皮と内臓を取り除く
3. 心臓／肝臓を除き、臓器は廃棄する
4. 十分に加熱する（中途半端な加熱はしない）

### 安全な動物
- 小型獣：ウサギ、ノウサギ、リス
- げっ歯類：ラット、マウス
- シカ（いる場合）

### 危険な動物
- 病気で死んだ動物
- 肉食動物（キツネ、アライグマ）
- 口に泡を吹いている動物

## 安全な植物

###果物
- ブラックベリー、野生のイチゴ
- 野生リンゴ（種は除く）
- ブドウ、イチジク

### 野菜
- シダの茎（2回ゆでる）
- アザミの根
- ユリの塊茎

### 食べてはいけない
- 白い乳液を持つ植物
- 房状につく赤または黒のベリー
- キノコ（専門家でない限り）
- タマネギに似た球根を持つ植物

## 浄化

### 常に加熱する
- すべての肉：15分以上
- 魚：身がほぐれるまで
- 昆虫：鳴くまで

### 火がない場合
- 魚：新鮮であれば、処理して生で食べる
- 昆虫：生でも安全（幼虫を除く）
- 果物：知っているものだけ

## 保存

### 冷蔵なし
- 日なたで乾燥させる（肉＋魚）
- 煙があれば燻製にする
- 塩があれば塩漬けにする

### おおよその消費期限
- 乾燥肉：1週間
- 乾燥魚：3〜5日
- 塊茎：数週間
- 乾燥果物：1か月

## 実践例：サバイバル食料

**状況：** 電力が数日間途絶え、四人分の食料を配給する必要がある。

**行うこと：** 1. 30秒間立ち止まり、主要な危険を明確にする。 2. 水、防寒具、照明、通信手段、安全な経路を集める。 3. 今リスクを下げる最も単純な行動を実行する。 4. 別の人が継続できるよう、実施済みの内容をメモ／チェックリストに記録する。

**避けること：** 計画なしにバッテリーを消耗しない、流れている水を渡らない、知らない植物を食べない、集団から離れない、避難場所を設営するのに暗くなるまで待たない。

**エスカレーション：** 天候が悪化する、体温が下がる、安全な水が不足する、脆弱な子ども／高齢者がいる、または方向感覚を失う場合は、計画を変更する。

**クイックチェック：** ガイドを閉じる前に、何が起きたか、何をしたか、何が残っているか、誰が責任を持つかを声に出して言う。この例はガイド付きの実践である；手順をあなたの環境に合わせ、専門的支援が存在する場合はそれを優先する。
