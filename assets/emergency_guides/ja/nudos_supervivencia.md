# 命を救う結び

五つの結びでサバイバルの95%をカバーする：救助する、縛り付ける、張る、つなぐ、確保する。**今日、コードで練習せよ** — 緊急時には手が震え、学ぶ時間はない。

## 重要手順

1. **もやい結び（bowline）— 救助の結び。** 抱え込む対象に締まらない固定ループ：人を引き上げる、または確保するために使う。「蛇が井戸から出て、木を回り、井戸に戻る」。荷重がかかった後でもほどきやすい。
2. **クローブヒッチ（clove hitch）— 支柱への素早い固定。** 丸太／支柱に交差する二回巻き。構造物（シェルター、いかだ）の開始と終了に使う。注意：断続的な引きで緩む — ハーフヒッチで止める。
3. **張り綱結び（taut-line hitch）— 調整できるロープ。** 張力下でつかむスライド式の結び：シート、シェルターの張り綱、物干しを張る。手では滑らせられ、荷重がかかると自ら食い込む。
4. **二重テグス結び — 二本のロープをつなぐ。** ロープを延長する安全な方法で、太さが違っていても濡れていても使える。二つの結びが互いを抱き合い、コンパクトになり、ずれない。
5. **角縛り（square lashing）— 棒を十字に結合する。** 構造物用：シェルター、いかだ、担架、三脚。最初のクローブヒッチ + 各軸に3回巻き + 締め付けるための絞め巻き2回 + 最後のクローブヒッチ。

## どれをいつ使うか

| 必要なこと… | 結び |
|-----------|------|
| 人を上げる／下ろす／確保する | もやい結び |
| 支柱への縛着を始める、または終える | クローブヒッチ + ハーフヒッチ |
| シートまたはシェルターの張り綱を張る | 張り綱結び |
| 別のロープでロープを延長する | 二重テグス結び |
| 二本の丈夫な棒を結合する（担架、いかだ、シェルター） | 角縛り |

## してはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| スリップノットで人を引き上げる | もやい結び：ループは胸の上で締まらない |
| 目を閉じて結び直せない結びを信用する | 必要になる前に20回練習する |
| 単純な結び（「靴ひも」の結び）でロープをつなぐ | 二重テグス結び；単純な結びは荷重でずれる |
| 結びの後に10 cm未満の端を残す | 十分な余りを残す：結びは荷重時にロープを「食う」 |
| 損傷したロープを人の荷重に使う | ロープ全体を点検する；一本の撚りが切れている = 救助には廃棄 |

## ロープの管理

- 砂と日光はロープを劣化させる：巻いて、日陰で、清潔に保管する。
- 濡れると強度を約10-15%失う；余裕を持って結ぶ。
- 人の体重には10×の余裕を見込む：80 kg → 最低800 kgのロープ。

## 実践例：命を救う結び

**状況：** 仲間が3メートルの溝に落ち、良いロープがある。

**実行：** 1. もやい結び：胸の上で締まらない固定ループ。2. 両脇の下に通す。3. 自分側の端をクローブヒッチ + ハーフヒッチで木に固定する。4. 純粋に腕だけではなく、ロープを肩にかけて歩きながら引き上げる。

**避ける：** 人にスリップノットを使わない、習熟していない結びを即興で使わない、損傷したロープで引き上げない、10 cm未満の余り端を残さない。

**エスカレーション：** その人がつかまれない、または頭部／脊柱を打つ転落があった場合、ロープで動かしてはならない：その場で安定化し（外傷ガイド）、緊急チャンネルで助けを求める。
