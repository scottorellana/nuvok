# 洪水

## 洪水の前
1. **自分の地域を知る** — 自分が洪水区域（浸水想定区域）に住んでいるか確認する
2. **書類を上げる** — 重要書類を高い場所に保管する
3. **備える** — 非常用キットを準備しておく

## 洪水の最中
1. **水の中を歩かない** — 徒歩でも車でも。15cm の水で倒される可能性がある
2. **運転しない** — 30cm の水で車が流される可能性がある
3. **水位が上がる場合** — 屋根または高い場所へ上がり、救助を待つ
4. **電気を切る** — 家の中に水が入る危険がある場合
5. **落ちた電線から離れる** — 通電している可能性がある

## 洪水の後
1. **許可を待つ** — 安全だと宣言されるまで家に戻らない
2. **構造物に注意する** — 浸水した建物は不安定な可能性がある
3. **消毒する** — 汚水に触れたものはすべて細菌を含む可能性がある
4. **被害を写真に撮る** — 保険のため
5. **濡れた機器を使わない** — 電気技師が確認するまで

## 警戒レベル
- **注意報** — 今後 6-12 時間以内に洪水の可能性
- **警報** — 洪水が差し迫っている

## 必須キット
- 飲料水（3+ 日分）
- 救急箱
- 懐中電灯 + 笛
- 非常用ラジオ
- 予備電池

## 実践例：洪水

**状況：** 家の前の通りに水がたまり始め、さらに上昇している。

**行うこと：** 1. 30 秒止まり、主な危険を定める。 2. 水、防寒、明かり、通信、安全な経路を集める。 3. 今すぐリスクを減らす最も単純な行動を実行する。 4. 他の人が続けられるよう、実施済みをメモ／チェックリストに記録する。

**避けること：** 計画なく電池を消費しない、流れる水を渡らない、知らない植物を食べない、集団から離れない、暗くなってから避難場所を設営しようと待たない。

**エスカレーション：** 天候が悪化する、体温が下がる、安全な水が不足する、子ども・高齢者などの脆弱な人がいる、または方向感覚を失う場合は計画を変更する。

**クイックチェック：** ガイドを閉じる前に、何が起きたか、何をしたか、何が残っているか、誰が責任者として残るかを声に出して言う。この例はガイド付き実習である；手順を自分の環境に合わせ、専門的支援が存在する場合はそれを優先する。
