# 森林中的危险

森林里几乎没有东西会主动猎杀你：**大多数事故是自己造成的** — 你踩哪里、手伸哪里、睡哪里。

## 关键步骤

1. **看清落脚点和抓握处。** 90%的蛇咬发生在脚和手：踩在倒木上（不看清另一侧绝不迈过去），绝不把手伸进树洞、石头下或落叶堆。
2. **声音是你的护盾。** 走路时发出自然声响：几乎所有动物听到你来都会避开。危险在于让它们受惊。
3. **用之前抖一抖。** 早晨抖靴子、衣服和背包：蝎子和蜘蛛夜里会钻进去取暖。
4. **躲避处先看头顶。** 悬挂的枯枝（"寡妇制造者"）、蜂巢、树上的蚁窝 — 枯枝比猛兽害死的人更多。
5. **遇到蛇：静止，然后后退。** 慢慢退两步；它不想把毒液浪费在吃不下的东西上。绝不要碰它"把它拨开"，死蛇也不行（咬合反射）。
6. **蜂群来袭：直线跑远。** 至少200-300米，能穿灌木就穿；不要跳水（它们会等你出来）。护住脸和脖子。
7. **严重咬伤或蜇伤时**，转到咬伤蜇伤指南：固定伤肢、记录时间，绝不用止血带也不要吸毒液。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 把手脚伸进看不见的地方 | 先看清，用棍子拨动 |
| 直接睡在落叶地面上 | 用树枝垫高床铺+检查周围 |
| 靠近"被遗弃"的幼崽 | 母兽就在附近：立刻离开 |
| 触摸毛毛虫、彩色蛙类或有乳白汁液的植物 | 鲜艳颜色=化学警告 |
| 在灌木丛中惊慌奔跑 | 稳步行走：摔倒是头号事故 |
| 把食物挂在睡觉的地方旁边 | 食物放50米外并挂高：别把动物请到床边 |

## 真正的危险排序

1. **摔倒和扭伤** — 野外真正的头号事故。
2. **坠落的枯枝** — 永远先看头顶。
3. **昆虫**（黄蜂、蚂蚁、蜱虫、蚊子）— 送医人数超过所有哺乳动物总和。
4. **蛇** — 看清落脚点即可避免。
5. **蜇人植物和荆棘** — 不清理会感染。
6. **大型哺乳动物** — 排最后：它们躲着你。

## 蜱虫和水蛭

- 蜱虫：用镊子夹住头部，缓慢直线拔出。不要烧它或用酒精泡（会反吐）。
- 水蛭：用指甲从它的吸盘处滑入使其脱落；不要硬扯。
- 记下被咬日期：之后几天发烧=就医。

## 示例：森林中的危险

**情况：** 天色渐暗，你在捡柴火，倒木之间落叶很深。

**做法：** 1. 先用长棍拨动落叶再伸手。2. 踩上每根倒木、看清另一侧再下脚。3. 正常出声地捡柴。4. 睡前抖靴子、检查庇护所头顶。

**避免：** 不要夜里捡柴，不要把手伸进洞里，不要碰鸟巢蜂巢，不要在庇护所里放食物。

**升级：** 被蛇咬或蜂群多处蜇伤（或过敏征兆：脸肿、呼吸有哨音），立即转到咬伤/蜇伤指南并启动网状网络SOS。
