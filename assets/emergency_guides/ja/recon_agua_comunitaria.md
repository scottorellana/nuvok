# 地域の飲用水

地区は、**安全な水が運ではなくシステムである**ときに成り立つ。水源＋処理＋公平な配給を、住民が運用する。

## 重要な手順

1. **主要な水源を一つ選び**、保護する。井戸、川の最良区間、または大きな屋根（学校／教会）からの雨水回収。水源を一つにすれば、処理と監視を集中できる。
2. **水源を物理的に保護する：** 洗濯をしない、動物が飲まない、トイレを近づけない範囲を設ける（最低30 m、トイレは下り勾配側）。看板とロープだけでもすでに「インフラ」である。
3. **簡易処理ステーション：** 番号を付けたドラム缶で沈殿（1日目、2日目）、粗ろ過（布／砂）、アプリの計算機で測定した塩素処理（2滴/L、5%で。規模換算：1小さじ ≈ 100滴 ≈ 50 L claros）。
4. **家庭での残留塩素テスト：** 30 min後、水はごくわずかに塩素のにおいがするはずである。においが全くない＝一度だけ再投与。強いにおい＝投与量が多すぎるため、換気し、次回の分を調整する。
5. **量と時間を決めた配給：** 一人一日Xリットル（5～7 Lから始める）、固定の順番、そして高齢者／病人のための指定運搬者。規則のある列は、すべてを壊す争いを防ぐ。
6. **水の記録簿：** どれだけ処理したか、どれだけの塩素で処理したか、誰が運用したか。誰かが病気になれば追跡できる。運用者が休んでも知識が残る。
7. **失敗の兆候を監視する：** 複数の家で下痢＝今日中にシステム全体を確認する（水源汚染、汚れたドラム缶、期限切れの塩素）とともに、その間は煮沸へ移行する。

## やってはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| 各家庭が「自分流」で処理する | 測定投与と記録簿を備えた一つのステーション |
| トイレや洗い場を水源のそばに置く | 30+ m、かつ下り勾配側 |
| 濁った水をそのまま塩素処理する | 塩素の前に必ず沈殿とろ過を行う |
| 「先に来た人順」で配給する | 一人当たりの量、時間、運搬者を決める |
| ドラム缶にふたも番号もない | ふたをし、ローテーションし、日付を記す |
| 下痢の事例を隠す | 直ちに知らせる。それがシステムの警報である |

## システムを拡大する

- 50軒 ≈ 最低1,500～2,000 L/日：10本の200 Lドラム缶をローテーションする。
- 各シフトに運用者二人、3日ごとに交代（疲労は投与量を誤らせる）。
- 雨：公共の屋根ごとにドラム缶へ。システムは無料で拡大する。

## 実践例：地域の水

**状況：** ハリケーンから1週目。40世帯があり、学校の井戸は使えるが、人々は汚れた容器で無秩序に列を作っている。

**行うこと：** 1. 短い集会：井戸を唯一の水源とし、周囲の保護範囲と時間を決める。 2. ステーション：番号付きドラム缶6本。沈殿、ろ過、計算機で塩素処理し、30 min待つ。 3. 配給：一人一日7 L、名簿付きの列、高齢者のいる8軒のための運搬者。 4. ドラム缶に貼った記録簿＋各回のにおいテスト。 5. 容器：ふた付きのみ。ポリタンク洗浄ステーションは別に置く。

**避けること：** 井戸で洗濯させない、沈殿させずに塩素処理しない、量を決めずに配給しない、化学薬品用ポリタンクを使わない。

**拡大対応：** 3軒以上で下痢：全体の即時煮沸、水源／ドラム缶／投与量の点検、影響を受けた人への計算機を使った経口補水液、故障箇所が見つかるまでメッシュで地区全体に通知する。
