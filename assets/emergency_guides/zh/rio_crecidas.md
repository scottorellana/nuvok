# 河流涨水

河水上涨的速度**比你背着营地奔跑还快**。战胜涨水要在事前：你在哪里搭营、监测什么、什么时候离开。

## 关键步骤

1. **在高处扎营：5 米规则。** 绝不要在河弯内侧的河滩、河中岛或沙洲上扎营——那是暂借的河道。寻找高阶地，查看过去涨水痕迹（挂在高处的树干、被压倒梳平的草），并待在它们上方。
2. **上游的天空说了算。** 即使你这里有太阳，山里打雷或下雨：河水也可能在几分钟内上涨。上游流域多云 = 营地进入警戒。
3. **插下你的水位见证杆。** 到达时在水边插一根树枝：如果水淹没它，或河流声音变得更低沉，就撤营——不要和趋势争辩。
4. **涨水已经开始的信号：** 水突然变浑、夹带小树枝和泡沫、轰鸣声增强、闻到翻动泥土的气味。出现任何一种 = 所有人立即上高阶地。
5. **向上撤离，不要沿河下游。** 如果沿岸逃向下游，涨水会和你同行。垂直于河流上升到能俯瞰山谷的地形。
6. **被困在岛上或车内：上到车顶/高点并发送 SOS。** 不要试图涉过涨水（30 cm 的急流水可击倒成年人；60 cm 可冲走汽车）。等待：突发洪水会在数小时内回落。
7. **涨水后，不要信任地面。** 被冲刷掏空而会塌陷的河岸、新水坑、不稳定的树干：行走时远离边缘 24-48 h。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 在“靠近水边，多方便”的小河滩扎营 | 高阶地，高于旧洪水痕迹 |
| 相信本地蓝天 | 监测上游流域；河水来自远处 |
| 留下来收拾整个营地 | 人先于物：河水不会等待 |
| 涉过“才到膝盖”的涨水 | 30 cm 急流水会击倒人；等待水位下降 |
| 沿河岸向下游奔逃 | 垂直上升到高地 |
| 靠近被冲刷的边缘观看 | 涨水后河岸会坍塌 |

## 雨季渡河和扎营

- 清晨尽早过河：山地河流会因融雪/每日降雨在下午上涨。
- 睡前始终确认你的垂直逃生路线：在 60 秒内，你往哪里上升？
- 儿童和不会游泳者睡在营地的高处一侧。

## 实用示例：河流涨水

**情境：** 营地距离河流 3 m；傍晚时上游山区雷声很大，虽然你们头顶有星星。

**要做：** 1. 营地警戒：穿好鞋，手边备好手电。 2. 每 15 min 检查你的水位见证杆。 3. 水淹没了树枝并出现泡沫：所有人带着身上现有物品立即上到高阶地。 4. 在上方清点队伍；任何人不得回去取东西。 5. 若有人被隔离，发送 mesh SOS。

**避免：** 不要睡“再睡一小时看看会不会过去”，不要“换到对岸更好”而过河，不要回去拿背包，不要在水变清并持续下降之前下去。

**升级：** 如果有人被冲走：不要跳下去——沿岸向前跑到他的下游前方，在缓流河段抛出绳子/长树枝，并大声给出指令（脚朝下游，见渡河指南）；为救援人员标记你最后看到他的位置。
