# 重度出血

> ⚠️ このガイドは専門的な医療を代替するものではありません。可能になり次第、医療支援を求めてください。

人は**5分未満**で失血死することがあります。呼吸していることを確認した後、出血を止めることが最優先です。

## 迅速評価

| 出血の種類 | 危険か？ | 対応 |
|-----------------|------------|--------|
| 噴き出す、または拍動する（動脈） | 🚨 数分で致命的 | 直ちに圧迫 |
| 持続的に流れ、衣服を濡らす | 🚨 重度 | 直ちに圧迫 |
| 少量ずつ滴り、自然に凝固する | ⚠️ 軽度 | 洗浄して包帯 |
| 血液の流出を伴わない打撲痕 | ✅ 内部 | ショックを観察 |

## 今すぐ行動する

1. **全体重をかけて圧迫する**。ガーゼか清潔な布を出血点に当て、10分以上、確認のために持ち上げない。
2. **染み通ったら、上にもう1枚重ねて**圧迫を続ける。下の布は絶対に外さない。
3. **腕や脚で止まらない場合**、傷の5-8cm上に止血帯を巻く。関節の上には絶対に巻かない。
4. **出血が止まるまで締め**、時刻を記録する。緩めない：それは病院で行う。
5. **首・脇の下・そけい部の場合**、傷口にガーゼを指で奥まで詰め、その上から圧迫する。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 血で濡れた布を取り除く | その上に別の布を重ねる |
| 刺さった物を抜く | 周囲を包帯で固定する |
| 首・胴体・頭部に止血帯を巻く | 腕と脚のみに使用する |
| すでに巻いた止血帯を緩める | 病院でのみ緩める |
| 噴き出すように出血している傷を洗う | まず出血を止める |

## 処置の段階的強化

```
ステップ 1: 防護
├── 手袋またはビニール袋（他人の血液＝病気）
└── ない場合：それでも行動する。命が最優先
     │
     ▼
ステップ 2: 露出させる
├── 衣服を切る、または裂く
└── どこから出血しているかを見なければならない
     │
     ▼
ステップ 3: 強い直接圧迫 ← 圧迫を維持できるならここから始める
├── 出血点に清潔なガーゼ／布を当てる
├── 全体重をかけて圧迫する（痛むが、それでよい）
├── 最低 10分、確認のために持ち上げずに続ける
└── しみ通る場合 → 別の布を上に重ねて続ける
     │
     ▼ 腕／脚で止まらないか？
ステップ 4: 腕／脚で、かつ大量出血の場合
└── すぐ止まらない場合、切断がある場合、または圧迫を維持できない場合は早期に止血帯
     │
     ▼ 首・腋窩・鼠径部の接合部、または深い傷の場合
ステップ 5: パッキング（首、鼠径部、腋窩）
├── ガーゼ／布を空洞の中へ入れる
├── 指で奥まで詰める
└── その上から圧迫する
     │
     ▼ それでも腕／脚から出血する場合
ステップ 6: 止血帯
├── 4-5 cmの丈夫な布（ワイヤーは絶対に使わない）
├── 傷より5-8 cm上に巻く
├── 結び目 → 棒 → 結び目 → 止まるまで回す
├── 棒が巻き戻らないよう固定する
└── 時刻を記録する
```

## 止血帯 — 詳細

| パラメータ | 値 |
|-----------|-------|
| 材料 | 幅4-5 cmの布（ネクタイ、丸めたTシャツ） |
| 絶対に使わない | ワイヤー、細いひも、細いベルト |
| 位置 | 傷より5-8 cm上、心臓に近い側；傷が見えない場合は、四肢の高い位置で強く締める |
| 避ける | 関節上（肘、膝） |
| 目標 | 出血を完全に止める |
| 時刻 | 止血帯または本人の額に記録する |

> ⚠️ 装着時には非常に強く痛みます — これは正常で、機能していることを意味します

## 失血によるショックの表

| 段階 | 兆候 | 対応 |
|------|---------|--------|
| 代償期 | 不安、冷たい皮膚 | 出血を止め、横にする |
| 進行期 | 蒼白、発汗、口渇、速い脈 | 脚を上げ、保温する |
| 重症 | 混乱、弱い脈、青みがかった唇 | 緊急搬送 |

## いつ助けを求める／搬送するか

- 重度出血、止血帯、またはパッキングを行った場合は**必ず** → 緊急に病院へ
- 軽度の出血：閉じない場合、咬傷の場合、または物が汚れていた／錆びていた場合（破傷風）は医師へ

## 実践例：重度出血（止まらない出血）

**状況：** 中庭で、誰かが薄い金属板で切り、数秒で血液がタオルにしみ込んでいる。

**行うこと：** 1. 現場の安全を確保し、特定の人を指名して救急へ通報させる。 2. より劇的に見える手順へ飛ばさず、ガイドの大きな手順を順番に行う。 3. 手袋、バリア、または清潔な布があれば使用する。 4. 毎分再評価する：呼吸、意識、出血、体温、または悪化。

**避けること：** 高度な手技を即興で行わない。損傷が疑われる場合は首／脊柱を動かさない。混乱している人に食べ物／飲み物を与えない。完璧な器材を探して通報を遅らせない。

**エスカレーション：** 正常に呼吸していない、胸痛がある、止まらない出血、混乱、広範囲の熱傷、毒物の可能性、妊娠後期、または複数の傷病者がいる場合は、直ちに通報または搬送する。

**迅速確認：** ガイドを閉じる前に、何が起きたか、何をしたか、何が残っているか、誰が責任者として残るかを声に出して言う。この例はガイド付きの実践である；手順を自分の環境に合わせ、専門的支援が存在する場合はそれを優先する。

## 科学的根拠と即興対応

- STOP THE BLEED/ACSに基づく：直接圧迫、接合部の深い創傷へのパッキング、生命を脅かす四肢出血への止血帯。
- 即席の止血帯は幅広く（4-5 cm）、出血が止まるまで締めなければならない；ワイヤー、細ひも、ケーブルは損傷を増やし、しばしば失敗する。
- しみ込んだ層を取り除かず、装着した止血帯を緩めない；上に材料を追加し、時刻を記録して搬送する。
