# 地震

## 揺れている間
1. **走らないでください** — 窓、ガラス、落下する可能性のある物から離れてください
2. **身を守ってください** — 頑丈なテーブルの下、または内部の壁のそばにいてください
3. **つかまってください** — 揺れが収まるまで固定されたものにつかまってください
4. **車の中にいる場合** — 橋や電柱から離れた安全な場所に停車してください
5. **路上にいる場合** — 建物、電柱、電線から離れてください

## 揺れの後
1. **自分の安全を確認してください** — けがをしていないか確認してください
2. **余震を想定してください** — 数時間または数日間、余震が起こる可能性があります
3. **損傷した建物から離れてください** — 不安定な構造物に入らないでください
4. **閉じ込められている場合は助けを求めてください** — 空洞のある物をたたき、叫ぶのは最後の手段にしてください
5. **懐中電灯を使ってください** — ガス漏れの可能性がある場合はマッチに火をつけないでください

## 事前準備
- [ ] 家の中の安全な場所を特定する（テーブルの下、内部の壁のそば）
- [ ] 背の高い家具を壁に固定する
- [ ] 懐中電灯、笛、救急箱を手の届く場所に用意する
- [ ] ガス、水道、電気の止め方を知っておく
- [ ] 家族で避難訓練を行う

##緊急キットの推奨内容
- 予備電池付きの懐中電灯
- 非常用の笛
- 完全な救急箱
- 水（一人一日当たり 1 ガロン、最低 3 日分）
- 腐敗しない食品
- 電池式ラジオ
- 防水袋に入れた重要書類

## 実践例：地震

**状況：** 訓練中、家族は居間におり、ドアへ走らずに対応しなければなりません。

**行うこと：** 1. 立ち止まり、30 秒間で主な危険を特定します。 2. 水、防寒具、照明、通信手段、安全な経路をそろえます。 3. 今すぐリスクを減らす最も単純な行動を実行します。 4. 別の人が引き継げるように、実施したことをメモ／チェックリストに記録します。

**避けること：** 計画なしに電池を消耗しないでください、流れている水を渡らないでください、知らない植物を食べないでください、集団から離れないでください、避難場所を設営するために暗くなるまで待たないでください。

**段階的対応：** 天候が悪化した場合、体温が低下した場合、安全な水が不足した場合、脆弱な子ども／高齢者がいる場合、または方向感覚を失った場合は、計画を変更してください。

**迅速確認：** ガイドを閉じる前に、何が起きたか、何をしたか、何が不足しているか、誰が責任者として残るかを声に出して言ってください。この例は誘導型の実践です。手順を自分の環境に合わせて調整し、専門的な支援がある場合はそれを優先してください。
