# 社区组织

灾后，**最稀缺的资源不是水：而是信任**。组织起来的街区能用很少资源生存；互相争斗的街区连富足都会浪费。

## 关键步骤

1. **第一次短会，今天就开：** 最多 20 分钟，站着开，邀请所有住户。三个点：有什么（清点）、什么最急（水/健康/厕所）、谁负责每项任务。公开记录。
2. **按能力分配角色，不按嗓门大小：** 水（社区指南）、健康（懂的人 + 急救包 + 本 app）、环境卫生、脆弱人群登记、夜间安全、通信（mesh + 白板）。每个角色都有替补。
3. **白板就是真相：** 一个实体点，写上：人员名单（安全/寻找中）、用水规则、轮班、下次会议、需求/提供。它能杀死谣言，而谣言是第 #2 号敌人。
4. **在冲突前制定资源规则：** 每人用水量、按名单排队、共同做饭更省粮，捐赠物公开分配——关起门来分发一天内就会破坏信任。
5. **每日 15 min 会议**（同一时间、同一地点）：做了什么、还缺什么、交接。简短并站着开：没完没了的会议会杀死参与度。
6. **冲突：冷静时、有见证人处理。** 两个发生冲突的人不要在队伍里吼着谈判：记录下来，在会议上或由 2-3 位受尊重的邻居处理。公开黄金规则：攻击他人的人失去排队轮次，不失去口粮（用饥饿惩罚会升级暴力）。
7. **向外连接：** 街区间的 mesh 会产生倍增效应（交换、医生、战术地图警报）；准备好的书面登记会在当局/NGO 到来时加速处理——有文件的街区先得到援助。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 等“某个人”来组织 | 第一次会议任何人都能召集：就是你 |
| 一个领导决定一切 | 分散角色、设替补，并公开白板 |
| “为了避免争吵”私下分发 | 所有分发都在众目睽睽下：不透明就是争端 |
| 开 3 小时会议 | 每天站着开 15-20 min |
| 用扣食物/水来惩罚冲突 | 可以扣轮次和分配任务；绝不可扣生存口粮 |
| 忽视老人、儿童和病人 | 脆弱人群登记，每户有负责人 |

## 组织者工具包

- 白板/墙 + 炭笔或记号笔。
- 登记本：每户人数、医疗需求、技能。
- 本 app 的 mesh：街区频道 + 集合点 + 战术地图。
- 会议哨子（3 声 = 开会）。

## 实用示例：社区组织

**情况：** 洪水后第 2 天；30 户家庭在学校，捐赠食物杂乱到达，两名邻居差点为毯子打起来。

**做法：** 1. 用哨子召集：在院子开 20 min 会议。 2. 在白板上公开清点并分配角色：水、公共厨房、登记、厕所、夜间安全。 3. 捐赠物分类后按家庭名单当众分发。 4. 差点发生的争执：会议后由 3 位邻居冷静处理——毯子按儿童/老人登记优先。 5. 每天上午 7 开会，并建立避难所 mesh 频道。

**避免：** 不要让“最强壮的人”管理捐赠物，不要夜里偷偷分发，不要开马拉松式会议，不要把登记“留到以后”。

**升级处理：** 如果冲突升级为暴力，或有人用威胁囤积：安全行动成对进行（绝不要单独一人），记录在本子里，将资源隔离并由 3 人轮流看管，并通过 mesh 与当局建立桥接——街区的力量在于所有人都看得见一切。
