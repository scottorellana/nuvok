# 分诊 — 先救谁？

> 适用于伤员很多而救援人员很少的紧急情况的简化 START 方法。

## 决策树

```
                        能行走并说话吗？
                       /                \
                     是                 否
                     │                  │
                  🟢 绿色           呼吸吗？
                  （可以等待）      /        \
                                   是         否
                                   │          │
                              大量出血吗？  打开气道
                              /         \       头后仰
                            是          否      现在呼吸吗？
                            │           │      /          \
                        🟠 橙色      🟡 黄色    是          否
                        （出血）     （稳定）    │            │
                                              有脉搏吗？     │
                                              /          \      否
                                            是           否     │
                                         🟠 橙色       ⚫ 黑色  │
                                                                      │
                                                    🔴 红色
                                                  （立即心肺复苏）
```

## 分诊类别

| 颜色 | 状态 | 行动 | 例子 |
|-------|--------|--------|----------|
| 🔴 **红色** | 危重，有即时帮助可能存活 | 首先处理 | 不呼吸（气道已开放）、严重休克 |
| 🟠 **橙色** | 严重，需要帮助但可以等待 1h | 止血 | 严重出血、开放性骨折 |
| 🟡 **黄色** | 稳定，可以等待数小时 | 固定、观察 | 闭合性骨折、轻伤 |
| 🟢 **绿色** | 轻伤，能行走 | 自我处理 | 小割伤、瘀伤 |
| ⚫ **黑色** | 打开气道后仍无反应 | 优先处理活着的人 | 无恢复的心搏骤停 |

## 黄金规则

1. **伤员很多时，不要在一个患者身上耗费时间**
2. **每 15 分钟重新评估一次** — 绿色可能变成红色
3. **给每名伤员做标记**，标上颜色（胶带、记号笔、衣物）
4. **在所有活着的人得到处理前，不要移动黑色类别伤员**

## 60 秒方案

| 步骤 | 时间 | 行动 |
|------|--------|--------|
| 1 | 0-10s | 大喊：**“谁能走路？”** → 这些是绿色 |
| 2 | 10-30s | 对剩下的人：呼吸吗？不呼吸者 → 打开气道 |
| 3 | 30-50s | 呼吸者：大量出血吗？→ 橙色 |
| 4 | 50-60s | 其他人 → 黄色。打开气道后仍不呼吸者 → 黑色 |

> 💡 目标不是拯救所有人。而是尽可能拯救更多人。

## 实用示例：多伤员分诊（先救谁？）

**情境：** 地震后有多人呼救，而你只有一个小急救包。

**做：** 1. 确保现场安全，并指定一个具体的人拨打急救电话。 2. 按顺序遵循指南中的主要步骤，不要跳到看起来最戏剧化的步骤。 3. 如有可用，使用手套、屏障物或干净布料。 4. 每分钟重新评估：呼吸、意识、出血、体温或是否恶化。

**避免：** 不要临时 improvisar 高级操作；如怀疑颈部/脊柱损伤，不要移动颈部/脊柱；不要给意识混乱者食物/饮料；不要因寻找完美装备而延误呼叫。

**升级：** 如果呼吸不正常、有胸痛、出血不止、意识混乱、大面积烧伤、可能中毒、妊娠晚期或有多名伤员，立即呼叫或转运。

**快速检查：** 在结束指南前，大声说出发生了什么、你做了什么、还缺什么以及谁继续负责。本示例是引导式练习；请根据你的环境调整步骤，并在存在专业帮助时优先考虑。
