# 最初 72 小时

冲击过后，接下来的 72 小时里，**社区就是政府**：外部援助会迟到——你们有序完成的事，胜过一百次临时 improvisation。

## 关键步骤

1. **第 0-1 小时：人员。** 清点家庭成员（mesh 会合点），按指南处理伤员（若人数多则分诊），并且不要重新进入受损结构（坍塌指南）。
2. **第 1-6 小时：外部危险。** 关闭燃气，标记 10 m 处的电缆，用红布标出有风险的结构——在 mesh 战术地图上制作一张社区危险地图。
3. **第 6-12 小时：诚实盘点。** 按家庭并共同统计：水、食物、药品、工具、发电机，以及技能（护士、泥瓦匠、电工）。写下来的内容不争议。
4. **第 12-24 小时：水和卫生优先。** 在需求迫使人临时应付之前，确保经处理的水源（社区用水指南）和应急厕所（卫生指南）——否则疫情会在第 3 天开始。
5. **第 2 天：角色和轮班。** 简单协调（组织指南）：供水、健康、夜间安全、脆弱人群登记（老人、婴儿、慢性病患者及其已清点药物）。
6. **第 2-3 天：通信和信号。** mesh 在无信号时连接社区；设置一个实体信息点（黑板/墙面），列出人员平安名单、寻找名单和需求——减少恐慌和谣言。
7. **黄金规则：先稳定，再重建。** 在缺少安全用水时，不要在第 1 天修屋顶；最初 3 天的秩序决定接下来一个月。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 每个家庭各自“解决自己的事” | 第 1 天完成共同盘点和角色分工 |
| 为了物品返回受损房屋 | 没有任何东西值得让余震砸在身上 |
| 把卫生问题“留到以后” | 第 1-2 天建好厕所：疫情不会等待 |
| 先耗尽所有瓶装水 | 立即开始处理水源，并保留瓶装水 |
| 谣言和吼叫式决策 | 信息黑板 + 固定的短会 |
| 默默囤积 | 写下来并分配的物资更持久，也能避免冲突 |

## 72 h 小时的社区急救箱

- 按住户列出人员名单（以及谁不在）——由 mesh 共享。
- 水：水源 + 处理 + 按量分配。
- 健康：急救包集中 + 会使用的人 + app 指南。
- 能源：一台发电机给所有手机充电 > 照亮五户房屋。

## 实用示例：最初 72 小时

**情境：** 黎明发生强烈地震；你所在街区有 3 栋房屋受损，一名轻伤员，且没有任何官方人员到达。

**要做：** 1. 逐户清点人员，并按指南处理伤员。 2. 关闭街区燃气，在 mesh 地图上标记电缆和裂缝。 3. 开 15 min 会议：盘点、公共用水以及在大地块后方挖沟式厕所。 4. 轮班：供水、儿童/老人、夜间巡查。 5. 在街角设黑板：谁平安、缺什么、下次会议时间。

**避免：** 不要进入有裂缝的房屋，不要在水源旁焚烧垃圾，不要漏登老人，不要等“有人来”才开始组织。

**升级：** 有重伤员或有人被困：使用分诊/坍塌指南 + 通过 mesh 向相邻街区发送 SOS——如果第 2-3 天多户出现腹泻，说明供水出了问题：立即更换水源，并加强厕所和氯消毒。
