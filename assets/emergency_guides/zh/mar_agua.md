# 海上与海岸的饮用水

四周全是不能喝的水：**喝海水脱水的速度比忍着口渴快一倍**。你的命取决于雨水、冷凝水，以及会不会在海岸找水。

## 关键步骤

1. **绝对不要喝海水。** "一小口"不行，掺着喝也不行：肾脏排盐耗掉的水比你喝进去的还多。它加速死亡，而且在那之前先搅乱你的判断。
2. **立刻搭好集雨装置。** 下雨之前就把所有布/防水布/塑料布摊开，中间下凹对准容器。用第一阵雨冲掉积盐，然后再收集。
3. **清晨的露水。** 在船上或海岸：日出前用布擦遍所有光滑表面（玻璃钢、船帆、大叶子），然后拧出水。
4. **在海岸：在第一道沙丘后面挖。** 离海30-60 m处，挖到出水为止；雨水形成的淡水层浮在咸水上面——只用布或杯子取最表层，不要搅动水坑。
5. **找入海口和岩石。** 流向大海的小溪、悬崖上滴水的裂缝、高处岩石上的雨水坑（低处的是咸浪花：用嘴唇试一下，不要咽）。
6. **青椰子=安全的水**（热带海岸）：捡棕榈树下掉落的青椰子。太熟的（棕色）水少油多：吃多了腹泻。
7. **有火或有太阳就蒸馏。** 煮海水，用布罩住接蒸汽再拧出来（粗糙但管用），或做太阳能蒸馏器，把盛海水的容器放进去。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 喝海水"骗骗口渴" | 绝对不行：失去的水比得到的多 |
| 喝尿或鱼血 | 同样脱水；极端情况下鱼眼/鱼脊里的液体也只有一点点 |
| 等下雨了才搭集雨装置 | 一切提前备好；热带阵雨只下几分钟 |
| 从沙滩水坑底部取水 | 只取表层淡水，不搅动 |
| 取浪边低处的水坑 | 那是咸水飞沫；只取高处雨水坑 |
| 没水却大量进食（鱼干、老椰子） | 消化蛋白质/脂肪要耗水 |

## 落水者的优先顺序

1. 先保漂浮和信号（获救往往比渴死来得早）。
2. 集雨装置常设不拆。
3. 省的是汗：用船帆/防水布遮阴，白天用海水打湿衣服降温（天黑前会干），炎热时段保持不动。
4. 没有水配着，就不要进食。

## 示例：海上找水

**情况：** 无动力小艇从昨天起漂流；只剩半升水，远处天色像要下雨。

**做法：** 1. 立刻把防水布搭成漏斗对准水桶，边缘再绑上备用布。2. 真渴了就把半升水喝掉，不要"存着"。3. 清晨擦遍全艇露水并拧出。4. 炎热时段用海水打湿衬衣，待在帆影下。5. 下雨时：先冲洗30秒，然后收集全部。

**避免：** 一滴海水都不要喝，没有水不要吃鱼干，不要放着集雨装置不搭，不要暴晒。

**升级：** 有人喝了海水后出现意识混乱或抽搐，按中暑/抽搐急症处理，把全部淡水优先给他；上岸后先在沙丘后挖水，再往内陆走。
