# 砂漠での水

砂漠では水こそが命です：水がなければ、極端な暑さでは **1-2 日**しか残されません。すべての判断は汗で測られます。

## 重要手順

1. **持っている水を飲む。** 古典的な致命的ミスは「節約する」ことです：人は水筒に水を残したまま脱水で死にます。あなたの身体はボトルよりも上手に水を蓄えます。
2. **水ではなく汗を配分する。** 動くのは夜明け、夕暮れ、または夜だけにする；それ以外は日陰で休む。正午に歩くと、1 リットル／時を消費する。
3. **乾いた流路を探す。** 乾いた小川の外側のカーブで、砂がより暗く見える場所や植生が生えている場所を 30-60 cm 掘る。砂が湿ったら、水が穴にしみ出すのを待つ。
4. **生命のサインを追う。** 夜明け／夕暮れの鳥は水の方へ飛ぶ；昆虫の群れ、合流する動物の足跡、緑の植生の斑点は近くに水があることを示す。
5. **夜明けに露を集める。** 太陽が出る前に、吸水性の布を植生の上で引きずって絞る；寒い夜には金属面や滑らかな岩にも凝結する。
6. **岩のくぼみを確認する。** 岩層の陰になった穴や割れ目（天然の水だまり）は、雨の数週間後まで雨水を保持する。
7. **できるときは必ず浄化する。** 岩の水だまりや掘った井戸の水：煮沸するか、キットの塩素滴下剤を使う（2 滴／リットル、5%、30 min）。砂漠での下痢は宣告です。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 喉が渇いたまま歩きながら水を「取っておく」 | 喉が渇いたら飲む；努力を配分する |
| サボテンの汁を飲む — 人を殺す俗説 | ほとんどは嘔吐と下痢を起こす：さらに多くの水を失う |
| 正午に水を探して歩く | 夜明け／夕暮れに探す；正午は日陰 |
| 尿やラジエーター水を飲む | 脱水を加速し、中毒を起こす |
| 予備が 1 リットル未満で食べる | 消化には水を使う：水がなければ食べない |
| すべてをソーラースチルに頼る | 収量は少ない（一杯／日）；補助であり、救済ではない |

## ソーラースチル（補助であり、奇跡ではない）

1. 湿り気のある地面（乾いた流路）に、幅 60 cm × 深さ 40 cm の穴を掘る、または潰した緑の植生を入れる。
2. 底の中央に清潔な容器を置く。
3. 穴を透明なプラスチックで覆い、縁を石／砂で密閉する。
4. プラスチックの中央、容器の真上に小石を置く：円錐が凝結水を中へ滴下する。
5. 6-12 h 待つ。収量は約 1 杯／日：それに頼るなら複数作る。

## 危険な脱水のサイン

- 尿が濃い、または 8+ 時間尿がない。
- 立ち上がるとめまい、脈打つ頭痛。
- つまんでも戻らない皮膚、唾液のない粘つく口。
- 混乱または易怒性 → 熱射病のガイドへ移る：今すぐ緊急事態です。

## 実践例：砂漠での水

**状況：** 車両が砂漠の道で故障した；一人あたり 1 リットルが残っており、救助には一日以上かかる可能性がある。

**行う：** 1. 車両のそばに留まる（日陰 + 視認性）。 2. 喉の渇きに応じて飲み、「節約」しない。 3. 最初と最後の光の時間に近くの乾いた流路を探し、外側のカーブを掘る。 4. 手元のプラスチックで一人につき一つのソーラースチルを組み立てる。 5. 位置を示し、mesh の SOS を起動する。

**避ける：** 正午に歩かない。サボテンや尿を飲まない。水が少ししか残っていないなら食べない。方角を標示せずに車両から離れない。

**エスカレーション：** 誰かが汗をかかなくなる、混乱する、または倒れる場合、それは熱射病です：今すぐ日陰、衣服を濡らす、あおぐ、そしてそのガイドへ移る — 砂漠で最優先の緊急事態です。
