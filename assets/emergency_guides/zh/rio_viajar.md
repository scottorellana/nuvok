# 沿河而行

"跟着河走就能找到人"只对了**一半**：河确实通向村镇，但紧贴河边的岸恰恰是最危险的路。

## 关键步骤

1. **先决定要不要动。** 如果有人在找你，一个持续发信号的固定点比走出几公里更值钱。只有没人知道你在哪、身体完好、还有整天天光时才移动。
2. **河是你的指南针，不是你的路。** 走河谷高处的山坡或台地，让河保持在视线或听觉范围内——不要走河岸本身（湿滑、被掏空、容易被夹在谷里）。
3. **顺流而下=人烟（几乎总是）。** 聚落沿水而建。往下游走，河谷会张开，出现道路、围栏、农田：一见到就跟上。
4. **在支流最宽处过河**，且要在早晨（见过河指南）。深的支流可能逼你沿它上溯一段：接受它，别硬闯。
5. **峡谷收窄=爬上去绕行。** 两壁收拢、河岸消失时，不要在谷底跳石头继续钻：退回来，爬上山脊从上面绕。
6. **幸存者的节奏：** 每天有效行进4-5小时，天黑前2 h搭好营地（而且要高，见涨水指南），每晚把脚擦干检查。
7. **给救援人员留痕迹：** 石堆、石头摆的箭头、在营地刮下姓名缩写和日期。若有空中搜救：每片开阔地都摆大型对比信号。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 踩着河岸的石头走 | 走高处台地/山坡，河在视线内 |
| "河还在流"就钻进峡谷 | 爬上去绕行；峡谷会困住你 |
| 走到天光最后一分钟 | 提前2 h在高处扎好营 |
| 有人在找你却离开安全点 | 留守加发信号比赶路更值钱 |
| "抄近道"横渡大河 | 每次渡河都是风险：非必要不过 |
| 连着几天湿脚行军 | 每晚擦干检查双脚（战壕足会让你走不了路） |

## 读懂河谷

- 河谷张开、水流变缓：人就在附近。
- 垃圾、罐头、砍刀痕、牛道：跟着走——牲口下河喝水走的是最好走的路。
- 黄昏的炊烟、黎明的鸡鸣、狗叫：每小时静默倾听2分钟。

## 示例：沿河而行

**情况：** 迷路第三天；没人知道你的路线，你身体完好，发现了一条水势坚决向下的河。

**做法：** 1. 先确认：没人会来这里找你——该动身了。2. 爬上河谷台地，顺流而下，让水声留在耳边。3. 堆石标，在每个高处营地刮上日期。4. 遇到峡谷：上山脊绕行。5. 见到第一条牛道或围栏就跟上——人家就在附近。

**避免：** 不要走湿滑的河岸，不要硬闯峡谷和渡口，不要走夜路，不要为了赶路而停止做标记。

**升级：** 途中受伤：切回"固定点"模式——高处显眼的庇护所、三连信号、网状网络SOS加信标；瘸着腿赶路会把几天的救援变成一场悲剧。
