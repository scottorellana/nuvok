# コミュニティ組織化

災害後、**最も不足する資源は水ではない。信頼である**。組織化された地区は少ないもので生き延びる。対立した地区は豊富なものさえ無駄にする。

## 重要な手順

1. **最初の短い集会を、今日行う：** 最大20分、立ったまま、すべての家を招く。三つの項目：何があるか（在庫）、何が急ぎか（水／健康／便所）、誰が各作業を担当するか。公開で記録する。
2. **声の大きさではなく、技能で役割を決める：** 水（コミュニティガイド）、健康（知識のある人＋救急箱＋このアプリ）、衛生、脆弱者の調査、夜間警備、通信（メッシュ＋掲示板）。各役割に代理を置く。
3. **掲示板が真実である：** 物理的な一か所に、人のリスト（OK／捜索中）、水の規則、当番、次の集会、必要なもの／提供できるものを掲示する。うわさを止める。うわさは敵 #2 である。
4. **資源の規則は、紛争の前に決める：** 一人当たりの水の量、リストに基づく列、共同で調理する共用食はより長持ちすること、寄付されたものは公開で分配すること——密室での分配は一日で信頼を壊す。
5. **15 minの毎日の集会**（同じ時刻、同じ場所）：何をしたか、何が不足しているか、交代要員。短く、立ったまま行う。終わりのない集会は参加を損なう。
6. **紛争：冷静な状態で、証人を付けて。** 衝突した二人は列の中で怒鳴り合って交渉しない。記録し、集会で、または尊敬されている近隣住民2〜3人と解決する。公開の黄金律：攻撃した者は順番を失うが、配給は失わない（空腹で罰すると暴力が拡大する）。
7. **外部とつながる：** 地区間のメッシュは効果を増幅する（物々交換、医師、戦術地図からの警報）。準備済みの書面による調査は、当局／NGOが到着したときに対応を速める——記録された地区が先に受け取る。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 「誰か」が組織してくれるのを待つ | 最初の集会は誰でも招集できる：あなたである |
| すべてを決める一人のリーダー | 代理付きで役割を分担し、公開掲示板を置く |
| 「口論を避けるため」に内々に分配する | すべての分配を見える場所で行う：不透明さこそが口論である |
| 3時間の集会 | 毎日、立ったまま15〜20 min |
| 食料／水を取り上げて紛争を罰する | 当番や作業は可。生命維持に必要な配給は決して不可 |
| 高齢者、子ども、病人を無視する | 家ごとに責任者を置いた脆弱者調査 |

## 組織担当者のキット

- 掲示板／壁＋木炭またはマーカー。
- 調査用ノート：家ごとの人数、医療上の必要、技能。
- このアプリのメッシュ：地区チャンネル＋集合地点＋戦術地図。
- 集会用の笛（3回吹く＝集合）。

## 実践例：コミュニティ組織化

**状況：** 洪水後2日目。学校に30家族がいて、寄付された食料は混ざった状態で届き、二人の近隣住民が毛布をめぐってほとんどけんかになりかけている。

**実行：** 1. 笛で招集する：校庭で20 minの集会。 2. 掲示板に公開在庫を出し、役割を決める：水、共同調理、調査、便所、夜間。 3. 寄付品は分類し、家族リストに基づき、見える場所で分配する。 4. けんかになりかけた件：集会後、冷静な状態で近隣住民3人と解決する——毛布は子ども／高齢者の調査に基づき優先する。 5. 毎日午前7時に集会を行い、避難所のメッシュチャンネルを使う。

**避ける：** 「最も強い者」に寄付品を管理させない、夜に隠れて分配しない、長時間のマラソン集会をしない、調査を「後で」にしない。

**エスカレート時：** 紛争が暴力に発展する、または誰かが脅して独占する場合：二人一組で安全確保（決して一人だけでは行動しない）、ノートに記録する、資源を3人の交代制管理下で隔離する、メッシュで当局との橋渡しを探す——地区の力は、全員がすべてを見ていることである。
