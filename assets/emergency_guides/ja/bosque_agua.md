# 森で水を得る

**3の法則：水なしでは3日で死に至る** — しかも脱水すると初日から判断力が落ちます。森に水はあります。読み取り方を知ることが鍵です。

## 重要ステップ

1. **探す前に聞く。** 夜明けと夕暮れに2分間じっと立ち止まる：流れる水の音は遠くまで聞こえます。音に向かって歩く。
2. **登らず、下る。** 水は重力に従います：谷筋と低地を下ってたどる。夕暮れの鳥は水に向かって飛びます。
3. **緑のサインを探す。** より濃く密な植生、アシ、ヤナギ、厚い苔 = 地表近くに水があります。
4. **雨 = 無料で安全な水。** ビニール/タープをV字に張って容器へ。処理せず飲める唯一の水です。
5. **蒸散袋。** 日なたの葉の茂った枝にビニール袋をしっかり縛る：4〜6時間で葉からきれいな水が集まります（少量ですが安全）。
6. **濁った水は浄化の前にろ過。** 布/Tシャツを重ねてろ過：泥と見える虫を除去。ろ過は浄化ではありません。
7. **見つけた水は必ず浄化。** 1分間しっかり沸騰（高地では3分）、または塩素（5%漂白剤を1リットルに2滴、30分待つ — ツールに計算機あり）。

## してはいけないこと

| ❌ 間違い | ✅ 正しい |
|----------|----------|
| 「澄んで見えるから」と水たまりや止水を飲む | 流れる水だけ、必ず浄化 |
| 自暴自棄で雪を食べる・生水を飲む | 下痢はさらに脱水させる：必ず浄化 |
| 喉が渇いてから節水する | 定期的に少しずつ飲む；渇きは遅れて来る |
| 日中の暑さの中で水を探し歩く | 早朝か夕方に探す；汗が少ない |
| 尿や海水を飲む | 脱水を加速する — 絶対にダメ |
| 液があるからと未知の果実やつるを信じる | 完全に見分けられるものだけ |

## 安全な順の水源

1. **直接受けた雨水** — 処理不要で安全。
2. **葉の蒸散（袋）** — 安全だが少量。
3. **湧き水と速い沢** — 必ず浄化。
4. **川と淵** — ろ過+浄化。
5. **止水** — 最終手段：ろ過+強めの煮沸。

## 必要な水の量

- 日陰で安静：**1日2〜3リットル**。
- 荷物を背負って歩行：**1日4〜6リットル**。
- 水の節約は機能しません：節約すべきは汗（朝夕に動き、日中は日陰で休む）。

## 例：森で水を得る

**状況：** 森で迷って2日目。ボトルは昨夜から空で、日差しが強い。

**行動：** 1. 午後半ばまで日陰で待つ。2. 2分間静かに聞く：流水の位置を特定。3. 一番濃い緑に沿って谷を下る。4. Tシャツでろ過し、1分煮沸か塩素30分。5. 雨に備えてタープをV字に張る。

**回避：** 正午に歩かない、生水を飲まない、水なしで食べない（消化は水を使う）、水を探して丘を登らない。

**エスカレーション：** 怪しい水の後に下痢や嘔吐が出たら中毒ガイドへ移り経口補水を準備（計算機）；24時間水が見つからなければ、歩き続けるより救助信号を優先。
