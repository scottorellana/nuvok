# 砂漠の危険

砂漠で人を殺すものは、映画に出てくるものとはめったに一致しません：それは**突然の増水、手を置く地面、そして寝床を作る小川**です。

## 重要手順

1. **乾いた流路では絶対にキャンプしない。** 突然の増水は砂漠の静かな殺し屋です：あなたには見えない 30 km 先の雨が、夜に水の壁を送り込むことがあります。小川が最も快適で平らな場所に見えても、必ず高い地形で眠る。
2. **流路が音を立て始める、または濡れた土のにおいがしたら、高い場所へ走る。** 動いている水のある小川を渡らない：数分で水たまりから奔流になる。
3. **触る前に見る。** ヘビやサソリはあなたが欲しい日陰で休む：石の下、薪、割れ目。石や薪は自分の方へ転がして持ち上げる（生き物は反対側へ逃げる）。見えない場所に決して手を入れない。
4. **毎朝、ブーツと衣服を振る。** サソリは夜にあなたの熱を求めます。履く前に、ブーツを逆さにしてかかとを叩く：必須の儀式です。
5. **杖を持って歩き、強く踏む。** 振動がヘビに知らせる；咬傷の大半は踏んだとき、または手を置いたときに起こる。見つけたら：静止し、ゆっくり後退する — 決して扱わない。「死んでいる」ものでも（頭は反射で噛む）。
6. **砂嵐：止まり、覆い、待つ。** 到達する前に進行方向を標示する（石の矢印）。鼻と口を布で覆い、目を保護し、風よけに背を向けて風に背中を向け、待つ：嵐の中を歩くことは迷うことです。
7. **夜の寒さを尊重する。** 40 °C の一日の後、明け方は 0 °C 前後になり得る：砂漠の低体温症は存在します（暑さとシェルターのガイド）。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 「とても平らで快適な」乾いた小川でキャンプする | 必ず流路から離れた高い地形で |
| 割れ目、穴、石の下に手／足を入れる | まず見る、石は自分の方へ転がして動かす |
| ブーツを振らずに履く | 毎回、逆さにしてかかとを叩く |
| 「死んだ」ヘビを扱う | 頭は数時間後でも反射で噛む |
| 砂嵐の最中に歩く | 止まる、進行方向を標示する、覆う、待つ |
| ヘビ咬傷を切る／吸う | 固定し、時刻を記録し、咬傷と刺傷のガイドへ行く |

## ヘビに咬まれた場合

1. ヘビから離れる；座って落ち着く（心拍が速いと毒が広がる）。
2. その肢の指輪／時計／ブーツを今すぐ外す（腫れます）。
3. 肢を心臓の高さ、またはそれより低く固定する；時刻と腫れの端をペンで印す。
4. 止血帯、切開、吸引、氷は一切しない。
5. 歩くのは最小限にする；可能なら運んでもらう → 咬傷と刺傷のガイド。

## サソリ刺傷

- 局所の強い痛み：洗う、布越しの局所冷却、キットの鎮痛薬。
- 4 h 監視する：流涎、複視、けいれん、または呼吸困難 = 緊急の抗毒素、SOS を起動する。
- 小さな子どものサソリ刺傷は常に緊急です。

## 実践例：砂漠の危険

**状況：** 乾燥地帯で日が暮れかけている；唯一の平らで風よけのある地面は、柔らかい砂の乾いた小川である。

**行う：** 1. それを拒否する：快適さが劣っても、最も近い高い段丘へ 3-5 m 上がる。 2. キャンプを設営する前に、周囲の石や割れ目を自分の方へ転がして確認する。 3. シェルター内でブーツを逆さにする。 4. 朝に嵐になった場合に備え、石の矢印で進行方向を標示する。 5. 防寒を準備する：明け方は寒くなります。

**避ける：** どれほど快適でも流路で眠らない。ブーツを外に置きっぱなしにしない。暗闇で石の下に手を入れない。砂嵐が来たら歩かない。

**エスカレーション：** それでも増水に追いつかれた場合：すべてを手放し、最も高い場所へ登る（水を渡らない）；急速に進む腫れを伴う咬傷または呼吸困難があれば、mesh の SOS を起動し、咬傷のガイドを適用する — 毒との競争です。
