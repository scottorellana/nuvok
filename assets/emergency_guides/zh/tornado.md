# 龙卷风

对付龙卷风，开车赢不了，桥下也赢不了：**赢在地下，或最里面的房间**，靠提前那几分钟。

## 关键步骤

1. **龙卷风逼近的信号：** 天空发绿、突降大冰雹、诡异的寂静接着货运火车般的轰鸣、旋转的墙云或漏斗云。出现任何一个=立刻进避难位置。
2. **最好的避难所在地下：** 地下室或地窖，钻到结实的桌子下，远离窗户。没有地下室：一层最里面的房间（内卫、储物间、走廊）——你和外界之间隔的墙越多越好。
3. **保护姿势：** 蹲下，头抵住内墙，手和手臂护住头颈；床垫/棉被/头盔盖在身上。鞋穿好（过后到处是玻璃和钉子）。
4. **活动板房/铁皮房=永远撤出去：** 任何拖车房或轻质房都扛不住——去邻居的坚固建筑，实在没有就找远离树木和汽车的低洼沟坎，脸朝下趴好，双手抱后颈。
5. **在车里、龙卷风还远时：** 朝垂直于它路径的方向开，奔向坚固建筑。距离近或堵死了：弃车下到低沟——绝不躲桥下（风洞效应会把碎片加速成弹片）。
6. **安静不等于结束：** 可能是风眼，或有第二个涡旋。天空明显放晴或官方解除才出来，出来也要小心：燃气、电线、松动的结构（见城市危险指南）。
7. **过后：像走雷区一样落脚。** 玻璃、钉子、带电电线、不稳的废墟——按坍塌指南搜救人员，用网状网络上报灾情、召集家人。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 开窗"平衡气压" | 迷思：浪费几秒，换来横飞的玻璃 |
| 躲到桥底下 | 开阔低沟，脸朝下趴好 |
| 开车顺着它的方向硬赛 | 垂直于其路径开，或下沟 |
| 在活动板房里"抓紧点撑住" | 永远撤出去：坚固建筑或洼地 |
| 趴窗户拍漏斗云 | 进内屋：玻璃就是弹片 |
| 一安静就出来 | 等天空放晴或官方通知：可能有第二个涡旋 |

## 提前备好你的安全屋

- 提前选定：内部房间、一层、无窗。
- 屋内常备：水、手电、哨子、鞋、随手可拉的床垫、离线版本App。
- 全家1分钟演习：所有人摸黑也能到位。

## 示例：龙卷风

**情况：** 冰雹突至，轰鸣越来越响；你和家人在家，没有地下室。

**做法：** 1. 全体立刻进楼下内卫——谁也不许去看。2. 孩子塞最里面，大人护在外侧，床垫压顶，鞋穿好。3. 低头，手抱后颈，哨子拿在手里。4. 轰鸣过去：等到明确信号再出来。5. 出来要小心：查燃气/电线，通过网状网络报平安并去集合点。

**避免：** 不要开窗，不要出去挪车，不要"就探一秒"头，不要一安静就出门。

**升级：** 人在屋里房子垮了：钻进最结实的结构下（浴缸、实木桌）护住头；随后按坍塌指南救被困者，重伤用止血带/按大出血处理，启动网状网络SOS——最初30分钟全靠你们自己。
