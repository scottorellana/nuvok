# 緊急時の防寒と避難所

## 3-3-3 のルール

- 寒冷環境で防寒なしの 3 時間 = 低体温症
- 水なしの 3 日 = 死亡
- 食料なしの 3 週間 = 死亡

## 避難所の種類

### 緊急（即時）
- **閉じた車両** — 何もないよりよい
- **溝** — 風を防ぐ
- **石／雪の壁** — 風を遮る

### 即席
- **枝の防風壁** — 長い側を風に向ける
- **雪の避難所** — 十分な雪がある場合
- **プラスチックのタープ** — どんなプラスチックでも役立つ

## 基本的な作り方

### 緊急避難所
1. 自然の斜面を探す、または穴を掘る
2. 枝で覆い、その後に土／葉をかぶせる
3. 入口は風下側に向ける
4. 地面から持ち上げた寝床（断熱）

### 迅速なタープ
```
    /\
   /  \  <- プラスチック／ポンチョ
  /____\
```

## 体温

### 低体温症（冷却）
**徴候:**
- 制御できない震え
- 混乱、途切れ途切れの発話
- 協調運動の低下
- 極度の眠気

**処置:**
1. 濡れた衣服を脱がせる
2. 可能であれば皮膚と皮膚を接触させる
3. 意識があれば温かい飲み物を与える
4. 四肢をこすらない

### 熱中症
**徴候:**
- 熱く乾いた皮膚
- 混乱
- 速く強い脈拍
- 体温 >40°C

**処置:**
1. 日陰へ移動する
2. 水で冷やす
3. 意識がない場合は液体を与えない
4. 医療支援を求める

## 服装

### レイヤー（システム）
1. **ベース** — 湿気を体から遠ざける
2. **断熱** — 熱を保持する
3. **保護** — 風／雨

### 優先事項
- 頭を覆う（体熱の 50%）
- 手と足
- 首

## 火

### 迅速な方法
- 火打石 + 金属
- サングラス／虫眼鏡
- 電池 + アルミホイル
- 摩擦（ボウドリル）

### 乾いた材料
- 乾いた木の樹皮
- 紐／パラコード
- 小さな乾いた小枝
- 骨髄のある骨

## 実践例: 防寒と避難所

**状況:** 夕暮れ時に嵐がグループを襲い、衣服が濡れ始めている。

**実行:** 1. 30 秒停止し、主要な危険を定義する。 2. 水、防寒具、光、通信手段、安全な経路を集める。 3. 今すぐリスクを下げる最も単純な行動を実行する。 4. 別の人が継続できるよう、実施済みのことをメモ／チェックリストに記録する。

**避ける:** 計画なしにバッテリーを消耗しない、流れている水を渡らない、知らない植物を食べない、グループから離れない、避難所の設営を暗くなるまで待たない。

**エスカレーション:** 天候が悪化する、体温が下がる、安全な水が不足する、脆弱な子ども／高齢者がいる、または方向感覚を失う場合は、計画を変更する。

**迅速確認:** ガイドを閉じる前に、何が起きたか、何をしたか、何が不足しているか、誰が責任者として残るかを声に出して言う。この例はガイド付きの練習である。手順を自分の環境に適応させ、専門的支援が存在する場合はそれを優先する。
