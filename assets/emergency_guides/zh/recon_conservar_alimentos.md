# 无冷藏保存食物

没有冰箱时，就是在和细菌赛跑：**盐、烟、太阳和糖**是人类的冰箱——而知道什么时候不要吃某样东西，是这门手艺的一半。

## 关键步骤

1. **先吃最先坏掉的东西：** 新鲜肉/鱼（数小时）、乳制品（1 天）、熟食（炎热时 1 天），把米、豆、罐头、根茎类留到后面。每周菜单由腐败速度决定。
2. **日晒干燥（水果、香草、番茄、辣椒）：** 切成薄片，放在干净网架/薄板上，直射阳光并有微风，用蚊帐布覆盖，每天翻动 2 次；每晚搬到屋顶下。到折断而不是弯曲时即完成（2-4 天）。
3. **干肉（tasajo）：** 1 cm 的无脂肪肉条，四面撒盐，挂在太阳/微风下或低温烟上方，直到变暗且僵硬（2-3 天）。脂肪不会干燥：会变酸败——全部去掉。
4. **盐腌鱼：** 蝴蝶式剖开，内外铺厚盐层，压重物堆放一夜，然后日晒干燥。盐很便宜；中毒不便宜。
5. **烟熏 = 干燥 + 风味 + 保护性外壳：** 用硬木（栎木、果木、干红树林木）进行冷/低温烟熏（不是烹熟）数小时。绝不要用树脂木（松木）或有毒木材。
6. **像宝物一样储存：** 所有东西都要充分干燥，放入带盖容器，底部放盐/灰，置于高处、黑暗、通风处；每周检查——一块发霉会污染整罐。
7. **无申诉丢弃规则：** 酸味/氨味、黏液、肉上有霉、罐头膨胀或冒泡 = 丢掉。重建时期，一次集体食物中毒就是第二场灾难。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 为了“更划算”而晾干厚块 | 切成细条：厚的会从内部腐烂 |
| 把脂肪留在要晾干的肉上 | 去脂：脂肪会酸败并毁掉整块 |
| 用松木/油漆木烟熏 | 只用天然硬木 |
| 对闻起来怪的东西“尝一点” | 无申诉丢弃 |
| “差不多干了”就潮湿存放 | 干到会折断，否则回到太阳下 |
| 膨胀罐头“煮开以防万一” | 肉毒中毒：不开罐直接丢掉 |

## 其他穷人的冰箱

- **zeer 陶罐冷却器：** 一个陶罐套在另一个里面，中间填湿沙，上面盖湿布：可为蔬菜降温约 ~10 °C（额外保存数天）。
- **地下储存：** 根茎类（土豆、木薯、胡萝卜）放入装有干沙的箱子/坑中，保持凉爽黑暗：可保存数周到数月。
- **蜂蜜/糖和醋腌：** 如果罐子干净并密封，水果和蔬菜可保存数月。

## 实用示例：保存食物

**情况：** 停电已经 2 天，邻居的一头牛出了事故：有 30 kg 肉和强烈阳光。

**做法：** 1. 今天就做：分配任务——剔骨、去掉所有脂肪、切成 1 cm 的条。 2. 大量撒盐，挂在带蚊帐的框架上，放在阳光和微风中。 3. 用栎木低火，在下风处处理烟熏批次。 4. 夜间：所有东西都搬到屋顶下并覆盖。 5. 第 3 天：僵硬的放入带盐的罐子；脂肪熬成猪油/牛油（立即用于煎炸，不生存放）。

**避免：** 不要带脂肪晾干，不要堆放潮湿肉条，不要把肉留在夜间户外，不要保存任何会弯曲而不是折断的东西。

**升级处理：** 如果有人吃了保存食物后呕吐或腹泻：口服补液盐（计算器）+ 中毒指南，并且所有可疑批次都要丢弃，通过 mesh 通知收到该批次的人——宁可失去食物，也不要失去人。
