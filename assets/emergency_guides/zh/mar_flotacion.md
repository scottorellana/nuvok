# 海上漂浮与求生

在水里活下来靠的不是游泳：**靠的是漂浮和保暖**。游泳耗尽体力、加速失温；漂浮才是计划。

## 关键步骤

1. **先漂浮，不要游。** 冷水刺激会让你喘息1-2分钟：仰面漂浮，调整呼吸，等恐慌过去，再做任何决定。
2. **抓住一切能漂的东西。** 保温箱、塑料桶、木板、船只残骸：在你和海底之间，任何浮具都比你的体力可靠。
3. **用HELP姿势抗寒。** 有救生衣或浮具时：双膝抱胸，双臂交叉压紧救生衣，保持不动。最多可减少50%的热量流失。多人时：围成一圈相互搂抱，孩子在中间。
4. **衣服穿着别脱。** "脱衣好游泳"的迷思会害死人：衣服锁住的水会被体温焐热，还能提供短暂浮力。只丢掉把你往下拽的东西（漂不起来时才丢重靴）。
5. **裤子当浮具。** 只有漂浮稳定时才脱：两个裤脚各打一个结，在头顶上方兜进空气，再从腰部收口。每隔几分钟重新充气。
6. **只有目标明确才游。** 岸边看得见且够得着？水流顺向？附近有漂浮物？用仰泳/蛙泳省力地游。否则：原地漂浮别动——救援人员更容易找到固定不动的目标。
7. **遇离岸流：平行于海滩游。** 海水把你往外海拖时，不要迎着它硬拼：沿与海岸平行的方向游出水道，再斜线游回。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 立即朝远处的海岸游 | 漂浮、评估、冷静决定 |
| "为了游得快"脱掉衣服 | 衣服穿着：保暖又助浮 |
| 迎着离岸流硬游 | 平行于海滩游，游出水道 |
| "就喝一点"海水 | 绝对不行：加倍脱水还会搅乱判断 |
| 不停挣扎喊叫 | 看见船时才用反光物/衣服发信号 |
| 离开同伴或船只残骸 | 残骸漂浮，从空中看得见 |

## 在水中保存热量

- 水带走热量的速度是空气的25倍：失温决定你还剩多少时间。
- 不要靠游泳"取暖"：尽量少动，身体蜷成一团。
- 尽量把身体撑上任何浮具：半身出水，存活时间翻倍。

## 示例：海上漂浮

**情况：** 小艇在离岸500 m处翻覆；有浪，水流正把你带离海滩。

**做法：** 1. 仰面漂浮，直到呼吸恢复控制。2. 和其他人一起抓住翻覆的船体：它是你的岛，也是你的信号。3. 围成一圈相互搂抱，孩子在中间。4. 如果是离岸流，游得最强的人平行于海滩游出去求援；其余人留在船体旁。5. 用手机/金属向任何船只打闪光信号。

**避免：** 不要所有人逆流朝海滩游，不要脱衣服，不要喝海水，不要离开船体。

**升级：** 出现无法控制的发抖或意识混乱（失温）时，把人尽量抬上船体、离开水面并盖住；上岸后转到失温指南——获救后的突然衰竭是真实存在的。
