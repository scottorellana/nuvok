# 川に沿って移動する

「川をたどれば人のいる場所に着く」は**半分だけ**真実である。川は集落に行き着くが、川のすぐ岸は歩くには最も危険な場所の一つである。

## 重要な手順

1. **まず移動するかどうかを決める。** 捜索されているなら、合図を出せる固定地点は何キロも進むことより価値がある。誰もあなたを待っていない、健康である、日中に使える日数がある場合にのみ移動する。
2. **川はあなたの羅針盤であり、道ではない。** 川が見える、または音が聞こえる谷の高い斜面または段丘を歩く。川岸そのものは歩かない（滑りやすい、えぐられている、狭い峡谷状になっている）。
3. **下流 = 文明（ほぼ常に）。** 集落は水に沿っている。下流では谷が開け、道、柵、耕作地が現れる。最初の兆候でそれらに従う。
4. **支流は幅の広い部分で渡る**、かつ朝に渡る（川の渡渉ガイド）。深い支流では、しばらく上流へ進まざるを得ないことがある。受け入れ、無理に渡ろうとしない。
5. **峡谷が閉じてくる = 登って迂回する。** 壁が狭まり、岸が消える場合、岩を飛び越えながら内部を進み続けてはならない。戻り、尾根状の高みに上がり、上から迂回する。
6. **生存者のペース:** 一日あたり有効に使える時間は 4-5 時間、日没の 2 h 前には野営地を整える（かつ高所に。増水ガイド）、足は乾かし、毎晩確認する。
7. **救助者のために痕跡を残す:** ケルン、石の矢印、野営した場所に削って記したイニシャルと日付。空から捜索されている場合は、各空き地に大きくコントラストのある合図を置く。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 川岸そのものの石の上を歩く | 川が見える高い段丘／斜面を歩く |
| 「川は続いているから」と峡谷に入り込む | 登って迂回する。峡谷は閉じ込める |
| 日が暮れる直前まで歩く | 2 h 前に、高所で野営地を設営する |
| 捜索されているときに安全な地点を離れる | 留まって合図を出すことは、前進するより価値がある |
| 「カーブを短縮するために」川を渡る | 渡渉は毎回リスクである。不可欠な場合のみ行う |
| 何日も続けて足が濡れたまま歩く | 毎晩足を乾かして確認する（塹壕足は行動不能にする） |

## 谷を読む

- 谷が開け、水が穏やかになる：人が近い。
- ごみ、缶、鉈で切った跡、牛の小道：それらをたどる — 家畜は楽なルートで水を飲みに下りる。
- 夕暮れの煙、夜明けの雄鶏、犬：毎時間 2 分、静かに耳を澄ます。

## 実践例：川沿いに移動する

**状況:** 道に迷って三日目。誰もあなたのルートを知らず、あなたは無事で、はっきり下っている川を見つけた。

**行うこと:** 1. 確認する：ここでは誰もあなたを捜していない — 移動すべき時である。 2. 谷の段丘へ上がり、水音を聞きながら下流へ歩く。 3. 高所の各野営地にケルンを作り、日付を削って記す。 4. 峡谷に出たら：尾根に上がって迂回する。 5. 牛の小道または柵を最初に見つけたら、それに従う — 家は近い。

**避けること:** 濡れた岸を歩かない、峡谷や渡渉を無理に進まない、夜に歩かない、より速く進むために合図を出すのをやめない。

**エスカレーション:** 途中で負傷した場合：「固定地点」モードに戻る — 視認しやすい高所の避難場所、三重の合図、メッシュのSOSとビーコン。足を引きずって進むことは、数日で済む救助を悲劇に変える。
