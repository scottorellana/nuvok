# 川の増水

川は**キャンプ一式を抱えて走るあなたより速く**上がる。増水への勝負は事前に決まる：どこに設営するか、何を監視するか、いつ去るか。

## 重要手順

1. **高い場所にキャンプする：5メートルの規則。** カーブ内側の川原、島、砂州には決して設営しない — それらは一時的に借りている河道である。高い河岸段丘を探し、過去の増水の痕跡（引っかかった丸太、なぎ倒された草）を見て、その上に留まる。
2. **上流の空が支配する。** 自分の所が晴れていても山で雷が鳴る、または雨が降る：川は数分で増水し得る。上流域が曇り = キャンプは警戒態勢。
3. **目印の棒を立てる。** 到着時に水際へ枝を突き立てる：水がそれを覆う、または川の音がより低くなるなら、キャンプを撤収する — 傾向と議論しない。
4. **すでに増水が進行中の合図：** 水が突然濁る、小枝や泡を運ぶ、轟音が増す、掘り返された土のにおいがする。これらのどれか = 全員が高い河岸段丘へ、今すぐ。
5. **川下ではなく上へ避難する。** 岸沿いに逃げると増水はあなたと一緒に進む。川に対して直角に上がり、谷を見下ろせる地形まで登る。
6. **島または車に閉じ込められた：屋根／高所へ行きSOS。** 増水を渡ろうとしない（速い水30 cmで成人は倒される；60 cmで車が流される）。待つこと：鉄砲水は数時間で下がる。
7. **増水後は地面を信用しない。** えぐられて崩れる岸、新しい水たまり、不安定な丸太：縁から24-48 h離れて歩く。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 「水辺で快適だから」と小さな川原にキャンプする | 古い増水痕の上にある高い河岸段丘 |
| 地元の青空を信用する | 上流域を監視する；川は遠くから来る |
| キャンプを全部撤収するために留まる | 人が先、物は後：川は待たない |
| 「膝に少し届く程度」と増水を渡る | 速い30 cmで倒される；下がるまで待つ |
| 川下へ岸沿いに走って逃げる | 高い地形へ直角に上がる |
| えぐられた縁へ見に近づく | 増水後に岸は崩落する |

## 雨季の渡河とキャンプ

- 早朝に渡る：山の川は午後、日々の雪解け／雨で増水する。
- 眠る前に必ず垂直方向の脱出ルートを確認する：60秒で、どこへ上がるか？
- 子どもと泳げない人はキャンプの高い側で眠る。

## 実例：川の増水

**状況：** 川から3 mの場所にキャンプ；日暮れに、あなたたちの上には星があるのに山の上流で強い雷が鳴る。

**行う：** 1. キャンプ警戒：靴を履き、ライトを手元に置く。 2. 目印の棒を15 minごとに確認する。 3. 水が棒を覆い、泡が来ている：全員が着の身着のまま高い河岸段丘へ今すぐ上がる。 4. 上でグループの人数確認；誰も物を取りに戻らない。 5. 誰かが孤立したらmeshでSOS。

**避ける：** 「通り過ぎるか見よう」ともう一時間眠らない、反対岸へ「その方がよい」と渡らない、リュックを取りに戻らない、水が澄み、持続的に下がるまで降りない。

**エスカレーション：** 誰かが流された場合：飛び込まない — 岸沿いに先回りして走り、流れの遅い区間でロープ／長い枝を投げ、指示を叫ぶ（足を川下へ、渡河ガイド）；救助者のために最後に見た地点を記録する。
