# 湿地の危険

湿地の危険は辛抱強い：**アリゲーターは岸辺で待ち、ヘビは枝で待ち、感染は濡れた擦り傷のすべてに潜む**。

## 重要手順

1. **開けた水際を軽視しない。** アリゲーター／クロコダイルは水と陸の境目で狩りをする。特に夜明け／夕暮れ時。水を取る場所や渡る場所は、幅が広く見通しのよい地点にし、浮いた植生の間は絶対に避け、夜の濁った水には決して入らない。
2. **逃げるための距離：野営または魚をさばく時は水から5メートル。** （においがそれらを引き寄せる）。熱帯の濁った水で「涼むため」に泳いではならない。
3. **枝をつかむ前に見よ。** ヘビは顔や手の高さの枝の上で休む。湿地では、体が通る前に杖で植生を払いのける。
4. **アリゲーターの攻撃（1〜3を守れば極めてまれ）：** 目と吻を攻撃し、音を立て、打つ――高くつく抵抗をするものは放すことが多い。陸上では：水から離れる方向へまっすぐ遠くまで走る（陸上では遠くまで追ってこない）。
5. **すべての傷は直ちに洗って覆う。** 湿地の水は数時間で擦り傷を感染させる：飲用水／煮沸水＋石けんで洗い、乾かし、覆う。足と脚を一日に2回確認する――ここでの水ぶくれは入口になる。
6. **ヒル：爪を使い、火は使わない。** 爪／平らにしたナイフを口の部分に差し入れて外す。焼いたり引きちぎったりすると、傷の中へ吐き戻させる（感染）。その後、洗って覆う。
7. **小動物の釣り針：** 淡水エイ（足を引きずって歩く）、トゲのあるカニやナマズ（穴に手を入れない）、ヒアリ（休むために立つ場所を確認する）。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 水際で野営する／魚をさばく | 水から5+ m離れ、残渣は野営地から遠ざける |
| 濁った水で「ひと泳ぎ」する | 濁った熱帯では絶対にしない：自分を見ているものが見えない |
| 見ずに枝をつかむ | 最初に杖、次に目、最後に手 |
| ヒルを引きちぎる／焼く | 口の部分に爪を入れ、洗って覆う |
| 「小さな」擦り傷を無視する | すべて洗う＋覆う；2×/日確認する |
| 夜に水際を歩く | 夜の番は爬虫類のもの |

## 待てない感染の徴候

- 広がる赤み、局所の熱感、膿、擦り傷から上に伸びる赤い線。
- 濡れた傷の後の発熱。
- 行動：煮沸水＋石けんで2×/日洗い、覆い、早期に避難搬送する――熱帯の感染は速く進む。

## 実践例：湿地の危険

**状況：** 夕暮れに水路のそばで魚を釣った。魚をさばいて野営地を設営する必要があり、脚にヒルを付けている者がいる。

**行うこと：** 1. 野営地は水から10 m離し、高い足場にする。 2. 魚は遠くでさばき、残渣は野営地のそばではなく、下流の流水へ入れる。 3. ヒルは爪で外し、煮沸水で洗って覆う。 4. 煙の多い火を焚き、全員の足を確認する。 5. 夜に誰も水際へ戻らない。

**避けること：** 暗い水の水際で魚をさばかない、ヒルを焼かない、寝る場所のそばに残渣を残さない、夕暮れに誰かを一人で水汲みに行かせない。

**エスカレーション：** ヘビ咬傷：固定し、正確な時刻を記録し、咬傷ガイド＋メッシュのSOSへ；広がる赤みまたは発熱を伴う傷＝優先避難搬送――湿地では感染は、放置すれば勝つ、ゆっくりした緊急事態である。
