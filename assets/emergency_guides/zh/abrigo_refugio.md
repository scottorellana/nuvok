# 紧急情况下的保暖与避难所

## 3-3-3 规则

- 寒冷中无保暖 3 小时 = 低体温症
- 无水 3 天 = 死亡
- 无食物 3 周 = 死亡

## 避难所类型

### 紧急（立即）
- **封闭车辆** — 总比没有好
- **壕沟** — 防风
- **石墙/雪墙** — 挡风

### 临时搭建
- **树枝挡墙** — 将长边朝向风
- **雪地避难所** — 如果有足够的雪
- **塑料篷布** — 任何塑料都可用

## 基本搭建

### 应急避难所
1. 寻找天然坡面或挖坑
2. 用树枝覆盖，然后覆土/树叶
3. 入口背向风
4. 床铺抬离地面（隔热）

### 快速篷布
```
    /\
   /  \  <- 塑料/雨披
  /____\
```

## 体温

### 低体温症（失温）
**体征：**
- 不受控制地发抖
- 意识混乱、说话断续
- 协调能力丧失
- 极度嗜睡

**处理：**
1. 脱掉湿衣服
2. 如可能，皮肤贴皮肤取暖
3. 如果清醒，给予热饮
4. 不要摩擦四肢

### 中暑
**体征：**
- 皮肤发热且干燥
- 意识混乱
- 脉搏快速有力
- 体温 >40°C

**处理：**
1. 转移到阴凉处
2. 用水降温
3. 如果无意识，不要给予液体
4. 寻求医疗帮助

## 着装

### 分层（系统）
1. **内层** — 让湿气远离身体
2. **保温层** — 保留热量
3. **防护层** — 防风/防雨

### 优先事项
- 覆盖头部（身体热量 50%）
- 手和脚
- 颈部

## 火

### 快速方法
- 火石 + 金属
- 太阳镜 / 放大镜
- 电池 + 铝箔
- 摩擦（弓钻）

### 干燥材料
- 干树皮
- 绳索/伞绳
- 小干枝
- 带骨髓的骨头

## 实用示例：保暖与避难所

**情况：** 一场暴风雨在黄昏时突然袭击队伍，衣服开始被淋湿。

**做：** 1. 停下 30 秒，确定主要危险。 2. 集中水、保暖物、光源、通信工具和一条安全路线。 3. 执行现在能降低风险的最简单行动。 4. 在笔记/检查清单中标记已完成事项，以便他人能够继续。

**避免：** 不要无计划地耗费电池，不要穿越流动的水，不要吃不认识的植物，不要与队伍分开，也不要等到天黑才搭建避难所。

**升级：** 如果天气恶化、体温下降、缺乏安全饮水、有儿童/易受伤害的老年人，或迷失方向，请改变计划。

**快速检查：** 在关闭指南前，大声说出发生了什么、你做了什么、还缺什么以及谁负责。此示例为引导式练习；根据你的环境调整步骤，并在有条件时优先寻求专业帮助。
