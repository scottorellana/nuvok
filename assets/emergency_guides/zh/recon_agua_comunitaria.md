# 社区饮用水

一个社区能够维持下去，前提是**安全饮水是一个系统，而不是碰运气**：水源 + 处理 + 公平分配，由邻里共同运作。

## 关键步骤

1. **选择一个主要水源**并保护它：水井、河流中最合适的河段，或大型屋顶（学校/教堂）雨水收集。单一水源 = 集中处理和监测。
2. **从物理上保护水源：** 设定周界，在其中**不得**洗衣、动物不得饮水，厕所不得靠近（至少 30 m，且厕所位于下坡处）。一块牌子和一根绳子已经是“基础设施”。
3. **简易处理站：** 在编号桶中沉淀（第 1 天、第 2 天）、粗过滤（布/沙）以及用应用计算器计量加氯（2 滴/L，浓度 5% — 放大到批量：1 茶匙 ≈ 100 滴 ≈ 50 L 清澈水量）。
4. **家庭余氯测试：** 到 30 min 时，水应有非常轻微的氯味；没有气味 = 再重复一次剂量；气味强烈 = 剂量过多，通风并在下一批调整。
5. **按量按时分发：** 每人每天 X 升（从 5-7 L 开始）、固定时段，并为老人/病人指定运水者。有规则的队伍能避免破坏一切的争执。
6. **用水日志：** 处理了多少水、用了多少氯、由谁操作。如果有人生病，可以追踪；当操作员休息时，知识仍被保留下来。
7. **监测故障信号：** 多户出现腹泻 = 今天检查整个系统（水源污染、桶不干净、氯过期），同时改为煮沸。

## 不该做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 每个家庭“按自己的办法”处理 | 单一处理站，剂量测量并记录日志 |
| 厕所或洗衣处靠近水源 | 30+ m 且位于下坡 |
| 直接给浑水加氯 | 加氯前始终先沉淀和过滤 |
| “先到先得”分发 | 按人计量、固定时间和运水者 |
| 桶不加盖且不编号 | 加盖、轮换并标记日期 |
| 隐瞒腹泻病例 | 立刻报告：这是系统警报 |

## 扩展系统

- 50 户 ≈ 每天最低 1,500-2,000 L：10 个 200 L 的桶轮换。
- 每班两名操作员，每 3 天轮换（疲劳会导致剂量错误）。
- 下雨：每个公共屋顶接入桶中——系统可免费扩展。

## 实用示例：社区用水

**情境：** 飓风后第 1 周；40 个家庭，学校水井可用，但人们拿着脏容器混乱排队。

**做法：** 1. 短会：水井将作为唯一水源，设周界和时间表。 2. 处理站：6 个编号桶——沉淀、过滤、用计算器加氯并等待 30 min。 3. 分发：7 L/人/天，按名单排队，为 8 户老人指定运水者。 4. 日志贴在桶上 + 每批做气味测试。 5. 容器：只用带盖容器；另设水桶清洗站。

**避免：** 不要让人在水井处洗衣，不要未经沉淀就加氯，不要不计量分发，不要使用装过化学品的水桶。

**升级处理：** 3+ 户出现腹泻：立即全面煮沸饮水，检查水源/水桶/剂量，用计算器为受影响者配制口服补液盐，并通过 mesh 通知整个社区，直到找到故障。
