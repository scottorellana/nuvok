# 森林火灾

林火**上坡时跑得比你快**，随风向说变就变，靠烟和恐慌杀的人比火焰更多。

## 关键步骤

1. **要撤就早撤，否则别撤。** 最糟的是拖延的决定：一队汽车堵死在浓烟弥漫的逃生路上。看得见的烟在逼近+接到警报=带上ICE紧急信息卡和应急包立刻走。
2. **横向逃、往坡下逃，** 绝不往坡上跑，也绝不顺着风助火势的方向跑（火上坡速度翻倍）。
3. **找烧过的和烧不着的：** 已经冷却的黑色过火区、岩石、湖泊/河流、犁过的田、宽阔公路。一大片过火区是森林里最安全的避难所。
4. **被困无路可逃：** 找低洼开阔处（沟渠、路堑），脸朝下趴好，双脚朝向火，盖上泥土/非化纤毯子，隔着湿布呼吸贴地的空气。火头几分钟就会过去：撑住。
5. **困在车里：** 不要下车在火焰间狂奔——关紧车窗，熄火，开着车灯，裹上毯子蜷到仪表盘下：火头的辐射热靠车壳挡，车会受损但能保你。
6. **烟最先杀人：** 湿布捂口鼻，弯腰低姿移动，绝不往浓烟里钻，哪怕"出口就在那个方向"——没有能见度就没有出口。
7. **只有留有余地时才守房子：** 门窗全关，10 m内清走可燃物，灌满浴缸/水桶，穿棉质衣服——即便如此，只要当局说撤：撤。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 烟越来越大还"再看看" | 趁早从宽阔路线撤离 |
| 往坡上跑 | 横向+往下，奔过火区/开阔地 |
| 从车里冲出来在火焰间跑 | 留在车内，蜷到仪表盘下，关窗 |
| 穿化纤衣服撤离 | 棉/毛：化纤会熔进皮肤 |
| 冲着火头回去拿东西/牵牲口 | 什么都不值得迎向火头 |
| 浇湿全身衣服穿越火焰 | 蒸汽会烫伤：只弄湿呼吸用的布 |

## 高风险区的准备

- 房子四周清出10 m（清落叶，柴堆放远）。
- 干燥季节备好应急包和证件+商定两条撤离路线（网状网络的集合点）。
- 用网状网络的战术地图和街坊共享火头位置与被封路段。

## 示例：森林火灾

**情况：** 2 km外的烟柱越来越大，风朝着你的村子吹；唯一的主干出口紧挨着火头。

**做法：** 1. 立即出发：家人+ICE紧急信息卡+水；把火头位置发布到网状网络的地图上。2. 走偏离风轴的横向路线，哪怕更远。3. 浓烟封路：立刻掉头去过火区/开阔地，不赌"说不定冲得过去"。4. 湿布捂着呼吸，车灯全开。5. 在集合点集结，上报缺谁。

**避免：** 不要等"第二次通知"，不要上山头观望，不要开进浓烟，不要顶着火头回去赶牲口。

**升级：** 火在半路追上：关死的车里蜷到仪表盘下，或开阔沟里脚朝火、盖上土；火头过去后，转移到冷却的过火区，处理烧伤和吸入伤（见烧伤指南和心肺复苏指南）并启动网状网络SOS。
