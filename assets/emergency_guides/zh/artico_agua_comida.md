# 极寒中的水与食物

被冻住的水包围着，你也能渴死：**吃雪会降低核心体温**，干冷让你在不出汗的情况下持续脱水。而且严寒要收双倍热量。

## 关键步骤

1. **绝不直接吃雪。** 用体温融雪，花的正是维持你生命的那点热量，还要烧掉双倍能量换水。只有身体暖和且在行进中，才允许极少量。
2. **化开再喝，不要含着：** 火/炉子加锅（锅底先倒一点液态水打底，免得烧穿锅），或装雪的深色袋子晒太阳/水瓶塞进外套夹层（不贴皮肤）。
3. **化水选冰不选雪：** 同体积下，冰出双倍的水，耗一半的燃料。选发蓝的陈年淡水冰；新的海冰是咸的（陈年蓝冰已经析出盐分）。
4. **喝温水，勤着喝。** 严寒中感觉不到渴，呼气却带走大量水分：尿液清亮是你的仪表。温水不用你的体温在肚子里二次加热。
5. **吃脂肪，热量翻倍：** 严寒每天烧4,000-6,000 kcal。脂肪是王（每克能量超过两倍）；睡前一顿热食就是你的夜间暖气。
6. **别让水冻住：** 水瓶倒着放（冰从上面结起：瓶口就不会冻死），白天揣外套里，夜里放进睡袋/庇护所。
7. **冰钓当作食物计划：** 冰层下的水整个冬天都有鱼——凿孔+带饵的钓线（见捕鱼指南）；每次都要先查冰层厚度（见冰雪危险指南）。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 渴了抓雪往嘴里塞 | 化开、温热之后再喝 |
| 干锅大火化雪 | 先加一点水打底，否则烧穿锅 |
| "反正是冰"就用新海冰 | 只用陈年蓝冰或淡水冰 |
| "化水费劲"就限量喝 | 喝到尿液清亮：冷性脱水最阴险 |
| 极寒中吃"清淡"少油餐 | 脂肪加双份口粮：严寒是按热量收费的 |
| 水瓶正着放在露天 | 倒着放，揣进外套/睡袋 |

## 夜间雪炉

- 睡前把水瓶/袋子装满雪塞进睡袋（不贴皮肤）：天亮就有水，一滴燃料不花。
- 保温瓶或裹着袜子的水瓶=液态水撑到早晨。

## 示例：严寒中的水与食物

**情况：** 在雪庇护所里等待的第二天；炉子只剩半罐燃料，液态水不多，食物是饼干+一罐花生酱。

**做法：** 1. 拴着导向绳出去找发蓝的冰（不是雪）。2. 用你现有的液态水打底，分批融化；灌满水瓶，其中一瓶倒置放进睡袋。3. 睡前吃热的一餐：花生酱是你最好的武器（脂肪）。4. 每小时喝温水，直到尿液清亮。5. 燃料过半：化水优先于做饭（饼干不需要火）。

**避免：** 不要"顺便"含雪，不要干锅化雪，不要为省粮跳过夜宵，不要把水瓶留在外面。

**升级：** 燃料耗尽：正午用深色袋子装雪晒太阳，行进时水瓶夹在外套层间；有人不再排尿或神志混乱，按急症处理（失温/脱水），把所有温水优先给他。
