# Triagem — Quem atender primeiro?

> Método START simplificado para emergências com muitos feridos e poucos socorristas.

## Árvore de decisão

```
                        Caminha e fala?
                       /                \
                     SIM                NÃO
                     │                  │
                  🟢 VERDE           Respira?
                  (Pode esperar)    /        \
                                   SIM       NÃO
                                   │          │
                              Sangra muito?   Abrir via aérea
                              /         \       inclinando a cabeça
                            SIM         NÃO     Respira agora?
                            │           │      /          \
                        🟠 LARANJA  🟡 AMARELO SIM        NÃO
                        (Hemorragia) (Estável) │            │
                                              Tem pulso?     │
                                              /          \   NÃO
                                            SIM          NÃO  │
                                         🟠 LARANJA    ⚫ PRETO │
                                                                      │
                                                    🔴 VERMELHO
                                                  (RCP AGORA)
```

## Categorias de triagem

| Cor | Estado | Ação | Exemplos |
|-------|--------|--------|----------|
| 🔴 **VERMELHO** | Crítico, pode sobreviver com ajuda imediata | Atender PRIMEIRO | Não respira (com via aberta), choque severo |
| 🟠 **LARANJA** | Grave, precisa de ajuda mas pode esperar 1h | Deter hemorragia | Sangramento severo, fratura exposta |
| 🟡 **AMARELO** | Estável, pode esperar horas | Imobilizar, observar | Fratura fechada, ferimentos menores |
| 🟢 **VERDE** | Leve, caminha | Autoatendimento | Cortes menores, hematomas |
| ⚫ **PRETO** | Não responde após abrir via aérea | Priorizar os vivos | Parada sem recuperação |

## Regras de ouro

1. **Não perca tempo com um paciente quando há muitos**
2. **Reavalie a cada 15 minutos** — um VERDE pode passar a VERMELHO
3. **Marque cada vítima** com a cor (fita, marcador, roupa)
4. **NÃO mova os PRETOS até que todos os vivos estejam atendidos**

## Protocolo em 60 segundos

| Passo | Tempo | Ação |
|------|--------|--------|
| 1 | 0-10s | Gritar: **"Quem consegue caminhar?"** → esses são VERDE |
| 2 | 10-30s | Aos que ficam: respiram? Os que não → abrir via aérea |
| 3 | 30-50s | Os que respiram: sangram muito? → LARANJA |
| 4 | 50-60s | Os demais → AMARELO. Os que não respiram após via aérea → PRETO |

> 💡 O objetivo NÃO é salvar todos. É salvar o MAIOR NÚMERO que você puder.

## Exemplo prático: Triagem de múltiplas vítimas (quem atender primeiro?)

**Situação:** Depois de um tremor, há várias pessoas pedindo ajuda e você só tem um kit de primeiros socorros pequeno.

**Faça:** 1. Garanta a segurança da cena e peça a uma pessoa específica para ligar para a emergência. 2. Siga os passos principais do guia em ordem, sem pular para o passo que parece mais dramático. 3. Use luvas, barreiras ou panos limpos se estiverem disponíveis. 4. Reavalie a cada minuto: respiração, consciência, sangramento, temperatura ou piora.

**Evite:** Não improvise manobras avançadas, não mova pescoço/coluna se suspeitar de lesão, não dê comida/bebida a alguém confuso e não atrase a chamada por procurar equipamento perfeito.

**Escalone:** Ligue ou transporte imediatamente se não respira normalmente, há dor no peito, sangramento que não cede, confusão, queimadura extensa, possível veneno, gravidez avançada ou múltiplas vítimas.

**Checagem rápida:** antes de fechar o guia, diga em voz alta o que aconteceu, o que você fez, o que falta e quem fica responsável. Este exemplo é uma prática guiada; adapte os passos ao seu ambiente e priorize ajuda profissional quando existir.
