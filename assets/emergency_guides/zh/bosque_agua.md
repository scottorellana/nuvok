# 森林中的水

**三三法则：没有水，3天就会死亡** — 而且脱水从第一天起就会让你判断力下降。森林里有水，关键是要会"读"出它在哪里。

## 关键步骤

1. **先听，再找。** 黎明和黄昏时，静止不动2分钟：流水声很远就能听到。朝声音走。
2. **往低处走，不要往高处。** 水顺着重力流：沿着沟壑和洼地往下走。黄昏时鸟群飞向水源。
3. **寻找绿色标志。** 更绿更密的植被、芦苇、柳树、厚苔藓 = 地表附近有水。
4. **雨水 = 免费又安全的水。** 把塑料布/防水布拉成V形接进容器。这是唯一不用处理就能喝的水。
5. **蒸腾取水袋。** 把塑料袋紧紧套在阳光下的茂密树枝上：4-6小时能收集到叶子蒸发的干净水（量少但安全）。
6. **浑水先过滤再净化。** 用多层布/T恤过滤：去掉泥和可见的虫子。过滤不等于净化。
7. **找到的水必须净化。** 大滚煮沸1分钟（高海拔3分钟），或用氯（5%漂白水每升2滴，等30分钟 — 工具里有计算器）。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 因为"看起来清澈"就喝水坑或死水 | 只取流动的水，且必须净化 |
| 绝望之下吃雪或喝生水 | 腹泻会让你脱水更快：必须净化 |
| 等到口渴才开始省水 | 定时小口喝；口渴信号来得太晚 |
| 大热天顶着太阳找水 | 清晨或黄昏找；出汗更少 |
| 喝尿或海水 | 会加速脱水 — 绝对不要 |
| 因为有汁液就相信不认识的果子/藤蔓 | 只有百分之百认识才可以 |

## 水源安全排序

1. **直接接的雨水** — 无需处理即安全。
2. **树叶蒸腾（袋子）** — 安全但慢。
3. **泉水和湍急溪流** — 必须净化。
4. **河流和水潭** — 过滤+净化。
5. **死水** — 最后手段：过滤+大火煮沸。

## 你需要多少水

- 阴凉处休息：**每天2-3升**。
- 负重行走：**每天4-6升**。
- 省水没有用：要省的是汗（早晚行动，白天阴凉处休息）。

## 示例：森林中的水

**情况：** 在森林迷路第二天，水瓶从昨晚就空了，太阳很大。

**做法：** 1. 待在阴凉处到下午三四点。2. 静听2分钟：定位流水声。3. 沿着沟壑往下，跟着最密的绿色走。4. 用T恤过滤，煮沸1分钟或加氯等30分钟。5. 把防水布拉成V形以防下雨。

**避免：** 不要中午赶路，不要喝生水，没有水不要进食（消化耗水），不要往山上找水。

**升级：** 喝了可疑的水后如出现腹泻或呕吐，转到中毒指南并准备口服补液（计算器）；24小时找不到水时，优先做救援信号而不是继续走。
