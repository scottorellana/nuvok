# 在山中迷路与下撤

在山中迷路时，“不管怎样先往下走”的本能会致命：**峡谷会变窄，瀑布从上方看不见，浓雾会抹去整个世界**。

## 关键步骤

1. **一旦犹豫，立即停下。** STOP 规则：坐下、吸气、观察、计划。迷路后继续走会成倍扩大错误；救援人员会从你最后已知位置开始搜索。
2. **如果可以，原路返回。** 你最后一个明确知道自己在哪里的点非常重要：回到那里，即使要上坡，即使很难受。
3. **有雾或夜晚 = 扎营。** 在山中无能见度移动，就像拿峡谷玩俄罗斯轮盘。搭建庇护（寒冷指南）并等待：山雾通常会在黎明时散开。
4. **下撤时：走山脊或山背，绝不要走峡谷。** 水道会收窄成瀑布和岩壁。宽阔山脊和山背下降更平缓且视野更好。
5. **只在保持距离的情况下沿水走。** 河流向下通常通向有人处，没错——但要沿着山谷上方宽阔的坡面走，不要进入峡谷内部。
6. **标记你的踪迹。** 石堆、交叉树枝、箭头：如果你必须返回或别人来找你，你的踪迹会传达信息。
7. **在陡峭地形上测试每一步。** 陡坡上保持三点支撑，下攀时面向坡面；如有疑问，选择更长的绕行路线——在这里扭断脚踝会改变一切。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| “沿峡谷往下走，水总会流到某个地方” | 走宽阔山脊和山背；与水保持距离 |
| 在浓雾或夜间行走 | 搭建庇护并等待能见度 |
| 犹豫时还继续“再走一点” | STOP：停下、思考、回到已知点 |
| 背对岩壁下攀 | 面向坡面，三点支撑 |
| “分头向两个方向探索” | 队伍始终在一起；最多保持在视线范围内 |
| 因为尴尬而不说出疑虑 | 立即说出来：所有人一起核对方向 |

## 给救援人员的信号

- 3 个任何信号 = 求救：3 声哨响、3 次闪光、3 堆火。
- 在庇护所附近的开阔区域设置高对比度的大信号（衣物、雪上的树枝）。
- 哨声比你的声音传得更远，而且不会让你耗尽体力（救援手势指南）。

## 实用示例：在山中迷路

**情况：** 下山时小径在雾中消失；你已经“觉得”方向没错走了一个小时，但周围没有任何熟悉迹象。

**要做：** 1. 在原地 STOP：不要再向下走一步。2. 你能原路回到上山路线吗？回到最后一个可靠地标，即使需要一个小时。3. 如果雾更浓：在半山坡搭建庇护，等待黎明。4. 有能见度后：选择坡度平缓的宽阔山背，并一路标记路标。5. 启用 mesh 的 SOS，并在空旷处每隔几分钟吹哨。

**避免：** 不要沿着“听起来有水声”的沟谷下行，不要夜间行走，不要在陡坡上临时抄近路，不要不停地用手机找信号而耗电（信标模式）。

**升级：** 如果有人跌倒且无法行走：不要沿坡向下移动他——先稳定伤情（骨折/创伤指南），就地建立庇护，mesh + 集中信号成为你的唯一任务。
