# 城市中的水和资源

没有公共服务的城市**在你触手可及处隐藏着数百升水**——在水箱、管道和热水器里。知道在哪里、按什么顺序获取，比外出寻找更有价值。

## 关键步骤

1. **一停水：立刻把所有能装的都装满。** 最初几分钟仍有水压：浴缸、锅、瓶子。之后关闭总进水阀（防止你管道中的清水倒流排空或被污染）。
2. **你家里藏着水：** 热水器/储水式热水器（40-60 L：下面的阀门，打开上方一个热水龙头让空气进入）、管道（打开家里最低处的水龙头）、马桶水箱（水箱，不是马桶碗——要净化）以及冰箱冷冻室的冰。
3. **城市水源顺序：** 1) 瓶装水，2) 建筑物热水器和水箱，3) 蓄水池/地下水池，4) 游泳池和喷泉仅用于卫生或在有判断地消毒后使用（化学成分未知），5) 城市河流：最后手段，并使用完整的净化阶梯。
4. **城市降雨也算：** 在庭院和屋顶放置篷布和容器；丢弃最初几分钟的水（冲洗屋顶），并消毒。
5. **对所有可疑的水进行消毒：** 煮沸 1 min 或用氯（计算器）。城市里的“清水”可能携带破裂管道从地面带入的东西。
6. **不抢掠的资源：邻里网络。** 与邻居组织起来，弄清每个人有什么（社区组织指南）：楼房水箱 + X 女士的菜园 + 邻居的药房，分配使用比争抢更有价值。
7. **按每人每天 3-4 L 配给**（饮用 + 最低限度烹饪）：这样，一个 4 口之家可以靠 50 L 的热水器生活大约 3-4 天——有时间组织更多资源。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 喝马桶碗里的水 | 用水箱（储水箱）里的水并消毒 |
| 喝“加氯”的泳池水 | 累积化学物质未知：仅用于卫生 |
| 停水后让总阀保持打开 | 关闭它：保护你管道中的水 |
| 不打开上方水龙头就排空热水器 | 空气从上方进入，否则什么也流不出来 |
| 背着邻里囤积 | 邻里网络：安全和资源持续更久 |
| 不处理就喝破裂管道里“看起来清”的水 | 停水后始终煮沸或加氯 |

## 在水量有限时保持卫生

- 用水壶和肥皂洗手：0.5 L 用得好 > 3 L 流水。
- 洗碗/洗衣的漂洗水可重复用于马桶（用桶直接倒入马桶碗）。
- 没有水冲马桶：马桶碗内放双层袋 + 每次使用后加土/灰（卫生指南）。

## 实用示例：城市用水

**情况：** 地震：整个街区没有电，也没有自来水，你家只有 6 小瓶水。

**做：** 1. 打开最低处的水龙头，把管道里剩余的水装进锅里；关闭总阀。 2. 排空热水器（下方阀门 + 打开热水龙头）：+50 L。 3. 取出马桶水箱的水和冰。 4. 在院子里架篷布，以防下雨。 5. 与邻居会合：清点物资并安排公共水箱的值守轮班。

**避免：** 不要把饮用水用来洗碗，不要喝楼里泳池的水，不要让每个人从公共水箱里“能拿多少拿多少”，不要喝未消毒的水。

**升级处理：** 如果多户出现腹泻，公共用水已被污染：停止使用，所有人改为煮沸水 + 口服补液盐（计算器），并做好标记；mesh 将通知传达给整个街区。
