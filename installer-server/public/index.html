📋 Instrucciones de instalación
Android (APK)
1. Descarga el archivo .apk
2. Ábrelo (puede pedir permiso "instalar apps de origen desconocido")
3. Pulsa Instalar
4. Acepta los permisos de ubicación, Bluetooth y archivos
5. La app copiará automáticamente los mapas, biblioteca y modelo IA (~1.3 GB)
macOS (DMG — prueba local, no notarizado)
Este build todavía no está notarizado por Apple. Si aparece “Apple no pudo verificar…”, no significa que el APK Android esté afectado; es Gatekeeper bloqueando el DMG local.
Para distribución real en Mac falta firma Developer ID + notarización + stapling. Para pruebas de campo usa Android.
Windows
No hay build de Windows todavía. Usa Android o macOS.
Linux
No hay build de Linux todavía. Usa Android o macOS.
