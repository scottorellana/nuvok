# 竜巻

竜巻に対しては、車の中でも橋の下でも勝てない：**数分の余裕を持って、地下または最も内側の部屋に入ることで生き延びる**。

## 重要手順

1. **竜巻が差し迫っている兆候：** 緑がかった空、突然の大きな雹、異様な静けさの後に貨物列車のような轟音、回転する壁雲または漏斗雲。いずれかがあれば、今すぐ避難。
2. **最良の避難場所は地下：** 地下室またはくぼみ、頑丈な机の下、窓から離れる。地下室がない場合：下階の内部の部屋（内側の浴室、クローゼット、廊下）— 自分と屋外の間に壁が多いほどよい。
3. **防護姿勢：** しゃがみ、頭を内壁に向け、手と腕で頭と首を覆う；マットレス／毛布／ヘルメットを上にかぶせる。靴を履く（その後、至る所にガラスと釘がある）。
4. **モバイルホーム／薄板の家 = 必ず出る：** トレーラーや軽量住宅は耐えられない — 近隣の堅固な避難場所へ、なければ木や車から離れた低い溝／低地へ、うつ伏せになり、手を首の後ろに置く。
5. **遠くに見える竜巻の中で車両にいる場合：** 進路に対して直角に、堅固な避難場所へ運転する。近い、または渋滞で止まっている場合：車を捨てて低い溝へ — 橋の下は絶対に不可（風洞となり破片を加速させる）。
6. **静けさは終わりではない：** 目または第二の渦が続くことがある。空が明らかに開けるか公式の通知がある場合にのみ外に出る。出るときは注意する：ガス、電線、緩んだ構造物（都市危険ガイド）。
7. **その後：地雷原を歩くように踏み進む。** ガラス、釘、通電している電線、不安定ながれき — 人を探すには崩壊ガイド、被害報告と家族集合にはメッシュを使う。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 「気圧を合わせるために」窓を開ける | 迷信：数秒を失い、飛散ガラスを受ける |
| 橋の下に避難する | 開けた低い溝で、うつ伏せになる |
| 進行方向に車で先回りしようとする | 進路に直角、または溝へ |
| モバイルホームに「つかまって」残る | 必ず堅固な避難場所または低地へ出る |
| 窓から漏斗雲を撮影する | 内部の部屋へ：ガラスは散弾になる |
| 最初の静けさで外に出る | 空が開けるか通知を待つ：第二の渦があり得る |

## 安全な部屋を準備する

- 事前に選んでおく：内部、下階、窓なし。
- 中に置くもの：水、懐中電灯、笛、靴、手の届くマットレス、このアプリのオフライン版。
- 家族で 1 分の訓練：全員が暗闇でも到達できるようにする。

## 実践例：竜巻

**状況:** 突然の雹と強まる轟音；家族と家にいて、地下室はない。

**行うこと:** 1. 全員を下階の内側の浴室へ、今すぐ — 誰も見に行かない。 2. 子どもは奥へ、大人が覆い、マットレスを上に、靴を履く。 3. 頭を下げ、手を首の後ろに、笛を手元に。 4. 轟音が過ぎた後：外に出る前に明確な合図を待つ。 5. 慎重に退出：ガス／電線を確認し、メッシュへ報告し、集合場所へ。

**避けること:** 窓を開けない、車を固定するために外へ出ない、「一秒だけ」とのぞかない、最初の静けさで外へ出ない。

**段階的対応:** 中にいる間に家が壊れる場合：最も強い構造物（浴槽、頑丈なテーブル）の下に入り、頭を守る；その後、閉じ込められた人には崩壊ガイド、重傷には止血帯／出血ガイド、メッシュのSOSを適用する — 最初の 30 分はあなたたちの時間である。
