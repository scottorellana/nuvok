# 山での寒さと避難場所

山での敵は **風 + 湿気 + 標高** の三位一体である：風は熱を 10 倍速く奪い、濡れた衣服は宣告に等しい。

## 重要な手順

1. **暖かいことより乾いていること。** 濡れた衣服（雨または汗）は保温性の 90% を失う。登りで汗をかく前にレイヤーを調整する；止まる前に濡れたものを替える。
2. **まず風を遮る。** -5 °C で強風なら体感は -20 °C になる。どんな遮蔽物（岩、風下側のくぼ地、雪壁）も、風の中の焚き火より価値がある。
3. **山頂から下り、底を避ける。** 避難場所は風を避けた中腹に置く：山頂は風を受け、谷底は夜間の冷気がたまる。
4. **屋根の倍、地面を断熱する。** 松の枝／乾いた草を 20-30 cm：凍った地面は空気より多くの熱を奪う。
5. **深雪では：トレンチまたは雪洞。** 体の大きさの溝 + 枝と雪の屋根、または締まった雪の斜面に雪洞（ドーム状の天井、棒で作る通気孔、寝る台は高く — 冷気は下がる）。
6. **反射させる小さな火。** 熱を避難場所へ反射する岩や壁に向ける；温めた石を布で包み、衣服の中に入れる。
7. **集団の低体温症を監視する。** 制御不能な震え、不器用さ、ろれつが回らない、「もう寒くない」：緊急事態 — ただちに低体温症ガイド、体温を共有する。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 滝のように汗をかきながら登り続ける | レイヤーを調整：出発時は寒め、行動中はほどよく |
| 山頂や谷底に避難する | 中腹、風の当たらない側 |
| 雪／凍った地面に直接寝る | 植物断熱を 20-30 cm、常に |
| 雪洞を密閉する | 通気孔は常に開ける（CO₂ は睡眠中に殺す） |
| 「寒さ対策に」酒を飲む | 血管を拡張する：5 min は温め、残りを冷やす |
| 夜まで避難場所の判断を待つ | 建設には最低 2 時間の明るさが必要 |

## レイヤリングの規則

- **ベース：** 化繊またはウール（綿は絶対に不可：濡れると冷やす）。
- **中間：** 保温（フリース／ダウン） — 努力時には脱ぐ。
- **外側：** 防風／防水を常に手の届く所に。
- 帽子と手袋：頭と手は不釣り合いに熱を失う。

## 実践例：山での寒さ

**状況：** 午後半ば、霧で下山が閉ざされた；汗をかいており、風が吹き、残りの明るさは 2 時間。

**行うこと：** 1. 止まる：今すぐ避難場所を決め、「もう少し下」へ行かない。 2. 風を避けた中腹：大岩の背後のくぼ地。 3. 濡れたレイヤーを替える；乾いたものをすべて着る。 4. 地面に 30 cm の枝、風上に雪／枝の壁。 5. 岩に向けた小さな火 + 包んだ熱い石；メッシュの SOS を起動する。

**避けること：** 霧の中で暗くなっても下り続けない、濡れた衣服で寝ない、山頂や谷底に設営しない、迷って明るさを浪費しない。

**エスカレーション：** 誰かが震えなくなり、寒さで傾眠になったら重度低体温症である：低体温症ガイド、皮膚と皮膚で体温を共有、こすったり酒を与えたりしない；夜明けに、集団全員が可能な場合に限り下山を評価する。
