# 海啸

面对海啸只有一个做法：**去高处，步行，立刻**。它不是一波浪：而是整片海水持续数分钟推进，而且第一波通常不是最严重的。

## 关键步骤

1. **地震就是警报。** 在海岸，强烈或持续较久（20+ 秒）的地震 = 不等警报器或确认，立即疏散到高处。犹豫的几分钟就是生死之差。
2. **自然信号 = 跑：** 海水退去露出干海底、海上发出像飞机/火车一样的轰鸣、水体行为异常。三者任一出现：不要观看 — 向上走。
3. **步行并向上：** 30+ 米高度或 3+ 公里内陆。汽车会堵在所有人逃离的车流里：沿山坡步行上去的人能到；排队车里的人到不了。
4. **没有天然高地：高层混凝土建筑**（4+ 层、屋顶）是你的城市 B 计划。树木只作为最后手段。
5. **在高处停留 12 小时或直到官方通知。** 海啸是一列相隔 10-60 min 的波浪列；第二波或第三波通常更大。“已经过去了”会害死下去观看的人。
6. **被水困住：抓住大型漂浮物**（屋顶、树干），不要与退流对抗 — 它会把你带到外海又带回来；保存体力，保护自己免受碎片伤害（水流像由汽车和墙体组成的搅拌机）。
7. **之后：** 水退后留下陷阱 — 泄漏、电缆、被冲刷掏空的结构，以及需要心肺复苏/伤口指南的伤员。mesh 会让家人重新汇合（事先约定的高处集合点）。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 下到海滩去看退去的海水 | 这是最高级别信号：跑上高处 |
| 沿海岸开车疏散 | 步行，垂直于海岸线，向上 |
| 强震后等待警报器 | 在海岸，地震就是命令 |
| 第一波后返回 | 在上方停留 12 h 或等待官方通知：还会有更多波 |
| 躲在“坚固”的底层 | 高处：第 4+ 层或山坡 |
| 逆着退流游泳 | 抱住大型漂浮物漂浮，并保护自己免受碎片伤害 |

## 为你的海岸做准备

- 了解你的垂直撤离路线：步行 15 min 内是哪片山坡/哪栋建筑？
- 家庭高处集合点设在 mesh 中（不要在海滩）。
- 和孩子演练：“强烈摇晃 = 如有必要不等爸爸也上去，他从自己的那边上去”。

## 实用示例：海啸

**情境：** 海滨小镇；一场长时间地震摇晃，探头查看时海水开始退去，搁浅的船只露出来。

**做：** 1. 一边离开一边大喊“海啸，往上！”——你的声音能救邻居。 2. 家人按约定的垂直路线步行，各自向上走：集合点在上方，不在家里。 3. 在不停下来的前提下，帮助你能帮助的人上去。 4. 到上方后：通过 mesh 清点人数，任何人都不下去。 5. 至少 12 小时或等待官方通知。

**避免：** 不要拿东西，不要开车，不要在波与波之间下去“帮忙”，不要相信间歇期的平静。

**升级：** 如果有人被冲走后出现：若无反应则进行心肺复苏（心肺复苏指南），处理伤口和低体温；将其位置报告到 mesh，以便小组指挥救援——且在通知前其他任何人都不下去。
