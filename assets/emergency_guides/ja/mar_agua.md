# 海と海岸での飲料水

飲めない水に囲まれている：**海水は渇きの二倍の速さで脱水させる**。あなたの命は雨、結露、そして海岸での探し方を知ることにかかっている。

## 重要な手順

1. **海水は絶対に飲まない。** 「少しだけ」も、混ぜてもだめ：腎臓は受け取る水より多くの水を使って塩を排出する。死を早め、先に判断力を曇らせる。
2. **今すぐ雨水回収を準備する。** 雨が降る前に、すべての布・帆布・プラスチックを広げ、中央を容器へ向けてくぼませる。最初の雨でたまった塩を洗い流し、その後に集める。
3. **夜明けの露。** ボートまたは海岸で：日が出る前に、滑らかな表面（船体、帆、大きな葉）を布で拭き取り、絞る。
4. **海岸では最初の砂丘の後ろを掘る。** 海から 30-60 m 離れたところで、水が出るまで掘る；雨の淡水層は塩水の上に浮いている — 井戸をかき混ぜず、表面だけを布またはカップで取る。
5. **河口と岩を探す。** 海へ下る小川、滴る崖の割れ目、高い岩の雨だまり（低いものは塩のしぶき：唇で味見し、飲み込まない）。
6. **青いココナッツ = 安全な水** 熱帯の海岸では：ヤシの根元に落ちた青いもの。非常に熟したもの（茶色）は水が少なく油分が多い：過剰では下剤になる。
7. **火または太陽があれば蒸留する。** 海水を、蒸気を捕らえる布の下で沸かして絞る（粗いが機能する）、または塩水の容器を内部に置いた太陽熱蒸留器を使う。

## やってはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 「渇きをごまかすため」に海水を飲む | 絶対に不可：得るより多くの水を失う |
| 尿または魚の血を飲む | 同様に脱水させる；極限の緊急時に魚の眼・脊柱の液体はごくわずか |
| 雨が降るまで回収装置を作るのを待つ | すべて事前に準備；熱帯の雨は数分で終わる |
| 砂浜の井戸の底から取る | 表面の淡水層だけ、かき混ぜない |
| 砕け波の近くの低い水たまり | 塩のしぶきである；雨の高い水たまりだけ |
| 水なしで多く食べる（干し魚、熟したココナッツ） | タンパク質・脂肪の消化は水を消費する |

## 漂流者の優先事項

1. まず浮力と信号（渇きで死ぬ前に救助される）。
2. 常設の雨水回収を設置する。
3. 汗を節約する：帆・帆布で日陰、日中は冷やすために海水で衣服を濡らす（夜になる前に乾く）、暑い時間帯は動かない。
4. 一緒に飲む水がなければ食べない。

## 実践例：海での水

**状況：** 昨日からエンジンのない小舟で漂流している；残りは半リットルで、空は遠くの雨を示している。

**行うこと：** 1. 今すぐ帆布をバケツへ向かう漏斗状に張り、追加の布を端に結ぶ。 2. 残りの半リットルは実際の渇きに応じて飲み、「取っておく」ことはしない。 3. 夜明けに小舟全体の露を拭き取り、絞る。 4. 暑い時間帯にはシャツを海水で濡らし、帆の日陰にいる。 5. 雨が降ったら：30 秒すすぎ、その後すべて集める。

**避けること：** 海水を一滴も飲まない、水なしで干し魚を食べない、回収装置を未設置のままにしない、日なたに身をさらさない。

**エスカレーション：** 誰かが海水を飲んで混乱またはけいれんした場合は、熱中症・けいれんの緊急事態として扱い、すべての淡水をその人に優先する；海岸に着いたら、内陸へ歩く前に砂丘の後ろを掘る。
