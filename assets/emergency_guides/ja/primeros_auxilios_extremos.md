# 重要な応急処置：MARCH/XABCDEアルゴリズム

> ⚠️ このガイドは専門的な医療や対面訓練に代わるものではない。支援または搬送を開始しながら、資源が少ない状況で最初の数分に行動するためのものである。

## 絶対的優先順位

実際の緊急時に「すべてをやろう」としてはいけない。以下を順番に行う：

```text
0. 現場の安全：自分が別の被害者にならない。
1. 大量出血：噴き出す血、または衣服をぐっしょり濡らす血。
2. 気道：呼吸できるか？閉塞はあるか？
3. 呼吸：正常に呼吸しているか？胸に開放創はあるか？
4. 循環／ショック：冷たい皮膚、弱い脈、混乱。
5. 神経学的状態：反応しない、けいれん、頭部打撲。
6. 露出＋体温：隠れた損傷を探し、寒冷／暑熱を避ける。
```

これは病院前外傷で用いられるMARCH/XABCDEの一般向け版と、非専門家向けの応急処置を組み合わせたものである。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|---|---|
| 「見た目がひどい」から小さな傷から始める | まず数分で命を奪うもの：血液、気道、呼吸 |
| 必要がないのに首／背中を負傷した人を動かす | 火災、崩落、交通、または呼吸停止がある場合のみ動かす |
| 重症者に水、アルコール、錠剤を与える | 混乱している、嘔吐している、外傷がある、または手術が必要になる可能性がある場合は口から何も与えない |
| 針金／細いひもを止血帯として使う | 幅広い布4〜5 cm、または市販の止血帯 |
| 刺さった物を抜く | 周囲を固定する；出血を塞いでいる可能性がある |

## 手順0 — 安全と指揮

1. 3秒見る：交通、電線、ガス、火、武器、崩落、水、煙。
2. 手袋があれば着用する；なければ手にビニール袋をかぶせる。何もなければ、それでも行動する：命が最優先。
3. 一人を指名する：「あなた、救急に電話して」。別の一人に：「あなた、救急箱／AED／布／懐中電灯を持ってきて」。
4. 一人の場合は、スピーカーフォンを起動し、話しながら作業する。

## 手順1 — 大量出血

血液が噴き出す、拍動する、衣服をぐっしょり濡らす、または血だまりを作る場合に行動する。

1. ガーゼ、清潔なTシャツ、または自分の手で出血点を直接強く圧迫する。
2. 鼠径部／腋窩／首の深い傷の場合：布／ガーゼを空洞に詰めて満たし、その上から圧迫する。
3. 腕または脚で、すぐに制御できない、圧迫を維持できない、または切断がある場合：止血帯を傷の5〜8 cm上に、関節の上を避けて装着する。出血が完全に止まるまで締め、時刻を記録する。
4. 病院外で止血帯を緩めてはいけない。

## 手順2 — 気道

1. 話す、または泣いているなら、気道は開いている。
2. 反応しない場合：口の中を見る。見える物だけを取り除く；盲目的にかき出さない。
3. 脊柱損傷の疑いがなければ：やさしく頭部後屈あご先挙上。
4. 首／背中の損傷の可能性がある場合：できるなら下顎挙上。呼吸していなければ、気道確保とCPRが脊柱より優先される。

## 手順3 — 呼吸

1. 正常に呼吸していない、またはあえぎだけなら：CPR。
2. 「空気を吸い込む」胸の開放創：プラスチック／袋／ラップを3辺だけ貼り付け、空気は出るが入らないように覆う。呼吸困難が悪化したら、数秒間一辺を持ち上げる。
3. きつい衣服をゆるめ、意識があり脊柱外傷がなければ楽な姿勢にする。

## 手順4 — ショック

徴候：冷たく蒼白で汗ばんだ皮膚；速い脈；口渇；混乱；脱力。

1. 人を寝かせる。
2. 上からも下からも保温する：地面は熱を奪う。
3. 痛み、骨折、骨盤／脊柱／頭部外傷、または呼吸困難がない場合に限り脚を上げる。
4. 口からは何も与えない。
5. 緊急搬送。

## 手順5 — 頭部、脊柱、けいれん

- 強い打撃、転落、事故、首／背中の痛み、脱力／しびれ：見つけた姿勢で頭を安定させ、どうしても必要な場合のみ一体として動かす。
- けいれん：打撲から守り、時間を測り、口に何も入れない。終わって呼吸していれば横向きにする。
- 呼吸している意識不明者で、脊柱損傷の疑いがない場合：回復体位。

## 手順6 — 露出と低体温

1. 不必要に裸にせず、隠れた損傷を探す。
2. すぐに再び覆う。外傷＋寒冷は出血とショックを悪化させる。
3. 毛布、ジャケット、段ボール、バックパック、または断熱材を人の下に使う。

## 安全な即席対応

| 必要なもの | 代用できるもの | 避けるもの |
|---|---|---|
| 圧迫 | Tシャツ、タオル、清潔なおむつ、直接の手 | 血で濡れた層を取り除く |
| 止血帯 | 幅広い布＋硬い棒 | ケーブル、コード、針金、細いロープ |
| 副木 | 段ボール、板、まっすぐな枝、丸めた雑誌 | 骨をまっすぐに戻す |
| 頸部／脊柱 | 頭の両側にタオル／衣類 | 首を引っ張る、または人を座らせる |
| 胸部シール | ビニール袋、包装材、テープ | 悪化する場合に4辺を完全密閉する |
| 保温 | 毛布、ジャケット、ビニール、体の下の段ボール | 冷たい地面に放置する |

## 科学的基盤

CPR/AEDに関するAHA 2025の公開原則、出血に関するSTOP THE BLEED/ACS、初期評価と早期搬送に関するATLS 2025およびPHTLS/NAEMTの外傷フレームワーク、IFRC/Red Crossの応急処置に基づく。独自講習の内容をコピーするものではなく、優先順位を一般人向けの安全な手順へ翻訳している。

## 実践例：重要な応急処置：MARCH/XABCDEアルゴリズム

**状況：** 遠隔地で、ある人が重傷を負い、搬送に30分以上かかる。

**実行：** 1. 現場の安全を確保し、特定の一人に緊急通報を依頼する。 2. ガイドの大きな手順を順番どおりに進め、より劇的に見える手順へ飛ばない。 3. 利用可能なら手袋、バリア、または清潔な布を使う。 4. 毎分再評価する：呼吸、意識、出血、体温、悪化。

**避ける：** 高度な手技を即興で行わない、損傷が疑われる場合は首／脊柱を動かさない、混乱している人に食べ物／飲み物を与えない、完璧な器材を探すために通報を遅らせない。

**エスカレーション：** 正常に呼吸していない、胸痛がある、止まらない出血、混乱、広範囲熱傷、毒の可能性、妊娠後期、または複数の傷病者がいる場合は、直ちに電話するか搬送する。

**クイックチェック：** ガイドを閉じる前に、何が起きたか、何をしたか、何が残っているか、誰が責任者として残るかを声に出して言う。この例はガイド付き練習である；手順を環境に合わせ、利用可能な場合は専門的支援を優先する。
