# Identidad oficial de Nuvok

**Estado:** fuente oficial de marca aprobada por producto.  
**Lema oficial:** `PREPARA • PROTÉGETE • SOBREVIVE`

Este directorio preserva los PNG originales entregados por el responsable del producto. No se redibujan, recolorean, deforman, recortan ni se sustituyen con propuestas generativas anteriores.

## Assets

| Archivo | Rol aprobado | Uso |
|---|---|---|
| `nuvok_brand_guidelines_master.png` | Guía visual maestra | Referencia para diseño, marketing, presentaciones y futuras exportaciones. No usar como logo embebido en UI. |
| `nuvok_lockup_primary.png` | Lockup horizontal principal | Cabeceras, portada, splash y contextos de marca en fondo oscuro/neutro, cuando hay suficiente ancho. Incluye emblema, wordmark y lema. |
| `nuvok_wordmark.png` | Wordmark solo texto | Barras estrechas, documentación, pie de página y lugares donde el emblema completo no cabe. |
| `nuvok_lockup_halo.png` | Lockup horizontal con halo | Portadas, hero banners y superficies oscuras donde el brillo oliva mejora la visibilidad. |
| `nuvok_identity_presentation.png` | Lámina de presentación | Referencia de sistema y capacidades. No usar como icono de app ni como logo de navegación. |

## Sistema visual observado

- **Emblema:** una `N` plateada/blanca dentro de un anillo segmentado oliva/dorado; integra una brújula/flecha al norte y un perfil de montañas. El símbolo comunica orientación, terreno y preparación ante desastres.
- **Wordmark:** `NUVOK` geométrico, con un indicador/flecha oliva dentro de la `O`.
- **Colores:** negro/grafito profundo, blanco metálico y oliva/dorado apagado. No introducir cian, naranja, degradados o colores de las propuestas descartadas.

## Reglas de uso

1. Mantener la proporción, relación emblema–wordmark, tipografía y lema sin alteraciones.
2. Usar el lockup principal en fondo negro, grafito o neutro oscuro; usar la versión negativa indicada en `nuvok_brand_guidelines_master.png` para fondos claros.
3. Usar el wordmark solo cuando el layout no permite el emblema completo.
4. El icono de app debe derivarse del **emblema circular** aprobado en la guía maestra; no usar la lámina `nuvok_identity_presentation.png` completa como icono.
5. No usar los PNG de presentación como assets de UI pequeños: contienen márgenes y composición editorial.
6. Antes de preparar iconos nativos, solicitar o crear una exportación cuadrada limpia del emblema oficial, conservando exactamente su geometría y paleta.
