# 砂漠での水

砂漠では水こそが命：水なしでは猛暑の中**1〜2日**しかもちません。すべての判断は汗で測ります。

## 重要ステップ

1. **持っている水は飲む。** 「節約」が古典的な致命的ミス：水筒に水を残したまま脱水で亡くなる人がいます。体はボトルより上手に水を蓄えます。
2. **水ではなく汗を節約する。** 移動は夜明け・夕暮れ・夜だけ。それ以外は日陰で休む。真昼の歩行は1時間に1リットルを失います。
3. **涸れ川を探す。** 干上がった川の外側カーブ、砂が濃く見える場所や植物が生える場所を30〜60cm掘る。砂が湿ったら、水が穴に染み出すのを待つ。
4. **生き物のサインを追う。** 夜明けと夕暮れの鳥は水に向かって飛ぶ。虫の群れ、集まる動物の足跡、緑の茂みは近くの水のしるし。
5. **夜明けの露を集める。** 日の出前に吸水性の布を草の上で引きずり、絞る。寒い夜は滑らかな岩や金属面にも水滴がつく。
6. **岩のくぼみを確認する。** 岩場の日陰のくぼみや割れ目（天然の水たまり）は、雨の後何週間も雨水を保つ。
7. **できる限り浄化する。** くぼみや掘った穴の水は、沸騰させるかキットの塩素（5%を1リットルに2滴、30分待つ）。砂漠での下痢は死の宣告です。

## してはいけないこと

| ❌ 間違い | ✅ 正しい |
|-----------|-----------|
| 渇いたまま歩きながら水を「温存」 | 渇いたら飲む。節約するのは体力 |
| サボテンの汁を飲む——命取りの俗説 | 大半は嘔吐と下痢を起こし、失う水が増える |
| 真昼に水を探して歩く | 探すのは夜明け・夕暮れ。真昼は日陰 |
| 尿やラジエーターの水を飲む | 脱水を早め、中毒を起こす |
| 残り1リットル未満で食事する | 消化は水を使う。水がなければ食べない |
| ソーラースチルに全てを賭ける | 収量は少ない（1日カップ1杯）。補助であり救いではない |

## ソーラースチル（補助であり奇跡ではない）

1. 湿り気のある地面（涸れ川）に幅60cm×深さ40cmの穴を掘るか、砕いた青草を入れる。
2. 底の中央に清潔な容器を置く。
3. 透明なビニールで穴を覆い、縁を石や砂で密閉する。
4. 容器の真上、ビニールの中央に小石を置く：円錐が結露を容器へ滴らせる。
5. 6〜12時間待つ。1日約カップ1杯：頼るなら複数作る。

## 危険な脱水のサイン

- 尿が濃い、または8時間以上出ない。
- 立ちくらみ、ズキズキする頭痛。
- つまんだ皮膚が戻らない、唾液のないネバつく口。
- 混乱やイライラ → 熱中症ガイドへ：今すぐの緊急事態です。

## 例：砂漠での水

**状況：** 砂漠の道で車が故障。1人1リットルしか残らず、救助は丸1日以上かかるかもしれない。

**行動：** 1. 車のそばに留まる（日陰＋発見されやすさ）。2. 渇きに合わせて飲み、「温存」しない。3. 朝夕の光で近くの涸れ川を探し、外側カーブを掘る。4. 手持ちのビニールで1人1基のソーラースチルを作る。5. 位置に印を付け、メッシュのSOSを起動する。

**回避：** 真昼に歩かない。サボテンや尿を飲まない。水が少ないときは食べない。方角の印なしで車を離れない。

**エスカレーション：** 誰かが汗をかかなくなる、混乱する、倒れる——それは熱中症：今すぐ日陰へ、服を濡らし、あおぎ、熱中症ガイドへ。砂漠で一番の緊急事態です。
