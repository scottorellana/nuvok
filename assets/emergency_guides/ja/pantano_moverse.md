# 沼地とマングローブでの移動

沼地では歩くのではない：**一歩ごとに交渉する**。泥は小道の5倍消耗し、直線は最も遅いルートである。

## 重要手順

1. **探り棒を常に使う。** 2 mの丈夫な枝：荷重をかける前に一歩ごとに試す。見た目に緑で固くても、深い泥の上のかさぶたかもしれない。
2. **開けた場所ではなく、根と草株を踏む。** マングローブの根と草の盛り上がりは支える；それらの間の「開けた道」は泥沼である。ジグザグになっても、草株から草株へ進む。
3. **深い泥にはまったら：横になる。** 垂直に戦うとさらに埋まる。荷重を分散する：胸を棒またはバックパックに載せ、片脚ずつ抜きながら後方へゆっくり「泳ぐ」。ゆっくりが勝つ；パニックは埋める。
4. **マングローブの潮 = あなたの時計。** 下げ潮で入り、上げる前に出る：満潮のマングローブは地面と目印を消す。入る時に制限時刻を決める。
5. **固定方位、さもなければ永遠の円。** 目印がなければ、沼地は円を描いて歩かせる：コンパス／太陽で方位を固定し、50歩ごとに遠くの物（高い木、アンテナ）で確認する。
6. **腰までの水：持ち上げず、引きずる。** 足を底に付けたまま滑らせると、穴と、泥からブーツを一回ごとに「抜く」消耗を避けられる。必要時に捨てられるよう、バックパックの腰ベルトは緩める。
7. **日暮れ前に水から出る。** 夜の沼地は爬虫類とヤブカのものだ：乾いた台、昆虫対策の煙の多い火、閉じた衣服（危険ガイド）。

## してはいけないこと

| ❌ 誤り | ✅ 正しい方法 |
|----------|------------|
| 「より直接的」な泥の開けた場所を渡る | 根から根へ、草株から草株へ |
| 飲み込む泥に対して垂直に戦う | 横になり、荷重を分散し、後方へ泳ぐ |
| 潮が上げている時にマングローブへ入る | 下げている時に入り、余裕を持って出る |
| 方位を確認せずに「まっすぐ」歩く | コンパス／太陽 + 50歩ごとの遠い目印 |
| 各足を泥の外へ持ち上げる | 足を底に付けたまま引きずる |
| 日暮れに水の中に居続ける | 暗くなる前に乾いた台 + 火 |

## ペースとエネルギー

- 疲れ切る前に休む：乾いた場所で一時間あたり10 min；泥は利息を取る。
- 思っている倍、水分補給する：湿気の中では気づく以上に汗をかく。
- 各休憩で脚と足を点検する：ヒルと、水が隠す傷（ヒルは引きちぎったり焼いたりせず、口の部分に爪を滑らせて外す）。

## 実践例：沼地での移動

**状況：** 海岸へ向かってマングローブを近道する；40分後、泥が足首から膝までになり、潮が上がり始める。

**実行：** 1. 制限時刻を確認する：潮がすでに支配している — 近道を中止する。2. まったく同じ足跡と既知の草株を踏んで引き返す。3. 一歩ごとに前方を棒で探る。4. 泥に飲まれたら：横になり、胸の荷重を棒に載せ、片脚ずつ。5. 乾いた場所で：脚を点検し、水分補給し、堅い地面でマングローブを迂回する。

**避ける：** 直接の開けた場所を渡って「急がない」、潮が上がっている間は進み続けない、棒を手放さない、垂直のまま戦い続けない。

**エスカレーション：** 誰かがはまり、その技術で出られない場合：同じ泥に入ってはならない — 固い足場から棒／ロープ／結んだシャツを使い、胸の下に枝を入れて荷重を分散する；正確な位置を添えてメッシュのSOSを起動する。
