# 森の水

**3のルール：水なしでは3日で死ぬ** — そして脱水状態では初日から判断を誤る。森には水が存在する。それを読み取る術を知らなければならない。

## 重要な手順

1. **探す前に耳を澄ませる。** 夜明けと夕暮れに、2分間じっとしている：流れる水は遠くからでも聞こえる。音のする方へ歩く。
2. **上らず、下る。** 水は重力に従う：谷筋や窪地を下方へたどる。夕暮れ時の鳥は水の方へ飛ぶ。
3. **緑の指標を探す。** より緑が濃く密な植生、イグサ、ヤナギ、豊富なコケ = 地表近くに水がある。
4. **雨 = 無料で安全な水。** プラスチック／防水シートを容器に向けてV字に広げる。これは処理せずに飲める唯一の水である。
5. **蒸散トラップ。** 日の当たる葉の茂った枝にビニール袋をしっかり結び付ける：4〜6時間で葉から清潔な水が集まる（少量だが安全）。
6. **濁った水は浄化する前にろ過する。** 布／Tシャツを重ねる：目に見える泥や虫を取り除く。ろ過しても浄化にはならない。
7. **見つけた水は必ず浄化する。** 強く泡立つ沸騰で1分間沸かす（山岳では3 min）、または塩素を使う（5%の漂白剤を2滴/リットル、30 min待つ — ツール内の計算機）。

## してはいけないこと

| ❌ 誤り | ✅ 正しい対応 |
|----------|------------|
| 水たまりや停滞水を「澄んで見えるから」と飲む | 流水のみ、かつ必ず浄化する |
| 絶望して雪を食べたり、浄化せずに飲んだりする | 下痢はさらに脱水を進める：必ず浄化する |
| 喉が渇くまで配分を待つ | 定期的に少しずつ飲む；渇きは遅れて来る |
| 暑い日中に水を探して歩く | 早朝または夕暮れに探す；汗が少なくなる |
| 尿や海水を飲む | 脱水を加速させる — 絶対にしない |
| 液体があるからといって未知の果実／つる植物を信用する | 完全な確信を持って識別できる場合のみ |

## 安全性順の水源

1. **直接集めた雨水** — 処理しなくても安全。
2. **葉の蒸散水（袋）** — 安全だが遅い。
3. **湧き水と流れの速い渓流** — 必ず浄化する。
4. **川と淵** — ろ過 + 浄化。
5. **停滞水** — 最後の手段：ろ過 + 強く沸騰。

## 必要な水の量

- 日陰で安静：**2〜3リットル/日**。
- 荷物を背負って歩く：**4〜6リットル/日**。
- 水を配分しても機能しない：配分すべきは汗である（早朝／夕方に移動し、日陰で休む）。

## 実践例：森の水

**状況：** 森で迷って二日目、昨夜からボトルは空で、強い日差しがある。

**行うこと：** 1. 午後半ばまで日陰にいる。 2. 静かに2分間耳を澄ませる：流れる水の位置を特定する。 3. より密な緑をたどりながら谷筋を下る。 4. Tシャツでろ過し、1分間沸騰させる、または30 min塩素処理する。 5. 雨に備えて防水シートをV字に設置する。

**避けること：** 正午に歩かない、浄化せずに飲まない、水なしで食べない（消化は水を消費する）、水を探して丘を登らない。

**エスカレーション：** 疑わしい水を飲んだ後に下痢または嘔吐が出た場合は、中毒のガイドに移り、経口補水液を準備する（計算機）；水を見つけられないまま24 h経過している場合は、歩き続けるより救助信号を優先する。
