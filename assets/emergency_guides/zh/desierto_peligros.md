# 沙漠的危险

沙漠里真正致命的很少是电影里演的那些：而是**突发山洪、你伸手的地方、和你铺床的干河床**。

## 重要步骤

1. **绝不在干河床里扎营。** 山洪是沙漠的无声杀手：30公里外你看不见的一场雨，可能在夜里送来一堵水墙。永远睡在高处，哪怕干河床看起来最平坦舒适。
2. **河床开始轰鸣或闻到湿土味，立刻往高处跑。** 不要蹚过有流水的河道：几分钟内水洼就变成激流。
3. **先看后碰。** 蛇和蝎子就休息在你想要的阴凉里：石头下、木头下、裂缝里。翻石头和木头时朝自己方向滚（动物往另一边逃），绝不把手伸进看不见的地方。
4. **每天早晨抖靴子和衣服。** 蝎子夜里会钻进来取暖。靴子倒过来+敲鞋跟再穿：必做仪式。
5. **拄杖行走，用力踏步。** 震动会提醒蛇避开；大多数咬伤发生在踩到或伸手时。看到蛇：静止，然后缓慢后退——绝不摆弄它，哪怕"死了"（蛇头会反射性咬人）。
6. **沙尘暴：停下、遮蔽、等待。** 暴风来之前先标记方向（石头箭头），用布遮住口鼻，保护眼睛，背风靠着掩体等待：在沙尘暴中行走等于迷路。
7. **敬畏夜间的寒冷。** 40°C的白天之后，凌晨可能接近0°C：沙漠失温真实存在（高温与庇护所指南）。

## 不要做的事

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 在"又平又舒服"的干河床扎营 | 永远在高处，远离河道 |
| 把手脚伸进裂缝、洞穴或石头下 | 先看清楚，石头朝自己滚 |
| 不抖靴子就穿 | 每次都倒置敲跟 |
| 摆弄"死"蛇 | 蛇头数小时后仍会反射性咬人 |
| 在沙尘暴中行走 | 停下、标记方向、遮蔽、等待 |
| 切开/吸吮蛇咬伤口 | 制动、记时间、转到咬伤指南 |

## 被蛇咬了

1. 远离蛇；坐下保持冷静（心跳快会加速毒液扩散）。
2. 立即取下患肢的戒指/手表/靴子（会肿胀）。
3. 患肢制动，保持与心脏同高或更低；记下时间并用笔标出肿胀边缘。
4. 不要止血带、不要切开、不要吸吮、不要冰敷。
5. 尽量少走动；能被抬就被抬 → 咬伤与蜇伤指南。

## 蝎子蜇伤

- 局部剧痛：清洗，隔布冷敷，用急救包的止痛药。
- 观察4小时：流口水、复视、肌肉抽搐或呼吸困难=急需抗毒血清，启动SOS。
- 小孩被蝎子蜇永远按急症处理。

## 示例：沙漠的危险

**情况：** 干旱地带天色渐晚；唯一平坦避风的地方是一条软沙干河床。

**做法：** 1. 放弃它：爬上3-5米外最近的高台，哪怕不那么舒服。2. 扎营前把周围石头朝自己滚动检查裂缝。3. 靴子倒置放在庇护所内。4. 用石头箭头标记方向，以防清晨遇沙尘暴。5. 备好保暖：凌晨会很冷。

**避免：** 再舒服也不睡河床，靴子不放外面，黑暗中不把手伸到石头下，沙尘暴来了不行走。

**升级：** 如果山洪还是来了：扔掉一切爬到最高点（不要横穿水流）；如果咬伤肿胀迅速蔓延或呼吸困难，启动网状网络SOS并按咬伤指南处理——这是和毒液赛跑。
