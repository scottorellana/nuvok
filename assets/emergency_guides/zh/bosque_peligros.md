# 森林危险

在森林里几乎没有什么会主动捕猎你：**大多数事故是人自己造成的**——脚踩哪里、手伸哪里、睡在哪里。

## 关键步骤

1. **看清脚踩哪里、手抓哪里。** 90% 的蛇咬发生在脚和手：踩在原木上面（不要在没看见另一侧时直接跨到另一边），绝不要把手伸进洞里、石头下面或落叶层中。
2. **声音 = 你的盾牌。** 走路时发出自然声响：几乎所有动物听到你来都会避开你。危险在于惊吓到它们。
3. **使用前抖动一切。** 早晨抖靴子、衣服和背包：蝎子和蜘蛛夜间会寻找温暖。
4. **进庇护所前检查上方。** 悬挂的枯枝（“寡妇制造者”）、蜂巢、树上的蚁巢——一根树枝杀伤的人比美洲狮更多。
5. **遇到蛇：静止并后退。** 缓慢向后退两步；它不想把毒液浪费在不能吃的东西上。绝不要碰它“把它移开”，死蛇也不要碰（咬合反射）。
6. **黄蜂/蜜蜂成群：直线跑远。** 至少 200-300 m，如果可以就穿过灌木；不要跳进水里（它们会等你出来）。遮住脸和颈部。
7. **如果发生严重咬伤或蜇伤**，转到咬伤和蜇伤指南：固定患处、标记时间，且绝不要使用止血带或吸吮。

## 不要做什么

| ❌ 错误 | ✅ 正确 |
|----------|------------|
| 把手/脚伸到看不见的地方 | 先看清，用棍子移动物品 |
| 直接睡在落叶层中的地面上 | 用树枝搭高床 + 检查区域 |
| 接近“被遗弃”的幼崽 | 母兽就在附近：立刻离开 |
| 触摸有毛的毛虫、彩色青蛙或有乳汁的植物 | 鲜艳颜色 = 化学警告 |
| 在灌丛中惊慌奔跑 | 稳定行走：跌倒是 #1 事故 |
| 把食物挂在睡觉处旁边 | 食物距离 50+ m 并悬高：不要邀请动物到你的床边 |

## 真实危险，按顺序

1. **跌倒和扭伤**——山林中真正的 #1 事故。
2. **坠落的枯枝**——始终检查上方。
3. **昆虫**（黄蜂、蚂蚁、蜱虫、蚊子）——造成的住院人数比所有哺乳动物加起来还多。
4. **蛇**——通过看清脚下可避免。
5. **刺激性植物和刺**——如果不清洁会感染。
6. **大型哺乳动物**——排在名单最后：它们会避开你。

## 蜱虫和水蛭

- 蜱虫：用镊子从头部夹住，缓慢、直线拉出。不要烧它，也不要用酒精淹它（会反流）。
- 水蛭：用指甲沿其口部滑入使其脱落；不要硬扯。
- 记录叮咬日期：随后几天出现发热 = 需要医疗处理。

## 实用示例：森林危险

**情境：** 黄昏时，你在找柴火，倒木之间有很深的落叶层。

**做法：** 1. 先用长棍拨动落叶，再伸手。 2. 每次踩上原木，并在下到另一侧前先看清。 3. 捡柴时保持正常声响。 4. 睡前抖靴子，并检查庇护所上方。

**避免：** 不要夜间捡柴，不要把手伸进洞里，不要触碰巢穴或蜂巢，不要把食物留在庇护所里。

**升级：** 如果被蛇咬，或遭蜂群攻击出现多处蜇伤（或有过敏：面部肿胀、呼吸时有哨鸣声），立即转到咬伤/蜇伤指南并启动 mesh 的 SOS。
